# 帮助页面功能 Spec

## Why
玩家需要一个帮助页面来了解游戏中的各种提升途径和玩法提示，帮助玩家更好地理解如何提升角色实力。

## What Changes
- 新增帮助页面组件，显示角色的完整信息（参考结算页面）
- 在菜单的帮助按钮上添加点击事件，打开帮助页面
- 在各项属性后面显示智能帮助提示，根据玩家当前状态动态显示

## Impact
- Affected specs: 菜单系统、页面路由
- Affected code: 
  - src/components/home/Menu.tsx（添加帮助按钮点击事件）
  - src/App.tsx（添加帮助页面状态管理）
  - 新增 src/components/help/HelpPage.tsx（帮助页面组件）
  - 新增 src/components/help/help.css（帮助页面样式）
  - 新增 src/utils/helpUtils.ts（帮助信息生成工具函数）

## ADDED Requirements

### Requirement: 帮助页面显示完整角色信息
帮助页面 SHALL 显示以下信息（参考结算页面）：
- 战斗力
- 等级
- 装备战斗力
- 幻兽战斗力
- 军衔
- 爵位
- 与公主关系
- 金钱和魔石

#### Scenario: 显示角色信息
- **WHEN** 玩家打开帮助页面
- **THEN** 显示完整的角色信息，但不显示评价称号、综合评语和操作按钮

### Requirement: 等级帮助信息
帮助页面 SHALL 在等级后面显示升级提示：
- 显示内容："日常任务，幻兽研究所任务、战斗和使用满经验球都可快速升级，可以在经验导师处兑换经验球"
- 显示条件：等级 < 132级
- 隐藏条件：等级 >= 132级时不显示

#### Scenario: 显示等级帮助
- **WHEN** 玩家等级 < 132级
- **THEN** 在等级后面显示升级提示信息

#### Scenario: 隐藏等级帮助
- **WHEN** 玩家等级 >= 132级
- **THEN** 不显示等级帮助信息

### Requirement: 装备战斗力帮助信息
帮助页面 SHALL 在装备战斗力后面根据条件显示以下帮助信息：

1. **品质提升提示**
   - 显示内容："你有装备可以提升品质"
   - 显示条件：当前装备的六件装备中至少有一件未达到极品品质
   - 隐藏条件：所有装备都达到极品品质

2. **魔魂等级提升提示**
   - 显示内容："你有装备可以提升魔魂等级"
   - 显示条件：当前装备的六件装备中至少有一件魔魂等级 < 12级
   - 隐藏条件：所有装备魔魂等级都达到12级

3. **使用等级提升提示**
   - 显示内容："你有装备可以提升使用等级"
   - 显示条件：当前装备的六件装备中至少有一件提升使用等级后不会超过角色等级
   - 隐藏条件：所有装备提升使用等级后都会超过角色等级

4. **战魂等级提升提示**
   - 显示内容："你有装备可以提升战魂等级"
   - 显示条件：战魂系统已开启 且 当前装备的六件装备中至少有一件战魂等级 < 5级
   - 隐藏条件：战魂系统未开启 或 所有装备战魂等级都达到5级

5. **战魂套装提示**
   - 显示内容："你的装备可以集齐战魂套装"
   - 显示条件：战魂系统已开启 且 当前装备的六件装备战魂类型不一致
   - 隐藏条件：战魂系统未开启 或 所有装备战魂类型都一致

#### Scenario: 显示装备品质提升提示
- **WHEN** 玩家装备中有未达到极品品质的装备
- **THEN** 显示"你有装备可以提升品质"

#### Scenario: 显示装备魔魂提升提示
- **WHEN** 玩家装备中有魔魂等级 < 12级的装备
- **THEN** 显示"你有装备可以提升魔魂等级"

#### Scenario: 显示装备使用等级提升提示
- **WHEN** 玩家装备中有提升使用等级后不会超过角色等级的装备
- **THEN** 显示"你有装备可以提升使用等级"

#### Scenario: 显示战魂等级提升提示
- **WHEN** 战魂系统已开启 且 玩家装备中有战魂等级 < 5级的装备
- **THEN** 显示"你有装备可以提升战魂等级"

#### Scenario: 显示战魂套装提示
- **WHEN** 战魂系统已开启 且 玩家装备战魂类型不一致
- **THEN** 显示"你的装备可以集齐战魂套装"

### Requirement: 幻兽战斗力帮助信息
帮助页面 SHALL 在幻兽战斗力后面显示幻化提示：
- 显示内容："可以继续幻化幻兽"
- 显示条件：始终显示

#### Scenario: 显示幻兽帮助
- **WHEN** 玩家打开帮助页面
- **THEN** 在幻兽战斗力后面显示"可以继续幻化幻兽"

### Requirement: 军衔帮助信息
帮助页面 SHALL 在军衔后面显示战功提示：
- 显示内容："获得战功来提高军衔和战斗力"
- 显示条件：军衔 < 元帅（等级 < 11）
- 隐藏条件：军衔达到元帅（等级 >= 11）

#### Scenario: 显示军衔帮助
- **WHEN** 玩家军衔 < 元帅
- **THEN** 显示"获得战功来提高军衔和战斗力"

#### Scenario: 隐藏军衔帮助
- **WHEN** 玩家军衔达到元帅
- **THEN** 不显示军衔帮助信息

### Requirement: 爵位帮助信息
帮助页面 SHALL 在爵位后面显示功勋提示：
- 显示内容："获得功勋来提高爵位和战斗力"
- 显示条件：爵位 < 王（等级 < 6）
- 隐藏条件：爵位达到王（等级 >= 6）

#### Scenario: 显示爵位帮助
- **WHEN** 玩家爵位 < 王
- **THEN** 显示"获得功勋来提高爵位和战斗力"

#### Scenario: 隐藏爵位帮助
- **WHEN** 玩家爵位达到王
- **THEN** 不显示爵位帮助信息

### Requirement: 公主关系帮助信息
帮助页面 SHALL 在与公主关系后面显示亲密度提升提示：
- 显示内容："每周日给公主赠送礼物，每天和公主聊天，均可提升亲密度"
- 显示条件：关系等级 < 亲密恋人（等级 < 6）
- 隐藏条件：关系等级达到亲密恋人（等级 >= 6）

#### Scenario: 显示公主关系帮助
- **WHEN** 玩家与公主关系 < 亲密恋人
- **THEN** 显示"每周日给公主赠送礼物，每天和公主聊天，均可提升亲密度"

#### Scenario: 隐藏公主关系帮助
- **WHEN** 玩家与公主关系达到亲密恋人
- **THEN** 不显示公主关系帮助信息

### Requirement: 金钱和魔石帮助信息
帮助页面 SHALL 在金钱和魔石后面显示抽奖提示：
- 显示内容："抽奖可获取大量物品"
- 显示条件：始终显示

#### Scenario: 显示金钱魔石帮助
- **WHEN** 玩家打开帮助页面
- **THEN** 在金钱和魔石后面显示"抽奖可获取大量物品"

### Requirement: 帮助页面关闭功能
帮助页面 SHALL 提供关闭按钮，点击后关闭帮助页面返回游戏主界面。

#### Scenario: 关闭帮助页面
- **WHEN** 玩家点击关闭按钮
- **THEN** 关闭帮助页面，返回游戏主界面
