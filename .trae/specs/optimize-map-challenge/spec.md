# 地图挑战系统优化 Spec

## Why

当前地图挑战系统的实现不完整，缺少核心功能：
- 没有地图占领状态管理
- NPC对话逻辑不完善
- 缺少挑战战斗流程
- 缺少每日奖励领取机制
- 缺少每日重置机制

参考文档提供了完整的交互逻辑设计，需要按照文档优化实现。

## What Changes

- **新增地图占领状态管理**：添加 `owermap`（拥有的地图）、`mapreward`（今日是否可领奖励）、`mapRaceData`（各地图今日是否已挑战）状态
- **优化NPC对话逻辑**：根据玩家当前状态显示不同选项（挑战/领取奖励）
- **完善挑战流程**：检查爵位要求 → 检查今日是否已挑战 → 进入战斗 → 胜利后成为保护者
- **完善奖励领取机制**：成为保护者后每日可领取奖励
- **添加每日重置机制**：新的一天重置奖励和挑战状态
- **添加挑战者配置**：每个地图有对应的挑战者数据
- **更新地图数据**：修正地图ID匹配问题

### 核心变量

| 变量名 | 类型 | 说明 |
|--------|------|------|
| owermap | string \| null | 当前拥有的地图ID，null表示没有 |
| mapreward | boolean | 今日奖励是否可领取 |
| mapRaceData | Record&lt;string, boolean&gt; | 各地图今日是否已挑战 |

## Impact

- **受影响的spec**：无
- **受影响的代码**：
  - `src/data/mapChallengeData.ts` - 更新地图配置和挑战者数据
  - `src/data/npcData.ts` - 更新NPC配置，使用动态选项
  - `src/utils/mapChallengeUtils.ts` - 重写工具函数
  - `src/App.tsx` - 添加状态管理和交互逻辑
  - `src/components/common/NPCModal.tsx` - 支持动态选项
  - `src/data/gameData.ts` - 修正地图ID与NPC的匹配

## ADDED Requirements

### Requirement: 地图占领状态管理

系统应管理玩家的地图占领状态：
- 记录玩家当前拥有的地图
- 记录各地图今日是否已挑战
- 记录今日奖励是否可领取
- 支持状态持久化（可选）

#### Scenario: 成为地图保护者
- **WHEN** 玩家挑战地图胜利
- **THEN** owermap设置为该地图ID，mapreward设置为true

#### Scenario: 每日重置
- **WHEN** 新的一天开始
- **THEN** mapreward设置为true，mapRaceData中所有地图重置为可挑战

### Requirement: NPC对话逻辑

地图赛报名官的对话应根据玩家状态显示：
- 显示挑战说明和当前地图状态
- 显示"查看保护者每天的奖励"选项
- 根据玩家是否是当前地图的保护者，显示"我来挑战"或"我来领取今天的奖励"选项
- 显示"随便看看"选项

#### Scenario: 玩家不是保护者
- **WHEN** 玩家点击地图赛报名官且不是该地图保护者
- **THEN** 显示挑战说明和"我来挑战"选项

#### Scenario: 玩家是当前地图保护者
- **WHEN** 玩家点击地图赛报名官且是该地图保护者
- **THEN** 显示保护者说明和"我来领取今天的奖励"选项

### Requirement: 地图挑战流程

挑战地图应按以下流程：
1. 检查爵位是否达到要求
2. 检查今日是否已挑战
3. 进入与挑战者的战斗
4. 战斗胜利后成为该地图保护者
5. 发放挑战奖励

#### Scenario: 挑战成功
- **WHEN** 玩家满足爵位要求且今日未挑战，战斗胜利
- **THEN** 玩家成为该地图保护者，标记今日已挑战，发放奖励

#### Scenario: 爵位不足
- **WHEN** 玩家爵位不足
- **THEN** 显示提示信息

#### Scenario: 今日已挑战
- **WHEN** 玩家今日已挑战过该地图
- **THEN** 显示提示信息

### Requirement: 每日奖励领取

成为地图保护者后可每日领取奖励：
- 检查是否是当前地图的保护者
- 检查今日奖励是否已领取
- 发放对应的奖励物品

#### Scenario: 领取奖励成功
- **WHEN** 玩家是该地图保护者且今日奖励未领取
- **THEN** 发放奖励，标记奖励已领取

#### Scenario: 不是保护者
- **WHEN** 玩家不是该地图保护者
- **THEN** 显示提示信息

#### Scenario: 今日已领取
- **WHEN** 玩家今日已领取过奖励
- **THEN** 显示提示信息

### Requirement: 挑战者数据

每个地图应有对应的挑战者配置：
- 挑战者名称
- 挑战者等级
- 挑战者战斗力
- 挑战者生命值

#### Scenario: 进入挑战战斗
- **WHEN** 玩家选择挑战
- **THEN** 使用该地图的挑战者数据创建战斗
