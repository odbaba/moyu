# 大地图系统 - 验证清单

## 数据验证
- [ ] 所有地点都有唯一ID
- [ ] 地点名称可以重复但ID不同
- [ ] 所有地点都有x和y坐标
- [ ] 地点坐标在合理范围内
- [ ] 每个地点最多有8个相邻地点
- [ ] 所有连接的地点都存在
- [ ] 没有重复的连接
- [ ] 连接关系与地点坐标相对应
- [ ] 地点的相对位置符合八个方向（东/南/西/北/东北/东南/西北/西南）

## 功能验证
- [ ] 大地图能正确打开和关闭
- [ ] 地图上显示所有游戏地点
- [ ] 重复名称的地点都正确显示
- [ ] 所有相邻地点之间都有直线连接
- [ ] 连接线清晰可见
- [ ] 连接线在地点下方绘制
- [ ] 拖拽功能流畅
- [ ] 拖拽有边界限制
- [ ] 当前位置有特殊高亮效果
- [ ] 高亮效果明显
- [ ] 点击地点可以正确移动
- [ ] 点击后地图关闭
- [ ] 关闭按钮功能正常
- [ ] ESC键可以关闭地图
- [ ] 打开地图时自动定位到当前位置
- [ ] 当前位置在地图视野中心
- [ ] 在触摸设备上也能正常拖拽

## 性能和体验验证
- [ ] 地图加载时间 < 1秒
- [ ] 拖拽操作无明显卡顿
- [ ] 地点名称清晰可读
- [ ] 地点名称不重叠
- [ ] 在不同屏幕尺寸上都能正常显示
- [ ] 地图显示美观
