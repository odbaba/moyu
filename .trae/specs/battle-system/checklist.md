# 战斗系统 - 验证检查清单

## 功能验证检查点
- [ ] 检查点 1: 战斗页面布局正确显示（敌人九宫格、玩家九宫格、战斗日志）
- [ ] 检查点 2: 角色卡片正确显示角色名、生命条、蓝条
- [ ] 检查点 3: 普攻能正常释放并造成正确伤害
- [ ] 检查点 4: 技能能正常释放、消耗蓝量并造成正确伤害
- [ ] 检查点 5: 蓝量不足时技能按钮禁用
- [ ] 检查点 6: 战斗回合制正常工作（玩家→敌人轮流行动）
- [ ] 检查点 7: 玩家回合时显示普攻和技能按钮
- [ ] 检查点 8: 战斗日志正确记录回合数和行动
- [ ] 检查点 9: 攻击时有角色撞击目标的动画
- [ ] 检查点 10: 伤害数字正确显示（-xx）
- [ ] 检查点 11: 敌人生命值为0时从页面消失
- [ ] 检查点 12: 所有敌人阵亡时显示战斗胜利
- [ ] 检查点 13: 玩家生命值为0时显示战斗失败

## 代码质量检查点
- [ ] 检查点 14: 所有新增代码都有注释
- [ ] 检查点 15: 代码风格与现有项目一致
- [ ] 检查点 16: TypeScript 类型定义完整，无类型错误
- [ ] 检查点 17: 组件结构清晰，职责分离合理
- [ ] 检查点 18: 没有引入不必要的依赖
