# Checklist

## 类型定义
- [x] PetType 类型定义包含所有幻兽类型（攻防型、调皮鬼、吉鲁猪、奇异兽、圣天使、守护、年猪）
- [x] PetQuality 类型定义包含所有品质（普通、良品、上品、精品、极品）
- [x] Pet 接口包含所有必要属性（基本信息、战斗属性、成长属性、评分属性等）

## 幻兽入口
- [x] 首页标题模块最左侧有"幻兽"按钮
- [x] 点击"幻兽"按钮可打开幻兽页面

## 出战栏
- [x] 出战栏显示在页面顶部
- [x] 可显示两个出战幻兽位置
- [x] 出战幻兽显示头像、生命值条、经验值条
- [x] 未出战位置显示空状态
- [x] 点击"召回"按钮可召回幻兽
- [x] 点击"合体/解体"按钮显示提示消息

## 幻兽列表
- [x] 列表显示在出战栏下方
- [x] 以垂直列表形式展示
- [x] 每项显示幻兽名称、等级、品质
- [x] 点击幻兽可打开详情弹窗

## 幻兽详情弹窗
- [x] 弹窗显示完整的属性信息表格
- [x] 表格包含名字、类型、品质、等级
- [x] 表格包含生命、经验、攻击、防御
- [x] 表格包含各项成长率和评分
- [x] 表格包含初始属性和评分
- [x] 表格包含罕见度和转世次数

## 移动端适配
- [x] 幻兽页面在移动端正常显示
- [x] 出战栏在一行内显示两个位置
- [x] 列表项适配手机屏幕宽度
- [x] 详情弹窗适配手机屏幕
