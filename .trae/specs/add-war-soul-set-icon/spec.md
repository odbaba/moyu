# 战魂套装图标显示功能 Spec

## Why
当前角色页面中，当玩家集齐战魂套装时没有直观的视觉提示。用户需要在装备模块右上角显示套装图标，点击后显示套装效果的详细信息，帮助玩家了解当前激活的套装效果。

## What Changes
- 在 `EquipmentDisplay` 组件中添加战魂套装图标显示功能
- 当全身6件装备都有战魂（任意类型）时，显示战魂套装图标
- 当全身6件装备都是天魂时，显示天魂套装图标
- 当全身6件装备都是地魂时，显示地魂套装图标
- 点击图标显示悬浮提示，包含套装名称、等级和效果描述
- **同时满足多个套装条件时，同时显示多个图标**

## Impact
- Affected code:
  - `src/components/character/EquipmentDisplay.tsx`（添加套装图标组件）
  - `src/components/character/character.css`（添加套装图标样式）
  - `src/utils/combatPower.ts`（复用现有套装检测函数）

## ADDED Requirements

### Requirement: 战魂套装图标显示
系统 SHALL 在装备模块右上角显示战魂套装图标。

#### Scenario: 战魂套装激活时显示图标
- **WHEN** 所有6件装备都有战魂属性（任意类型）
- **AND** 战魂系统已开启
- **THEN** 在装备模块右上角显示战魂套装图标
- **AND** 图标使用紫色/金色标识

#### Scenario: 战魂套装悬浮提示
- **WHEN** 玩家点击战魂套装图标
- **THEN** 显示悬浮提示内容：
  - 第一行：战魂套装X级
  - 第二行：全身装备都有战魂属性所激发出来的强大力量，使得人物战斗力提高X%。当前提高X战斗力

### Requirement: 天魂套装图标显示
系统 SHALL 在装备模块右上角显示天魂套装图标。

#### Scenario: 天魂套装激活时显示图标
- **WHEN** 所有6件装备都是天魂（soulType = WarSoulType.TIAN_HUN）
- **AND** 战魂系统已开启
- **THEN** 在装备模块右上角显示天魂套装图标
- **AND** 图标使用蓝色标识

#### Scenario: 天魂套装悬浮提示
- **WHEN** 玩家点击天魂套装图标
- **THEN** 显示悬浮提示内容：
  - 第一行：天魂套装X级
  - 第二行：全身装备都有天魂战魂而产生的神圣力量，使得战斗中所有敌人的战斗力下降X%

### Requirement: 地魂套装图标显示
系统 SHALL 在装备模块右上角显示地魂套装图标。

#### Scenario: 地魂套装激活时显示图标
- **WHEN** 所有6件装备都是地魂（soulType = WarSoulType.DI_HUN）
- **AND** 战魂系统已开启
- **THEN** 在装备模块右上角显示地魂套装图标
- **AND** 图标使用黑色/深色标识

#### Scenario: 地魂套装悬浮提示
- **WHEN** 玩家点击地魂套装图标
- **THEN** 显示悬浮提示内容：
  - 第一行：地魂套装X级
  - 第二行：全身装备都有地魂战魂而产生的神圣力量，使得战斗中所有敌人的生命值减少X%

### Requirement: 套装图标位置和样式
系统 SHALL 在装备模块右上角正确显示套装图标。

#### Scenario: 图标位置
- **WHEN** 套装激活时
- **THEN** 图标显示在装备模块右上角
- **AND** 图标不遮挡装备信息
- **AND** 图标大小适中，易于点击

#### Scenario: 无套装时不显示图标
- **WHEN** 没有激活任何战魂套装
- **THEN** 不显示任何套装图标

### Requirement: 多套装同时显示
系统 SHALL 同时显示多个激活的套装图标。

#### Scenario: 天魂套装同时显示战魂套装图标
- **WHEN** 同时满足天魂套装条件（6件都是天魂）
- **AND** 同时满足战魂套装条件（6件都有战魂）
- **THEN** 同时显示天魂套装图标和战魂套装图标
- **AND** 两个图标并排显示在右上角

#### Scenario: 地魂套装同时显示战魂套装图标
- **WHEN** 同时满足地魂套装条件（6件都是地魂）
- **AND** 同时满足战魂套装条件（6件都有战魂）
- **THEN** 同时显示地魂套装图标和战魂套装图标
- **AND** 两个图标并排显示在右上角

#### Scenario: 三个套装条件同时满足
- **WHEN** 同时满足天魂、地魂、战魂套装条件（理论上不可能，因为天魂和地魂互斥）
- **THEN** 显示所有激活的套装图标

## MODIFIED Requirements

## REMOVED Requirements
