# 角色信息页面 - 产品需求文档

## 概述
- **摘要**: 开发一个功能完整的角色信息页面，用于展示玩家角色的详细信息、装备属性和综合战斗力计算。
- **目的**: 为玩家提供一个直观的界面来查看和管理角色信息，包括核心属性、装备展示和战斗力详细计算。
- **目标用户**: 游戏玩家

## 目标
- 实现完整的角色属性展示
- 实现装备展示和详情弹窗
- 实现战斗力计算和详细组成展示
- 提供流畅的用户体验和响应式设计

## 非目标（超出范围）
- 不实现装备更换功能
- 不实现属性修改功能
- 不实现角色升级功能

## 背景与上下文
- 项目已有首页和战斗页面模块
- 入口在右下角菜单中
- 需要创建新的 `character` 模块目录
- 优先保障手机端用户体验

## 功能需求

### FR-1: 人物信息展示模块
- 显示核心属性：玩家名、等级、爵位、军衔、生命值、体力值、经验值、攻击力（最小值-最大值）、防御力、闪避率、幸运值、综合战斗力
- 实现"详细"按钮功能，点击后展开战斗力组成详情弹窗
- 战斗力计算组成包括：
  * 人物等级贡献：等级×1点战斗力
  * 装备基础贡献：装备数量×1点战斗力
  * 装备品质贡献：根据装备品质计算（白品+1、良品+2、上品+3、精品+4、极品+5）
  * 魔魂等级贡献：根据装备魔魂等级计算
  * 装备洞数贡献：根据可镶嵌宝石数量计算
  * 军衔加成：根据军衔等级计算
  * 爵位加成：根据爵位等级计算

### FR-2: 装备展示模块
- 展示装备类型：武器、衣服、战鞋、手镯、项链、头盔
- 实现装备弹窗功能：
  * 点击任意装备弹出装备详情窗口
  * 支持点击弹窗关闭按钮或点击弹窗外部区域关闭弹窗
- 装备信息内容规范：
  * 装备名称生成规则：`${装备品质}${装备名称}+${装备魔魂等级}`
  * 装备品质等级：白品、良品、上品、精品、极品（按顺序对应1-5点战斗力加成）
  * 魔魂等级规则：最高+12级，每级追加装备基本属性的10%攻击或防御；全套装备魔魂等级一致时额外增加对应数值的战斗力（如全套+9则额外+9战斗力）
  * 显示属性：装备使用等级、攻击（最小值-最大值）、追加攻击（最小值-最大值）、防御、追加防御、可镶嵌宝石数量（1-3个）、宝石属性
  * 属性显示规则：武器/手镯/项链仅显示攻击和追加攻击属性；衣服/战鞋/头盔仅显示防御和追加防御属性

### FR-3: 页面入口
- 在右下角菜单中添加"角色信息"按钮
- 点击按钮后显示角色信息页面
- 提供关闭角色信息页面的功能

## 非功能需求

### NFR-1: 界面设计
- 页面布局清晰合理，信息层级分明
- 响应式设计，适配不同屏幕尺寸
- 优先保障手机端用户体验

### NFR-2: 交互体验
- 交互操作流畅，弹窗显示/隐藏有过渡效果
- 战斗计算实时更新，确保数据准确性

### NFR-3: 代码质量
- 代码结构清晰，组件化开发，便于维护和扩展
- 遵循项目现有代码风格

## 约束
- **技术**: React + TypeScript, Vite
- **架构**: 必须创建新的 `components/character` 模块目录
- **样式**: 与现有项目风格保持一致

## 假设
- 角色和装备数据将通过模拟数据提供
- 战斗力计算逻辑按照需求文档中的规则实现
- 所有UI组件将按照现有组件风格实现

## 验收标准

- **Given**: 用户在游戏主界面
- **When**: 点击右下角菜单中的"角色信息"按钮
- **Then**: 显示角色信息页面
- **Verification**: `programmatic`

### AC-2: 人物信息完整展示
- **Given**: 角色信息页面已打开
- **When**: 查看人物信息区域
- **Then**: 显示所有核心属性：玩家名、等级、爵位、军衔、生命值、体力值、经验值、攻击力、防御力、闪避率、幸运值、综合战斗力
- **Verification**: `human-judgment`

### AC-3: 战斗力详情弹窗功能
- **Given**: 角色信息页面已打开
- **When**: 点击"详细"按钮
- **Then**: 显示战斗力组成详情弹窗，包含所有计算项
- **Verification**: `human-judgment`

### AC-4: 装备展示正确
- **Given**: 角色信息页面已打开
- **When**: 查看装备区域
- **Then**: 显示6种装备：武器、衣服、战鞋、手镯、项链、头盔
- **Verification**: `human-judgment`

### AC-5: 装备详情弹窗功能
- **Given**: 角色信息页面已打开
- **When**: 点击任意装备
- **Then**: 弹出装备详情窗口，显示完整装备信息

- **When**: 计算综合战斗力
- **Then**: 战斗力按照指定规则计算，结果准确
- **Verification**: `programmatic`

- **Given**: 在不同尺寸的设备上访问
- **When**: 查看角色信息页面
- **Then**: 页面布局自适应，手机端体验良好
- **Verification**: `human-judgment`

### AC-10: 页面关闭功能
- **Given**: 角色信息页面已打开
- **When**: 点击关闭按钮
- **Then**: 角色信息页面关闭，返回到游戏主界面
- **Verification**: `programmatic`
