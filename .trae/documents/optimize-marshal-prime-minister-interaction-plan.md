# 元帅和首相交互逻辑优化计划

## 概述

本计划旨在优化元帅和首相NPC的交互逻辑，使其与军衔和爵位模块更好地配合，参考 `reference/docs/元帅与首相交互逻辑文档.md` 和 `reference/docs/scripts_analysis/14_NPC系统.md` 文档。

## 当前实现情况分析

### 元帅 NPC（npc_marshal）
**当前选项：**
1. 领取军饷 - 周日领取魔石奖励 ✅
2. 战功查询 - 查看当前战功和晋升需求 ✅
3. 军情查询 - 查看各等级BOSS位置 ✅
4. 关于军衔 - 查看军衔系统说明 ✅

**缺失功能：**
- "没事"选项（关闭对话）
- 少将以上额外获得"高级斗志抑扬"

### 首相 NPC（npc_prime_minister）
**当前选项：**
1. 关于爵位 - 查看爵位系统说明 ✅
2. 交易 - 打开交易界面（开发中）⚠️
3. 领取奖励 - 领取爵位奖励 ✅

**缺失功能：**
- 捐献金币选项
- 功勋查询选项
- 关于国王的消息选项
- "没事"选项（关闭对话）

## 优化目标

### 一、元帅 NPC 优化

#### 1.1 添加"没事"选项
- 在选项列表末尾添加"没事"选项
- actionType: 'close'
- 点击后关闭NPC对话框

#### 1.2 少将以上额外奖励
- 当军衔等级 ≥ 7（少将及以上）时，领取军饷额外获得"高级斗志抑扬"
- 需要在 `militaryRankUtils.ts` 的 `claimMilitaryPay` 函数中已有实现
- 需要在 `App.tsx` 中处理物品添加逻辑

#### 1.3 军情查询优化
- 当前已实现根据已刷新BOSS动态显示
- 保持现有实现

### 二、首相 NPC 优化

#### 2.1 添加"捐献金币"选项
- 允许玩家捐献金币获得功勋
- 兑换比例：每750,000金币 = 1功勋
- 需要创建捐献界面或使用确认弹窗

#### 2.2 添加"功勋查询"选项
- 显示当前功勋和爵位信息
- 显示晋升所需功勋
- 显示晋升进度

#### 2.3 添加"关于国王的消息"选项
- 根据国王是否已救出显示不同内容
- 未救出：显示国王被俘虏的消息
- 已救出：显示国王回来的消息

#### 2.4 调整选项顺序
按照参考文档的顺序：
1. 捐献金币
2. 功勋查询
3. 关于国王的消息
4. 关于爵位
5. 没事

#### 2.5 移除"交易"选项
- 参考文档中没有交易选项
- 交易系统仍在开发中，暂时移除

### 三、军衔和爵位模块配合优化

#### 3.1 战斗胜利后自动获得战功和功勋
- 击败BOSS：获得1000战功 + 根据BOSS等级获得功勋
- 击败冰雪巨人：获得10000战功
- 在 `handleBattleEnd` 中添加逻辑

#### 3.2 自动晋升
- 战功达到要求自动晋升军衔
- 功勋达到要求自动晋升爵位
- 使用 `gainBattleExpAndPromote` 和 `gainMeritAndPromote` 函数

#### 3.3 战斗力加成计算
- 军衔战斗力加成：使用 `getMilitaryRankCombatPowerBonus`
- 爵位战斗力加成：使用爵位配置中的 `combatPowerBonus`
- 在 `combatPower.ts` 中整合计算
