# 修改怪物攻击力定义计划

## 需求说明

**当前问题**：怪物的攻击力在最小攻击力-最大攻击力之间浮动，这种表述不准确。

**正确理解**：

* 怪物本身有固定的最小攻击力和最大攻击力属性

* 只有在**发动普通攻击造成伤害时**，才会在最小攻击力-最大攻击力之间随机取一个值

## 影响范围分析

### 当前代码结构

1. **`MonsterTemplate`** **和** **`Monster`** **接口**：已正确定义 `attackMin` 和 `attackMax`
2. **`EnemyData`** **接口**：当前只有一个 `attack` 属性，需要修改
3. **战斗逻辑**：`calculateBaseDamage` 函数已正确实现随机取值逻辑

## 详细修改步骤

### 步骤 1：修改 `EnemyData` 接口 (types/index.ts)

**位置**：第 505-514 行

**修改内容**：

```typescript
// 修改前
export interface EnemyData {
  id: string;
  name: string;
  level?: number;
  combatPower?: number;
  maxHp: number;
  attack: number;  // 单一攻击力
  defense: number;
  description?: string;
}

// 修改后
export interface EnemyData {
  id: string;
  name: string;
  level?: number;
  combatPower?: number;
  maxHp: number;
  attackMin: number;  // 最小攻击力
  attackMax: number;  // 最大攻击力
  defense: number;
  description?: string;
}
```

### 步骤 2：修改 `generateEnemiesForBattle` 函数 (utils/monsterUtils.ts)

**位置**：第 112-157 行

**修改内容**：

* 删除计算平均攻击力的逻辑

* 直接使用怪物的 `attackMin` 和 `attackMax`，并应用随机变化

```typescript
// 修改前
const baseAttack = (monster.attackMin + monster.attackMax) / 2;
const attack = Math.round(baseAttack * variationFactor);

// 修改后
const attackMin = Math.round(monster.attackMin * variationFactor);
const attackMax = Math.round(monster.attackMax * variationFactor);

// EnemyData 对象中
attackMin: attackMin,
attackMax: attackMax,
```
