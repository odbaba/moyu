# 物品模块统一化重构计划

## 一、问题分析

### 1. 当前物品生成存在的问题

#### 1.1 抽奖系统 (lotterySystem.ts)
- **ID格式不统一**：使用 `lottery_equipment_${Date.now()}_${random}` 格式
- **品质参数错误**：`generateLotteryEquipment` 函数的 `quality` 参数默认为 0，不符合奖品等级要求
- **缺少属性**：没有设置魔魂等级和宝石孔
- **装备类型固定**：没有随机选择装备类型

#### 1.2 战利品系统 (lootUtils.ts)
- **ID格式不统一**：使用 `${prefix}_${Date.now()}_${Math.random()}` 格式
- **与inventoryData不一致**：ID格式与 inventoryData.ts 中的物品ID格式不同

#### 1.3 inventoryData.ts
- **ID格式固定**：使用 `weapon_lv1`, `helmet_lv10` 等固定格式
- **createEquipment函数**：已存在装备生成函数，但没有统一的ID生成规则

### 1.4 商店系统 (shopData.ts)
- **物品ID引用**：引用 inventoryData.ts 中的物品ID
- **数据一致性**：相对较好，但需要确保与新的统一模块兼容

## 二、重构目标

创建一个统一的物品工厂模块，提供：
1. 统一的物品ID生成规则
2. 统一的物品创建接口
3. 所有模块（抽奖、战利品、商店等）都使用这个公共模块

## 三、实施方案

### 步骤1：创建统一的物品工厂模块

**文件路径**： `src/utils/itemFactory.ts`

**功能设计**：
```typescript
// 物品ID生成规则
export function generateItemId(type: string, subtype?: string): string;

// 装备创建工厂
export function createEquipmentItem(config: {
  equipmentType: EquipmentType;
  level: number;
  quality: number;
  magicSoulLevel?: number;
  gemSlots?: number;
}): EquipmentItem;

// 消耗品创建工厂
export function createConsumableItem(config: {
  id: string;
  name: string;
  quantity?: number;
}): InventoryItem;

// 宝石创建工厂
export function createGemItem(config: {
  id: string;
  name: string;
  quantity?: number;
}): InventoryItem;

// 特殊道具创建工厂
export function createSpecialItem(config: {
  id: string;
  name: string;
  quantity?: number;
}): InventoryItem;

// 复制物品模板（用于战利品等场景）
export function cloneItem(item: InventoryItem): InventoryItem;
```

### 步骤2：定义统一的ID生成规则

**ID格式规范**：
- 装备：`equip_{type}_{level}_q{quality}_{timestamp}` （例： `equip_weapon_50_q4_1234567890`）
- 消耗品：`consumable_{id}` （例： `consumable_manjingyanqiu`）
- 宝石：`gem_{id}` （例： `gem_linghunjingshi`）
- 特殊道具：`special_{id}` （例： `special_yueguangbaohe`）

### 步骤3：重构 lotterySystem.ts

**修改内容**：
1. 导入 `itemFactory` 模块
2. 修改 `generateLotteryEquipment` 函数：
   - 使用 `createEquipmentItem` 创建装备
   - 根据奖品等级设置正确的品质（极品=4，高级=4，中级=4，普通=3）
   - 随机选择装备类型
   - 设置魔魂等级和宝石孔
3. 修改奖品创建逻辑：
   - 极品装备：品质4，魔魂等级9，宝石孔2
   - 高级装备：品质4，魔魂等级12，宝石孔1
   - 中级装备：品质4，魔魂等级0，宝石孔0
   - 普通装备：品质3，魔魂等级0-8随机，宝石孔0

### 步骤4：重构 lootUtils.ts

**修改内容**：
1. 导入 `itemFactory` 模块
2. 修改 `generateRandomEquipment` 函数：
   - 使用 `createEquipmentItem` 创建装备
   - 使用统一的ID生成规则
3. 修改 `cloneItemTemplate` 函数：
   - 使用 `cloneItem` 函数

### 步骤5：更新 inventoryData.ts

**修改内容**：
1. 导出 `createEquipment` 函数供 `itemFactory` 使用
2. 确保所有物品数据与新的ID格式兼容
3. 添加物品模板导出（供战利品系统使用）

### 步骤6：验证和测试

**测试内容**：
1. 抽奖系统生成的物品ID格式正确
2. 战利品系统生成的物品ID格式正确
3. 商店购买的物品ID格式正确
4. 所有物品属性完整且一致

## 四、文件修改清单

### 新增文件
- `src/utils/itemFactory.ts` - 统一的物品工厂模块

### 修改文件
- `src/utils/lotterySystem.ts` - 使用统一的物品工厂
- `src/utils/lootUtils.ts` - 使用统一的物品工厂
- `src/data/inventoryData.ts` - 导出物品模板和工具函数

### 无需修改

## 五、实施顺序

1. **创建 itemFactory.ts**（核心模块）
2. **修改 inventoryData.ts**（导出必要函数）
3. **重构 lotterySystem.ts**（使用新模块）
4. **重构 lootUtils.ts**（使用新模块）
5. **测试验证**（确保所有功能正常）

## 六、预期效果

### 统一性
- 所有物品使用统一的ID生成规则
- 所有物品属性结构一致
- 物品创建接口统一

### 可维护性
- 新增物品类型只需修改一个地方
- 物品生成逻辑集中管理
- 减少代码重复

### 扩展性
- 易于添加新的物品创建方法
- 支持未来更多的物品来源（如任务奖励、活动奖励等）
