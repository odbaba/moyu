# 装备精炼功能 - 宝石镶嵌与摘除功能修复计划

## 问题分析

### 问题1：无法选择可镶嵌宝石
- **原因**：`EquipmentRefineModal.tsx` 第103-107行的 `availableGems` 过滤器只包含 `gemType === 'enhance'`、`gemSubType === 'openHole'` 或 `gemSubType === 'soul'` 的宝石
- **遗漏**：可镶嵌宝石（中级战斗力石、高级战斗力石、中级经验石、高级经验石）的 `gemType` 和 `gemSubType` 都是 `'embed'`，但过滤器没有包含 `'embed'` 类型
- **解决方案**：修改过滤器，增加对 `gemType === 'embed'` 或 `gemSubType === 'embed'` 的支持

### 问题2：摘除宝石按钮问题
- **现状检查**：代码中已有 `handleRemoveEmbeddedGem` 函数和对应的UI（点击已镶嵌宝石可摘除）
- **待确认**：需要验证摘除功能是否完整正确实现

## 修改计划

### 步骤1：修改 `availableGems` 过滤器
- 文件：`d:\life\code\moyu\src\components\common\EquipmentRefineModal.tsx`
- 位置：第103-107行
- 修改内容：在过滤器中增加 `gemType === 'embed'` 条件

**当前代码：**
```typescript
const availableGems = useMemo(() => {
  return inventoryGems.filter(item =>
    item.gemType === 'enhance' || item.gemSubType === 'openHole' || item.gemSubType === 'soul'
  );
}, [inventoryGems]);
```

**修改为：**
```typescript
const availableGems = useMemo(() => {
  return inventoryGems.filter(item =>
    item.gemType === 'enhance' || item.gemType === 'embed' ||
    item.gemSubType === 'openHole' || item.gemSubType === 'soul' || item.gemSubType === 'embed'
  );
}, [inventoryGems]);
```
