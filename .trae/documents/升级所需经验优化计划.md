# 升级所需经验优化计划

> **注意**：此计划已完成。最终实现使用了 `preCalculateMaxExpTable` 预计算表方案，比原计划更优。`calculateNextLevelMaxExp` 函数已被删除，所有经验计算都使用 `MAX_EXP_TABLE` 预计算表。

## 问题分析

### 参考代码的升级逻辑（DefineSprite_932/frame_1/DoAction.as）

根据参考代码第 680 行和 401-416 行，升级所需经验的逻辑如下：

```actionscript
// 初始化
mjy = 10;  // 1级升2级需要10经验

// 升级逻辑（第401-416行）
if(dj < 20)
{
   mjy = Math.round(mjy * 1.2);  // 20级前，每次升级所需经验是上一级的1.2倍
}
else if(dj <= 50)
{
   mjy = Math.round(mjy * 1.1);  // 20-50级，每次升级所需经验是上一级的1.1倍
}
else
{
   mjy += hun;  // 50级以上，每次升级增加固定值
}
if(dj == 50 || dj == 132)
{
   hun = Math.round(mjy * 0.2);  // 在50级和132级时，计算 hun 值
}
```

**升级所需经验规则：**
1. **1级升2级**：需要 10 经验
2. **2-20级**：每次升级所需经验 = 上一级所需经验 × 1.2
3. **20-50级**：每次升级所需经验 = 上一级所需经验 × 1.1
4. **50级以上**：每次升级所需经验 = 上一级所需经验 + 固定值（该固定值在50级时计算，为50级所需经验的20%）

### 当前实现的问题

**当前代码（App.tsx 第940行）：**
```typescript
// 计算下一级所需经验（可根据实际需求调整公式）
maxExp = Math.floor(1000000 * Math.pow(1.1, level - 1));
```

**问题：**
1. 使用固定基数 1000000，而不是从 10 开始
2. 使用指数增长公式，而不是递归增长
3. 没有区分不同等级段的不同增长率
4. 与参考代码的逻辑完全不符

## 修复方案

### 方案1：创建升级所需经验计算函数

**修改文件：** `src/utils/attributeCalculator.ts`

**新增函数：**
```typescript
/**
 * 计算升级所需经验
 * @param currentLevel 当前等级
 * @param currentMaxExp 当前升级所需经验（用于递归计算）
 * @returns 升级所需经验
 */
export function calculateMaxExp(currentLevel: number, currentMaxExp?: number): number {
  // 1级升2级需要10经验
  if (currentLevel === 1) {
    return 10;
  }
  
  // 如果没有提供当前所需经验，递归计算
  if (currentMaxExp === undefined) {
    let maxExp = 10;
    for (let level = 1; level < currentLevel; level++) {
      maxExp = calculateNextLevelMaxExp(level, maxExp);
    }
    return maxExp;
  }
  
  return currentMaxExp;
}

/**
 * 计算下一级所需经验
 * @param currentLevel 当前等级
 * @param currentMaxExp 当前升级所需经验
 * @returns 下一级升级所需经验
 */
export function calculateNextLevelMaxExp(currentLevel: number, currentMaxExp: number): number {
  let hun = 0;
  
  // 20级前，每次升级所需经验是上一级的1.2倍
  if (currentLevel < 20) {
    return Math.round(currentMaxExp * 1.2);
  }
  // 20-50级，每次升级所需经验是上一级的1.1倍
  else if (currentLevel <= 50) {
    return Math.round(currentMaxExp * 1.1);
  }
  // 50级以上，每次升级增加固定值
  else {
    // 在50级时计算固定值（50级所需经验的20%）
    if (currentLevel === 50) {
      hun = Math.round(currentMaxExp * 0.2);
    }
    return currentMaxExp + hun;
  }
}
```

### 方案2：修改 checkAndLevelUp 函数

**修改文件：** `src/App.tsx`

**修改内容：**
```typescript
import { calculateNextLevelMaxExp } from './utils/attributeCalculator';

const checkAndLevelUp = useCallback((
  currentExp: number,
  maxExp: number,
  currentLevel: number
): { newExp: number; newMaxExp: number; newLevel: number; leveledUp: boolean } => {
  let exp = currentExp;
  let level = currentLevel;
  let currentMaxExp = maxExp;
  let leveledUp = false;
  
  // 检查是否可以升级（经验值溢出）
  while (exp >= currentMaxExp && level < 125) { // 最高等级125
    exp -= currentMaxExp;
    level++;
    leveledUp = true;
    
    // 计算下一级所需经验（使用参考代码的逻辑）
    currentMaxExp = calculateNextLevelMaxExp(level - 1, currentMaxExp);
  }
  
  return { newExp: exp, newMaxExp: currentMaxExp, newLevel: level, leveledUp };
}, []);
```

### 方案4：添加升级所需经验预计算表（可选优化）

为了提高性能，可以预计算所有等级的升级所需经验：

**修改文件：** `src/utils/attributeCalculator.ts`

**新增函数：**
```typescript
/**
 * 预计算所有等级的升级所需经验
 * @param maxLevel 最高等级（默认125）
 * @returns 等级 -> 升级所需经验的映射表
 */
export function preCalculateMaxExpTable(maxLevel: number = 125): Map<number, number> {
  const table = new Map<number, number>();
  let maxExp = 10; // 1级升2级需要10经验
  let hun = 0;
  
  table.set(1, maxExp);
  
  for (let level = 2; level <= maxLevel; level++) {
    // 20级前，每次升级所需经验是上一级的1.2倍
    if (level <= 20) {
      maxExp = Math.round(maxExp * 1.2);
    }
    // 20-50级，每次升级所需经验是上一级的1.1倍
    else if (level <= 50) {
      maxExp = Math.round(maxExp * 1.1);
    }
    // 50级以上，每次升级增加固定值
    else {
      // 在50级时计算固定值（50级所需经验的20%）
      if (level === 51) {
        hun = Math.round(maxExp * 0.2);
      }
      maxExp += hun;
    }
    
    table.set(level, maxExp);
  }
  
  return table;
}

// 导出预计算表
export const MAX_EXP_TABLE = preCalculateMaxExpTable();
```

## 注意事项

1. **等级上限**：参考代码中最高等级是 132 级，当前实现是 125 级，需要确认是否需要调整
2. **经验值保留**：升级后，多余的经验值应该保留到下一级
3. **满级处理**：达到最高等级后，经验值应该清零或转换为经验球
4. **性能优化**：如果频繁计算升级所需经验，建议使用预计算表
