# 物品系统重构计划

## 一、任务概述

重构物品信息模块，将物品分为五大类：装备类、消耗品类、技能书类、宝石类、特殊道具类，并将reference文档中的所有物品录入系统。

## 二、当前状态分析

### 现有物品类型 (types/index.ts)

* `consumable` - 消耗品

* `material` - 材料

* `equipment` - 装备

* `quest` - 任务物品

* `other` - 其他

### 需要新增的类型

* `skillbook` - 技能书类

* `gem` - 宝石类

* `special` - 特殊道具类

## 四、物品属性设计

### 装备类属性

```typescript
interface EquipmentItem extends InventoryItem {
  type: 'equipment';
  equipmentType: 'weapon' | 'helmet' | 'armor' | 'shoes' | 'bracelet' | 'necklace';
  useLevel: number;        // 使用等级
  quality: number;         // 品质 0-4
  magicSoulLevel: number;  // 魔魂等级 0-12
  holeCount: number;       // 宝石洞数量 0-2
  attackMin?: number;      // 最小攻击
  attackMax?: number;      // 最大攻击
  defense?: number;        // 防御
}
```

### 技能书类属性

```typescript
interface SkillBookItem extends InventoryItem {
  type: 'skillbook';
  skillName: string;       // 技能名称
  skillType: 'attack' | 'buff';  // 技能类型
  skillEffect: string;     // 技能效果描述
  damagePercent?: number;  // 伤害百分比
}
```

### 宝石类属性

```typescript
interface GemItem extends InventoryItem {
  type: 'gem';
  gemType: 'enhance' | 'embed';  // 强化宝石 | 镶嵌宝石
  effect: string;          // 效果描述
  successRate?: string;    // 成功率
  combatPower?: number;    // 战斗力加成
  expBonus?: number;       // 经验加成百分比
}
```

### 特殊道具类属性

```typescript
interface SpecialItem extends InventoryItem {
  type: 'special';
  specialType: 'craft' | 'gift' | 'ore';  // 打造 | 礼物 | 矿石
  effect: string;          // 效果描述
  quality?: number;        // 品质值(矿石用)
}
```
