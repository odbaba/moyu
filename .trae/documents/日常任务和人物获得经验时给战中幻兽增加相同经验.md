## 实现方案

### 方案概述

1. 创建工具函数计算带战斗力加成的经验值
2. 在日常任务完成时，给战中幻兽增加带加成的经验
3. 在幻兽研究所提高产量任务时，给战中幻兽增加带加成的经验

### 具体步骤

#### 步骤1：创建经验计算工具函数

**文件**：`src/utils/experienceUtils.ts`（新建）或修改现有文件

**功能**：

```typescript
/**
 * 计算带战斗力加成的经验值
 * 公式：实际经验 = 基础经验 × (1 + max(0, (playerCombatPower - playerLevel) × 0.05))
 * 
 * @param baseExp 基础经验值
 * @param playerCombatPower 玩家战斗力
 * @param playerLevel 玩家等级
 * @returns 加成后的经验值
 */
export function calculateCombatPowerBonusExp(
  baseExp: number,
  playerCombatPower: number,
  playerLevel: number
): number
```

**注意**：参考 [lootUtils.ts:L89](file:///d:/life/code/moyu/src/utils/lootUtils.ts#L89) 中的战斗力加成公式

```typescript
onImproveProduction={(expGained, vipGained, consumedSoulKings) => {
  // 消耗灵魂王
  const newInventory = consumeItemFromInventory(inventory, '灵魂王', consumedSoulKings);
  setInventory(newInventory);
  
  // 计算带战斗力加成的经验值
  const bonusExp = calculateCombatPowerBonusExp(expGained, character.combatPower, character.level);
  
  // 增加经验给角色（使用加成后的经验）
  setCharacter(prev => {
    const result = gainCharacterExperience(prev, bonusExp);
    
    if (result.message) {
      setInteractionLog(logs => [...logs, result.message!]);
    }
    
    return result.character;
  });
  
  // 给战中幻兽增加相同经验（带加成）
  setPets(prevPets => {
    return prevPets.map(pet => {
      if (!pet.isDeployed) {
        return pet;
      }
      
      const result = gainExperience(pet, bonusExp, character.level);
      
      if (result.message) {
        setInteractionLog(logs => [...logs, result.message!]);
      }
      
      return result.pet;
    });
  });
  
  // 增加VIP等级
  setPetInstituteState(prev => ({
    ...prev,
    productionRate: Math.min(prev.productionRate + 1, 6),
    vipLevel: Math.min(prev.vipLevel + vipGained, 10),
    canDoProductionTask: false
  }));
  setInteractionLog(prev => [...prev, `完成提高产量任务！获得经验 ${bonusExp}，VIP星级 +${vipGained}`]);
}}
```

## 注意事项

1. **只给出战幻兽**：遵循现有逻辑，只给 `isDeployed === true` 的幻兽分配经验
2. **复用现有函数**：使用 `gainExperience` 函数处理幻兽经验获取和升级
3. **战斗力加成**：

   * 公式：`实际经验 = 基础经验 × (1 + max(0, (playerCombatPower - playerLevel) × 0.05))`

   * 如果战斗力 < 等级，加成为 0（不减少经验）

   * 此加成适用于：任务经验、战斗经验等

   * **不适用于**：满经验球对玩家使用
4. **经验值相同**：战中幻兽获得的经验值与角色获得的经验值完全相同（都带战斗力加成）
5. **升级日志**：幻兽升级时输出升级提示日志
