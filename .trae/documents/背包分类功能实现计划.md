# 背包分类功能实现计划

## 需求描述
为背包增加分类筛选功能：增加分类多选框，默认全选中，只选中装备类则背包只显示装备类物品。

## 物品类型
背包物品共有以下类型（定义在 `src/types/index.ts`）：
- `consumable` - 消耗品
- `material` - 材料
- `equipment` - 装备
- `quest` - 任务物品
- `other` - 其他
- `skillbook` - 技能书
- `gem` - 宝石
- `special` - 特殊道具

## 实现步骤

### 步骤 1：修改 InventoryPage.tsx
**文件路径**：`src/components/inventory/InventoryPage.tsx`

1. 添加分类选中状态：
```typescript
const [selectedCategories, setSelectedCategories] = useState<ItemType[]>([
  'consumable', 'material', 'equipment', 'quest', 'other', 'skillbook', 'gem', 'special'
]);
```

2. 添加分类切换处理函数：
```typescript
const toggleCategory = (category: ItemType) => {
  setSelectedCategories(prev =>
    prev.includes(category)
      ? prev.filter(c => c !== category)
      : [...prev, category]
  );
};
```

3. 在 ItemGrid 上方添加分类筛选 UI（复选框列表）

4. 将 filteredItems 和 selectedCategories 传递给 ItemGrid

### 步骤 2：修改 ItemGrid.tsx
**文件路径**：`src/components/inventory/ItemGrid.tsx`

1. 更新 ItemGridProps 接口，添加 selectedCategories 属性：
```typescript
interface ItemGridProps {
  items: InventoryItem[];
  onItemClick?: (item: InventoryItem) => void;
  selectedCategories?: ItemType[];  // 新增：选中的分类列表，空数组表示全不选
}
```

2. 在 ItemGrid 组件中添加过滤逻辑：
```typescript
const filteredItems = selectedCategories && selectedCategories.length > 0
  ? items.filter(item => selectedCategories.includes(item.type))
  : items;
```

3. 使用 filteredItems 替代 items 进行渲染

- 默认全选中（显示所有类型物品）
- 当没有任何分类被选中时，显示空状态提示
- 分类筛选 UI 应在移动端也能正常显示（使用 flex-wrap）
