# 幻兽图标替换为头像显示实施计划

## 任务概述
将全局代码中的幻兽emoji图标显示替换为幻兽头像图片显示。头像图片存放在 `public/images/pet` 目录下，文件名使用幻兽类型的拼音命名。

## 当前实现分析

### 1. 当前幻兽图标显示方式
- 使用 `getPetEmoji(pet.hs_name)` 函数获取emoji图标
- 在 `src/components/common/constants.ts` 中定义了 `PET_TYPE_EMOJI` 映射表
- 所有组件都使用这个函数显示幻兽图标

### 2. 使用幻兽图标的组件列表
1. **PetListItem.tsx** - 幻兽列表项组件
2. **PetDetailModal.tsx** - 幻兽详情弹窗组件
3. **DeployedPetSlot.tsx** - 出战幻兽槽位组件
4. **PetFusionModal.tsx** - 幻兽幻化弹窗组件
5. **PetSelectModal.tsx** - 幻兽选择弹窗组件

### 3. 头像图片文件映射
| 幻兽类型 | 拼音文件名 | 文件路径 |
|---------|-----------|---------|
| 攻防型 | gongfangxing.jpg | public/images/pet/gongfangxing.jpg |

## 实施步骤

### 步骤1：创建幻兽类型到拼音的映射
**文件**: `src/components/common/constants.ts`

1. 新增 `PET_TYPE_PINYIN` 映射表，将幻兽类型映射到拼音文件名
2. 保留原有的 `PET_TYPE_EMOJI` 映射表（作为备用）

### 步骤2：创建获取幻兽头像的工具函数
**文件**: `src/components/common/utils.ts`

1. 新增 `getPetAvatar(petType: string): string` 函数
   - 根据幻兽类型返回头像图片路径
   - 使用 `PET_TYPE_PINYIN` 映射获取拼音文件名
   - 返回格式：`/images/pet/{拼音}.jpg`
   - 如果找不到对应类型，返回默认头像路径

### 步骤3：更新所有使用幻兽图标的组件
需要修改以下组件，将 `<span>{getPetEmoji(...)}</span>` 替换为 `<img src={getPetAvatar(...)} />`：

#### 3.1 PetListItem.tsx
- 位置：第92行
- 修改：将 `<span className="pet-list-emoji">{getPetEmoji(pet.hs_name)}</span>` 替换为 `<img className="pet-list-avatar-img" src={getPetAvatar(pet.hs_name)} alt={pet.hs_name} />`

#### 3.2 PetDetailModal.tsx
- 位置：第98行
- 修改：将 `<span className="pet-detail-emoji">{getPetEmoji(pet.hs_name)}</span>` 替换为 `<img className="pet-detail-avatar-img" src={getPetAvatar(pet.hs_name)} alt={pet.hs_name} />`

#### 3.3 DeployedPetSlot.tsx
- 位置：第124行
- 修改：将 `<span className="pet-emoji">{getPetEmoji(pet.hs_name)}</span>` 替换为 `<img className="pet-avatar-img" src={getPetAvatar(pet.hs_name)} alt={pet.hs_name} />`

#### 3.4 PetFusionModal.tsx
- 位置：第458行
- 修改：将 `<span className="fusion-pet-emoji">{getPetEmoji(pet.hs_name)}</span>` 替换为 `<img className="fusion-pet-avatar-img" src={getPetAvatar(pet.hs_name)} alt={pet.hs_name} />`

#### 3.5 PetSelectModal.tsx
- 位置：第143-145行
- 修改：将 `<span className="pet-select-item-emoji">{getPetEmoji(pet.hs_name)}</span>` 替换为 `<img className="pet-select-item-avatar-img" src={getPetAvatar(pet.hs_name)} alt={pet.hs_name} />`

### 步骤4：更新CSS样式
**文件**: `src/components/pet/pet.css`

为新增的图片元素添加样式：
1. `.pet-list-avatar-img` - 幻兽列表头像样式
2. `.pet-detail-avatar-img` - 幻兽详情头像样式
3. `.pet-avatar-img` - 出战幻兽头像样式
4. `.fusion-pet-avatar-img` - 幻化幻兽头像样式
5. `.pet-select-item-avatar-img` - 选择弹窗幻兽头像样式

样式要求：
- 设置合适的宽高（建议与原emoji容器大小一致）
- 使用 `object-fit: cover` 保持图片比例
- 添加圆角（可选）
- 确保图片居中显示

### 步骤5：更新导入语句
在所有修改的组件中：
1. 移除 `getPetEmoji` 的导入（如果不再使用）
2. 添加 `getPetAvatar` 的导入

## 注意事项

1. **图片路径**：使用 `/images/pet/xxx.jpg` 格式，这是相对于 `public` 目录的路径
2. **alt属性**：为图片添加 `alt={pet.hs_name}` 属性，提高可访问性
3. **备用方案**：保留 `PET_TYPE_EMOJI` 映射，以防需要回退到emoji显示
4. **样式一致性**：确保头像图片在各组件中的显示大小和位置与原emoji一致
5. **性能优化**：图片已经预加载在public目录，无需额外优化

## 测试验证

完成修改后需要验证：
1. 所有幻兽类型的头像都能正确显示
2. 头像在各组件中的显示效果正常
3. 移动端显示效果正常（优先保障手机端体验）
4. 图片加载失败时有合理的显示效果
