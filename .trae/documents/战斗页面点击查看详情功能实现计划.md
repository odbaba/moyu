# 战斗页面点击查看详情功能实现计划

## 一、需求分析

在战斗页面的九宫格中，点击角色、幻兽或怪物时，弹出对应的详情弹窗。

### 交互逻辑
- **玩家回合且已选择技能**：点击敌人 = 选择攻击目标（现有逻辑，保持不变）
- **其他情况**：点击角色/幻兽/敌人 = 查看详情（新功能）

## 四、技术细节

### 1. 点击事件处理逻辑
```typescript
const handleCharacterClick = (
  character: BattleCharacter | BattlePet,
  isEnemy: boolean
) => {
  // 如果是玩家回合且已选择技能，且点击的是敌人
  if (battleState.isPlayerTurn && battleState.selectedAction && isEnemy) {
    // 执行选择攻击目标的逻辑（现有逻辑）
    handleTargetSelect(character.id);
  } else {
    // 显示详情弹窗
    showCharacterDetail(character, isEnemy);
  }
};
```

### 2. 详情弹窗显示逻辑
```typescript
const showCharacterDetail = (
  character: BattleCharacter | BattlePet,
  isEnemy: boolean
) => {
  if (isBattlePet(character)) {
    // 幻兽详情
    const pet = deployedPets.find(p => p.id === (character as BattlePet).petId);
    if (pet) {
      setSelectedPet(pet);
      setDetailType('pet');
      setShowDetailModal(true);
    }
  } else if (isEnemy) {
    // 敌人详情
    setSelectedCharacter(character as BattleCharacter);
    setDetailType('enemy');
    setShowDetailModal(true);
  } else if ((character as BattleCharacter).isPlayer) {
    // 玩家角色详情
    setSelectedCharacter(character as BattleCharacter);
    setDetailType('character');
    setShowDetailModal(true);
  }
};
```

### 3. 数据转换
- **幻兽**：需要从 `BattlePet` 转换为 `Pet` 类型，通过 `petId` 在 `deployedPets` 中查找
- **角色**：直接使用 `BattleCharacter` 数据
- **敌人**：直接使用 `BattleCharacter` 数据

## 五、注意事项

1. **遵循项目规范**：
   - 代码必须添加注释
   - 优先复用现有功能
   - 手机端优先，确保一屏能展示所有信息

2. **用户体验**：
   - 弹窗应该有明显的关闭按钮
   - 点击遮罩层可以关闭弹窗
   - 弹窗内容应该简洁明了，适合手机端查看

3. **性能优化**：
   - 避免不必要的重新渲染
   - 使用 useCallback 优化回调函数

4. **类型安全**：
   - 使用 TypeScript 类型守卫区分不同类型
   - 确保类型转换的安全性
