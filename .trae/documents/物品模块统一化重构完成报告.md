# 物品模块统一化重构完成报告

## 一、重构成果

### 1. 新增文件

#### src/utils/itemFactory.ts
**统一的物品工厂模块**，提供：
- `generateItemId()` - 统一的ID生成函数
- `createEquipmentItem()` - 装备创建工厂
- `createConsumableItem()` - 消耗品创建工厂
- `createGemItem()` - 宝石创建工厂
- `createSpecialItem()` - 特殊道具创建工厂
- `cloneItem()` - 物品复制函数
- `randomEquipmentType()` - 随机装备类型选择
- `randomMagicSoulLevel()` - 随机魔魂等级生成
- `randomGemSlots()` - 随机宝石孔生成

### 2. 修改文件

#### src/data/inventoryData.ts
**新增导出**：
- `findItemByName()` - 根据名称查找物品模板
- `findItemById()` - 根据ID查找物品模板

#### src/utils/lotterySystem.ts
**重构内容**：
- 导入 `itemFactory` 模块
- 修改 `generateLotteryEquipment()` 函数：
  - 使用 `createEquipmentItem()` 创建装备
  - 使用 `randomEquipmentType()` 随机选择装备类型
  - 使用 `randomMagicSoulLevel()` 生成魔魂等级
  - ID格式统一为：`equip_{type}_{level}_q{quality}_{timestamp}_{random}`

#### src/utils/lootUtils.ts
**重构内容**：
- 导入 `itemFactory` 模块
- 修改 `cloneItemTemplate()` 函数：
  - 使用 `cloneItem()` 复制物品
  - 删除了 `generateUniqueId()` 函数（不再需要）
  - ID格式统一为：`{type}_{timestamp}_{random}`

## 二、统一ID格式规范

### 装备类
```
equip_{type}_{level}_q{quality}_{timestamp}_{random}
示例：equip_weapon_50_q4_1234567890_abc123def
```

### 消耗品类
```
consumable_{id}_{timestamp}_{random}
示例：consumable_manjingyanqiu_1234567890_abc123def
```

### 宝石类
```
gem_{id}_{timestamp}_{random}
示例：gem_linghunjingshi_1234567890_abc123def
```

### 特殊道具类
```
special_{id}_{timestamp}_{random}
示例：special_yueguangbaohe_1234567890_abc123def
```
