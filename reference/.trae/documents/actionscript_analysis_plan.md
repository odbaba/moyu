# ActionScript代码分析计划 - 游戏元素技术文档生成

## 项目概述

本项目是一个Flash游戏（魔域1.03），包含大量ActionScript代码文件。目标是全面分析代码，提取核心游戏元素信息，生成结构化的技术文档。

## 分析范围

### 代码文件统计
- **scripts目录**：包含约200+个ActionScript文件
- **文件类型**：
  - `DoAction.as` - 主要动作脚本
  - `CLIPACTIONRECORD onClipEvent(load).as` - 剪辑事件脚本
  - `BUTTONCONDACTION on(release).as` - 按钮事件脚本

### 核心游戏元素分类

1. **角色系统（Player/Character）**
   - 玩家属性定义
   - 等级系统
   - 战斗力计算
   - 爵位系统
   - 生命值/体力值管理

2. **幻兽系统（Pet/Summon）**
   - 幻兽属性
   - 幻兽类型
   - 成长系统
   - 幻化系统

3. **物品系统（Items）**
   - 装备类：武器、头盔、衣服、战鞋、手镯、项链
   - 消耗品类：体力药、果子、经验球
   - 技能书类：星魔剑、飞天连斩等
   - 宝石类：灵魂晶石、魔魂晶石等
   - 特殊道具：月光宝盒、金矿、银矿等

4. **怪物系统（Monsters/Enemies）**
   - 普通怪物
   - BOSS怪物
   - 魔族军队
   - PK赛BOSS
   - 地图挑战者

5. **技能系统（Skills）**
   - 技能定义
   - 技能效果
   - 技能学习

6. **地图系统（Maps）**
   - 地图定义
   - 怪物分布
   - NPC分布

## 实施步骤

### 第一阶段：代码扫描与分类（预计耗时：分析阶段）

1. **扫描所有DefineSprite目录**
   - 识别带有中文名称的目录（如`DefineSprite_164_武器`）
   - 记录Sprite ID与名称的映射关系

2. **扫描frame目录**
   - 分析主时间轴代码
   - 提取全局变量和函数定义

3. **扫描按钮事件文件**
   - 提取UI交互逻辑

### 第二阶段：元素提取与分析

#### 2.1 角色系统分析
- 文件位置：`DefineSprite_446`、`frame_6`、`DefineSprite_932`
- 提取内容：
  - 基础属性（hp, mhp, tl, mtl, dj, exp等）
  - 爵位系统（jwdj, jwexp）
  - 战功系统（jx）
  - 公主亲密度（gzgx）

#### 2.2 幻兽系统分析
- 文件位置：`DefineSprite_139_空幻兽对象`、`DefineSprite_561`等
- 提取内容：
  - 幻兽属性（hp, mhp, xgj, dgj, fy等）
  - 幻兽类型（攻防型、调皮鬼、吉鲁猪等）
  - 成长率系统
  - 幻化规则

#### 2.3 物品系统分析
- 文件位置：`DefineSprite_164_武器`、`DefineSprite_37_体力药`等
- 提取内容：
  - 物品ID（myid）
  - 物品名称（names）
  - 属性参数（dj, pz, mhdj, dong等）
  - 使用效果（useitem函数）
  - 价值计算（getjbvalue, getmsvalue）

#### 2.4 怪物系统分析
- 文件位置：`DefineSprite_124_怪物对象`、`DefineSprite_135_BOSS`、`DefineSprite_118_选择怪物`
- 提取内容：
  - 怪物属性（hp, xgj, dgj, fy, gwzdl）
  - 属性成长公式
  - 掉落系统
  - 特殊效果

#### 2.5 技能系统分析
- 文件位置：`DefineSprite_23_星魔剑`等技能书相关文件
- 提取内容：
  - 技能ID和名称
  - 技能效果描述
  - 学习条件

每个文档包含以下章节：

```markdown

## 概述
[系统简介]

## 核心定义

### 元素列表

| ID | 名称 | 类型 | 来源文件 |
|----|------|------|----------|
| ... | ... | ... | ... |

## 详细属性

### [具体元素名称]

**基本信息**
- 元素ID: xxx
- 名称: xxx
- 类型: xxx

**属性参数**
| 属性名 | 类型 | 说明 | 默认值 |
|--------|------|------|--------|
| ... | ... | ... | ... |

**核心函数**
- `functionName()`: 功能描述

**代码引用**
- 文件路径: `scripts/xxx/DoAction.as`
- 关键代码行: L1-L100

**关联元素**
- 关联物品: xxx
- 关联怪物: xxx
```

## 注意事项

1. **代码引用规范**：所有提取的信息需标注源文件路径和行号
2. **属性完整性**：确保提取所有可见属性，包括隐藏属性
3. **公式记录**：记录所有计算公式（如攻击力计算、经验计算等）
4. **关联关系**：记录元素之间的关联（如掉落关系、使用关系）
5. **中文命名**：保持中文命名，便于开发团队阅读
