# 日常任务官交互逻辑文档

## 概述

日常任务官是游戏中负责每日任务系统的NPC，位于树心城。玩家可以每天与日常任务官交互，接受不同的每日任务，获得丰厚的奖励。任务系统根据游戏内的星期系统循环，每天提供不同的任务内容。

**NPC位置**：树心城  
**代码位置**：[DefineSprite_1161/frame_1/DoAction.as](../scripts/DefineSprite_1161/frame_1/DoAction.as)  
**最后更新**：2026-04-16

## 对话系统

### 主对话流程

```
玩家点击NPC
    ↓
talk() 函数
    ↓
显示问候语 + 当前任务信息
    ↓
显示三个选项：
  1. 接受任务
  2. 关于日常任务
  3. 随便问问
```

### 对话选项详解

#### 选项1：接受任务

根据当前星期执行不同的任务逻辑：

| 星期 | nowday % 7 | 任务名称 | 执行函数 |
|------|------------|---------|---------|
| 周一 | 1 | 收集宝石 | mission() → gather() |
| 周二 | 2 | 收集宝石 | mission() → gather() |
| 周三 | 3 | 训练幻兽 | mission() → 打开幻兽给予界面 |
| 周四 | 4 | 训练幻兽 | mission() → 打开幻兽给予界面 |
| 周五 | 5 | 突袭 | mission() → 传送到雪域边境 |
| 周六 | 6 | PK赛 | mission() → 传送到皇宫 |
| 周日 | 0 | 地下城 | mission() → 传送到地下城 |

#### 选项2：关于日常任务

显示任务说明文档，包括：
- 周一和周二任务：收集宝石
- 周三和周四任务：训练幻兽
- 周五任务：突袭
- 周六任务：PK赛
- 周日任务：地下城魔族将领会议

#### 选项3：随便问问

关闭对话窗口

## 每日任务详细逻辑

### 一、收集宝石任务（周一、周二）

#### 任务描述

```
据说灵魂晶石里蕴含着强大的能量，还可以用于精练武器装备以提升品质，
所以国家正在大量收集灵魂晶石。你是否愿意帮助收集一些灵魂晶石？
```

#### 任务要求计算

根据玩家等级动态计算需要收集的数量：

| 玩家等级 | 需要物品 | 数量 | 计算公式 |
|---------|---------|------|---------|
| < 100级 | 灵魂晶石 | (等级+10) / 10 向下取整 | lhjs = (_loc3_ - _loc3_ % 10) / 10 |
| 100-109级 | 灵魂王 | 2个 | lhw = 2 |
| 110-119级 | 灵魂王 | 5个 | lhw = 5 |
| ≥ 120级 | 灵魂王 | 10个 | lhw = 10 |

#### 任务奖励

**收集灵魂晶石**：
- 经验值：30000 × 灵魂晶石数量
- 功勋值：500点

**收集灵魂王**：
- 经验值：210000 × 灵魂王数量
- 功勋值：2000点

#### 执行流程

```actionscript
function gather()
{
    if(lhjs)  // 收集灵魂晶石
    {
        if(_root.beibao.usethings("灵魂晶石", lhjs))
        {
            _root.rw_bs = false;  // 标记任务已完成
            exps = 30000 * lhjs;
            _root.xinxi.have_exp(exps);  // 给予经验
            _root.xinxi.upjw(500);  // 给予功勋
        }
    }
    else if(lhw)  // 收集灵魂王
    {
        if(_root.beibao.usethings("灵魂王", lhw))
        {
            _root.rw_bs = false;
            exps = 210000 * lhw;
            _root.xinxi.have_exp(exps);
            _root.xinxi.upjw(2000);
        }
    }
}
```

#### 任务限制

- 每天只能完成一次（通过 `rw_bs` 变量控制）
- 如果当天已完成，显示提示："你今天已经做过任务了"

### 二、训练幻兽任务（周三、周四）

#### 任务描述

```
为了组织强大的军队与魔族战斗，国家军队需要扩编一支战斗力强悍幻兽队伍，
国家出了很高价钱来招收符合要求的幻兽。
```

#### 任务要求

- 幻兽类型：攻防型
- 幻兽品质：极品10星以上（品质分 ≥ 500）

#### 任务奖励

| 幻兽星级 | 品质分范围 | 奖励魔石 | 战功 |
|---------|-----------|---------|------|
| 极品10星 | 1000-1499 | 5,000 | 1,000 |
| 极品15星 | 1500-2999 | 10,000 | 1,000 |
| 极品30星 | ≥ 3000 | 50,000 | 1,000 |

#### 执行流程

```actionscript
function givebb(hs_name, hs_pz)
{
    if(hs_name == "攻防型" && hs_pz >= 500)
    {
        _root.rw_hs = false;  // 标记任务已完成
        
        if(hs_pz >= 3000)
            _root.beibao.subms(50000);  // 50,000魔石
        else if(hs_pz >= 1500)
            _root.beibao.subms(10000);  // 10,000魔石
        else if(hs_pz >= 1000)
            _root.beibao.subms(5000);   // 5,000魔石
            
        _root.xinxi.upjx(1000);  // 1,000战功
        return true;
    }
    return false;
}
```

#### 任务限制

- 每天只能完成一次（通过 `rw_hs` 变量控制）
- 如果当天已完成，显示提示："你今天已经做过任务了"

### 三、突袭任务（周五）

#### 任务描述

**未救出国王时**：
```
据探子回报，魔族大军部分已经进入到了雪域边境，趁着敌人还未站稳脚人类军队
要派遣轻骑兵前往袭击敌人。不过敌人的战斗力还是非常强，战斗肯定会非常艰苦
和危险，你是否愿意前往杀敌？
```

**已救出国王时**：
```
虽然雪域边境已经是我们收复的领地了，但还不时有魔族军队侵扰，我们要趁着
敌人还没有发觉时派遣轻骑兵前往袭击敌人，敌人不是很多，但都是精捍部队，
勇士一定要小心。
```

#### 任务要求

- 从冰宫进入雪域边境
- 消灭冰雪巨人

#### 任务奖励

- 消灭每个冰雪巨人获得大量战功

#### 执行流程

### 五、地下城任务（周日）

#### 任务描述

**未救出国王时**：
```
探子来报说，今天在魔族将领某个地下城里举行了军事会议，国家军事指挥部
并打听国王下落。地下城共有三层，只有消灭门口那队怪物后才能进入下一层，
进入到每一层都会有奖励。
```

**已救出国王时**：
```
探子来报说，今天在魔族将领某个地下城里举行了军事会议，国王已经发布悬赏
任务招募勇士前去破坏魔族会议和消灭魔族将领。
```

#### 任务要求

- 前往地下城
- 消灭各层怪物
- 破坏魔族会议

#### 任务奖励

- 消灭怪物越多，获得功勋值越高
- 每层都有奖励

#### 执行流程

```actionscript
case 0:  // 周日
    if(_root.rw_dxc)
    {
        _root.rw_dxc = false;  // 标记任务已完成
        _root.talk.closeme();
        var _loc3_ = new Sound();
        _loc3_.attachSound("传送.wav");
        _loc3_.start();
        
        if(_root.king == false)  // 未救出国王
            _root.gotoAndStop("地下城1层");
        else  // 已救出国王
            _root.gotoAndStop("地下城3层");
    }
    else
    {
        _root.alertbox("\r\r你今天已经做过任务了");
        _root.talk.closeme();
    }
    return;
```

#### 特殊逻辑

- 未救出国王：从地下城1层开始
- 已救出国王：直接传送到地下城3层
- 周六时，地下城怪物会刷新（通过 `nextday()` 函数）

## 每日重置系统

### 重置时机

每日重置发生在游戏时间进入新的一天时，由 `nextday()` 函数触发。

### 重置内容

```actionscript
function nextday()
{
    // 重置任务标记
    rw_bs = true;       // BOSS任务（收集宝石）
    rw_hs = true;       // 幻兽任务（训练幻兽）
    rw_dxc = true;      // 地下城任务
    
    // 周六特殊重置
    if(_root.mc_day.nowday % 7 == 6)
    {
        // 重置地下城怪物
        rw_gw1_1 = true;  // 地下城1层怪物1
        rw_gw1_2 = true;  // 地下城1层怪物2
        rw_gw1_3 = true;  // 地下城1层怪物3
        rw_gw2_1 = true;  // 地下城2层怪物1
        rw_gw2_2 = true;  // 地下城2层怪物2
        rw_gw3_1 = true;  // 地下城3层怪物
    }
    
    // 周五特殊重置
    if(_root.mc_day.nowday % 7 == 5)
    {
        // 刷新雪域边境怪物
        gw_xybj_1 = gw_xybj_2 = gw_xybj_3 = gw_xybj_4 = gw_xybj_5 = true;
    }
}
```

## 核心代码结构

### 主函数调用流程

```
玩家点击NPC
    ↓
onRelease() 事件
    ↓
talk() 函数
    ├─ openme() - 打开对话窗口
    ├─ missionshow() - 显示当前任务信息
    ├─ words() - 显示对话文本
    └─ answer() - 添加对话选项
    ↓
玩家选择选项
    ↓
answer(num) 函数
    ├─ case 1: mission() - 接受任务
    ├─ case 2: 显示任务说明
    └─ case 3: closeme() - 关闭对话
    ↓
mission() 函数
    ├─ 周一/周二: gather() - 收集宝石
    ├─ 周三/周四: 打开幻兽给予界面
    ├─ 周五: 传送到雪域边境
    ├─ 周六: 传送到皇宫
    └─ 周日: 传送到地下城
```

### missionshow() 函数逻辑

```actionscript
function missionshow()
{
    switch(_root.mc_day.nowday % 7)
    {
        case 1:  // 周一
        case 2:  // 周二
            // 计算需要收集的灵魂晶石/灵魂王数量
            // 返回任务描述文本
            break;
            
        case 3:  // 周三
        case 4:  // 周四
            // 返回训练幻兽任务描述
            break;
            
        case 5:  // 周五
            // 返回突袭任务描述
            // 根据是否救出国王显示不同文本
            break;
            
        case 6:  // 周六
            // 返回PK赛任务描述
            break;
            
        case 0:  // 周日
            // 返回地下城任务描述
            // 根据是否救出国王显示不同文本
            break;
    }
}
```

## 设计模式分析

### 1. 状态模式

任务系统使用状态变量（rw_bs, rw_hs, rw_dxc）来控制任务是否可完成，这是一种状态模式的应用。

### 2. 策略模式

根据不同的星期，执行不同的任务逻辑，这是一种策略模式的应用：

```actionscript
switch(_root.mc_day.nowday % 7)
{
    case 1:
    case 2:
        // 收集宝石策略
        break;
    case 3:
    case 4:
        // 训练幻兽策略
        break;
    // ...
}
```

### 3. 模板方法模式

所有任务都遵循相同的流程模板：
1. 检查任务是否可完成
2. 执行任务逻辑
3. 给予奖励
4. 标记任务完成

## 潜在问题与改进建议

### 潜在问题

1. **任务次数限制不统一**
   - 收集宝石、训练幻兽、地下城任务有次数限制
   - 突袭、PK赛任务没有次数限制
   - 建议：统一任务次数限制逻辑

2. **等级计算公式不够清晰**
   - 收集宝石任务的物品数量计算公式较复杂
   - 建议：简化计算公式或添加详细注释

3. **国王状态影响任务描述**
   - 周五和周日的任务描述会根据国王是否救出而变化
   - 建议：在任务说明中明确提示玩家

### 改进建议

1. **添加任务追踪系统**
   - 显示当前任务进度
   - 显示任务完成奖励预览

2. **优化任务提示**
   - 添加任务完成提示
   - 添加任务失败原因说明

3. **扩展任务类型**
   - 增加更多日常任务类型
   - 添加周常任务和月常任务
