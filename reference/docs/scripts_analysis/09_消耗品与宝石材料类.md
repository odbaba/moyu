# 消耗品与宝石材料类分析

## 概述

消耗品和宝石材料是游戏中可堆叠或独立使用的物品类型。消耗品可以通过使用功能产生效果，宝石材料则用于装备强化、镶嵌等系统。

## 核心函数分析

### finding() - 可堆叠物品合并

用于可堆叠物品，自动合并相同物品：

```actionscript
function finding()
{
   var _loc3_ = false;
   i = 0;
   while(i < _parent.yn)
   {
      j = 0;
      while(j < _parent.xn)
      {
         if(_parent.array[i][j].myid == myid)
         {
            _parent.array[i][j].number += number;  // 合并数量
            _loc3_ = true;
            i = _parent.yn;
            j = _parent.xn;
         }
         j++;
      }
      i++;
   }
   if(_loc3_)
   {
      removeMovieClip(this);  // 合并成功，删除当前实例
   }
   else
   {
      _parent.getroom(this);  // 没有相同物品，占用新格子
   }
}
```

消耗品支持的拖拽目标：

## 事件处理

### onPress - 按下事件

```actionscript
onPress = function()
{
   _root.wpxs.tohide();           // 隐藏物品提示
   _parent.swapDepths(104000);    // 提升父容器层级
   this.swapDepths(104005);       // 提升当前物品层级
   _parent.freeroom(this);        // 释放原位置
   startDrag(this, 0);            // 开始拖拽
};
```

### onRelease - 释放事件

```actionscript
onRelease = function()
{
   _parent.swapDepths(_parent.mydepth);  // 恢复父容器层级
   this.swapDepths(mydepth);             // 恢复当前物品层级
   stopDrag();                           // 停止拖拽
   doAfterDrag();                        // 处理放置逻辑
};
```

### onRollOver - 鼠标悬停

```actionscript
onRollOver = function()
{
   texts = useit + "\n" + names + "　数量" + number + "\n" + "物品描述";
   _root.wpxs.toshow(this);
};
```

### onRollOut - 鼠标离开

```actionscript
onRollOut = function()
{
   _root.wpxs.tohide();
};
```

## 物品使用限制

### 电浆药水

- 每天只能使用一瓶
- 通过 `_root.useds_num` 变量控制

### 满经验球

- 人物每天最多使用5个
- 幻兽使用无限制
- 通过 `_root.usejy.openme()` 打开使用界面

### 空经验球

- 需要等级100级以上才能使用
- 放在背包中自动存储战斗经验

## 与其他系统的交互

- **角色信息系统**：通过 `_root.xinxi` 访问和修改角色属性
- **装备栏系统**：通过 `_root.zhuangbei.flashme()` 刷新显示
- **物品提示系统**：通过 `_root.wpxs.toshow()/tohide()` 显示提示
- **消息系统**：通过 `_root.msgbox()/alertbox()` 显示消息
- **音效系统**：通过 `new Sound()` 播放使用音效
- **经验球使用界面**：通过 `_root.usejy.openme()` 打开
- **装备精炼系统**：通过 `_root.zbjingliank.movethings()` 交互
- **宝石融合系统**：通过 `_root.baoshironghe.movethings()` 交互

## 设计模式

消耗品类采用了以下设计模式：

1. **策略模式**：不同物品有不同的 useitem() 实现
2. **模板方法模式**：共享 doAfterDrag() 和事件处理结构
3. **享元模式**：可堆叠物品通过 finding() 合并共享存储空间
