# UI组件类分析

## 概述

UI组件类是游戏中用户界面元素的脚本实现，包括NPC、地图切换按钮、怪物选择按钮等交互元素。

## 组件分类

### NPC类组件

| 文件路径 | 组件名称 | 功能 |
|---------|---------|------|
| DefineSprite_1079 | 地图赛报名官 | 地图挑战系统入口 |
| DefineSprite_1090 | 2008奥运使者 | 特殊活动NPC |

### 交互按钮类组件

| 文件路径 | 组件名称 | 功能 |

## 核心功能分析

### 怪物选择按钮 (DefineSprite_1074)

点击后进入战斗场景：

```actionscript
this.onRelease = function()
{
   _root.mb_visible = mb_visible;
   _root.tsxs._visible = false;
   _root.zhanchang.isBoss = isBoss;
   _root.zhanchang.gwname = names;
   
   // 根据怪物等级计算数量
   if(!isBoss && names != "蜘蛛" && names != "蜘蛛王后艾达")
   {
      if(dj <= 25)
      {
         _root.zhanchang.gwnum = random(3) + 1;  // 1-3只
      }
      else if(dj <= 65)
      {
         _root.zhanchang.gwnum = random(3) + 2;  // 2-4只
      }
      else if(dj <= 100)
      {
         _root.zhanchang.gwnum = random(3) + 3;  // 3-5只
      }
      else if(dj <= 130)
      {
         _root.zhanchang.gwnum = random(3) + 4;  // 4-6只
      }
   }
   else
   {
      _root.zhanchang.gwnum = 1;  // Boss只有1只
   }
   
   _root.gotoAndStop("战场");
};
```

怪物数量规则：

| 怪物等级 | 数量范围 |
|---------|---------|
| ≤25级 | 1-3只 |
| 26-65级 | 2-4只 |
| 66-100级 | 3-5只 |
| 101-130级 | 4-6只 |
| Boss | 1只 |

### 地图切换按钮 (DefineSprite_1071)

处理地图切换逻辑：

```actionscript
this.onRelease = function()
{
   // 1. 后花园进入限制（需要爵位）
   if(_root.nowmap == "皇宫" && map == "后花园")
   {
      if(_root.xinxi.jwdj <= 0)
      {
         _root.alertbox("\r\r只有爵位达到勋爵以上才可以进入后花园");
         return false;
      }
   }
   
   // 2. 亚维特岛进入限制（需要70级）
   if(_root.nowmap == "卡萨诺城" && map == "亚维特岛")
   {
      if(_root.xinxi.dj < 70)
      {
         _root.alertbox("\r\r亚维特岛是个十分危险的地方，70级以上才允许进入");
         return false;
      }
   }
   
   // 3. 雪域边境进入限制（需要任务）
   if(_root.nowmap == "冰宫" && map == "雪域边境")
   {
      if(_root.mc_day.nowday % 7 != 5 && _root.king == false)
      {
         _root.alertbox("\r\r该地方十分危险，你没有任务不能进入");
         return false;
      }
   }
   
   // 4. 地下城进入限制（需要消灭怪物）
   if(_root.nowmap == "地下城1层" && map == "地下城2层")
   {
      if(_root.rw_gw1_1 || _root.rw_gw1_2 || _root.rw_gw1_3)
      {
         _root.alertbox("\r\r只有消灭完怪物后才能进入下一层");
         return false;
      }
   }
   
   // 执行地图切换
   if(_root.nextmap)
   {
      _root.nowmap = map;
      _root.minmap.updata();
      _root.talk.closeme();
      _root.CloseAll();
      _root.gotoAndStop(map);
   }
};
```

地图进入限制：

| 当前地图 | 目标地图 | 限制条件 |
|---------|---------|---------|
| 皇宫 | 后花园 | 爵位≥勋爵 |
| 卡萨诺城 | 亚维特岛 | 等级≥70 |
| 冰宫 | 雪域边境 | 特定任务或周五 |
| 地下城1层 | 地下城2层 | 消灭所有怪物 |
| 地下城2层 | 地下城3层 | 消灭所有怪物 |
| 魔军帅旗 | 能量塔禁地 | 魔军主帅不在 |

### NPC对话系统 (DefineSprite_1079)

NPC对话系统包含两个核心函数：

#### talk() - 打开对话

```actionscript
function talk()
{
   _root.talk.openme(this);
   words = "对话内容...";
   _root.talk.words(words, "NPC名称");
   
   var _loc3_ = 1;
   _root.talk.answer(_loc3_++, "选项1");
   _root.talk.answer(_loc3_++, "选项2");
   _root.talk.answer(_loc3_++, "选项3");
}
```

#### answer() - 处理选择

```actionscript
function answer(num)
{
   switch(num)
   {
      case 1:
         // 处理选项1
         break;
      case 2:
         // 处理选项2
         break;
      case 3:
         _root.talk.closeme();
         break;
   }
}
```

## 事件处理模式

### NPC组件事件

```actionscript
this.onRelease = function()
{
   talk();  // 打开对话
   // 播放选择音效
   var _loc1_ = new Sound();
   _loc1_.attachSound("选择NPC.wav");
   _loc1_.start();
};

this.onRollOver = function()
{
   gotoAndStop(2);  // 高亮状态
   // 播放指向音效
   var _loc1_ = new Sound();
   _loc1_.attachSound("指向NPC.wav");
   _loc1_.start();
};

this.onRollOut = function()
{
   gotoAndStop(1);  // 普通状态
};

this.onPress = function()
{
   gotoAndStop(3);  // 按下状态
};
```

### 按钮组件事件

```actionscript
this.onRollOver = function()
{
   _root.minmap.updata(map);  // 更新小地图
   gotoAndStop(2);
};

this.onRollOut = function()
{
   _root.minmap.updata();
   gotoAndStop(1);
};

this.onPress = function()
{
   var _loc1_ = new Sound();
   _loc1_.attachSound("切换地图.wav");
   _loc1_.start();
   gotoAndStop(3);
};
```

## 与其他系统的交互

- **对话系统**：通过 `_root.talk.openme()/closeme()` 控制对话界面
- **战场系统**：通过 `_root.zhanchang` 设置战斗参数
- **小地图系统**：通过 `_root.minmap.updata()` 更新显示
- **消息系统**：通过 `_root.alertbox()` 显示提示
- **背包系统**：通过 `_root.beibao.more()` 添加奖励物品
- **音效系统**：通过 `new Sound()` 播放音效

## 帧状态设计

UI组件通常使用3帧状态：

| 帧号 | 状态 | 说明 |
|-----|------|------|
| 1 | 普通 | 默认显示状态 |
| 2 | 高亮 | 鼠标悬停状态 |
| 3 | 按下 | 鼠标按下状态 |

## 设计模式

UI组件类采用了以下设计模式：

1. **状态模式**：通过帧切换实现不同视觉状态
2. **命令模式**：onRelease事件封装具体操作
3. **模板方法模式**：NPC组件共享talk/answer结构
4. **观察者模式**：通过事件监听响应用户交互
