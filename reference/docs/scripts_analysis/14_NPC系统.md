## NPC交互机制

### 对话系统

所有NPC使用统一的对话系统：

```actionscript
// 打开对话
_root.talk.openme(this);

// 显示对话内容
_root.talk.words(words, "NPC名称");

// 添加选项
_root.talk.answer(1, "选项1");
_root.talk.answer(2, "选项2");
```

### 音效系统

| 音效文件 | 触发时机 |
|---------|---------|
| 选择NPC.wav | 点击NPC |
| 指向NPC.wav | 鼠标指向NPC |
| 传送.wav | 传送至其他地图 |

### NPC状态

| 帧号 | 状态 |
|------|------|
| 1 | 普通 |
| 2 | 高亮（鼠标悬停） |
| 3 | 按下 |
