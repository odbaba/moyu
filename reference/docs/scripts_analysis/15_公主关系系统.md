# 公主关系系统（好友系统）文档

## 概述

本游戏中的"好友系统"实际上是**公主关系系统**，玩家通过与公主互动来提升关系等级，获得各种奖励和特殊技能。

**核心文件**：
- `scripts/DefineSprite_932/frame_1/DoAction.as` - 关系等级计算 (upgzgx函数)
- `scripts/DefineSprite_1206/frame_1/DoAction.as` - 公主交互逻辑

---

## 关系等级系统

### 等级划分

| 关系等级 | 经验值需求 | 称呼 | 解锁内容 |
|---------|-----------|------|---------|
| 0 | 0 | 未认识 | 无 |
| 1 | 1-9 | 认识 | 基础聊天 |
| 2 | 10-29 | 普通朋友 | 极品1星攻防型幻兽 |
| 3 | 30-49 | 好朋友 | 奇异兽 |
| 4 | 50-99 | 知己 | 极品12星奇异兽、年猪礼物 |
| 5 | 100-199 | 恋人 | 极品19星奇异兽、技能"爱的力量"等级1 |
| 6 | 200+ | 亲密恋人 | 极品19星奇异兽、技能"爱的力量"等级2 |

### 经验值获取途径

| 途径 | 经验值 | 条件 | 频率 |
|------|--------|------|------|
| 聊天 | +1 | 任意关系等级 | 每天一次 |
| 送99朵白玫瑰 | +5~104 | 基础5点 + 每多1朵+1点 | 周日 |
| 送999朵白玫瑰 | +25~5220 | 基础25点 + 每多1朵+5点 | 周日 |

### 经验值计算公式

```actionscript
// 聊天：固定+1
gzgxexp += 1;

// 99朵白玫瑰：基础5点 + 额外数量
exp = 5 + (数量 - 1) * 1;

// 999朵白玫瑰：基础25点 + 额外数量
exp = 25 + (数量 - 1) * 5;
```

## 交互功能详解

### 1. 聊天系统

**功能**：每天与公主聊天一次，获得友好度+1和幻兽奖励

**对话内容**（根据关系等级变化）：

| 关系等级 | 公主对话 | 奖励 |
|---------|---------|------|
| 0 | "听说你是位英勇的战士，我非常敬佩你的勇敢。" | 无 |
| 1（未救国王） | "很高兴，你能和我聊天。我最担心的是我的父亲，你有他的消息了吗。" | 无 |
| 1（已救国王） | "很高兴，你能和我聊天。非常感谢你把我父亲救出来。" | 无 |
| 2 | "我的朋友，我这里有些攻防型幻兽..." | 极品1星攻防型幻兽 |
| 3 | "我这里有许多幻兽，这个奇异兽听说是幻兽幻化时的最好副幻兽..." | 奇异兽 |
| 4 | "这是我精心为你培养的12星奇异兽..." | 极品12星奇异兽 |
| 5 | "看，这只亚特兰蒂斯大陆里非常稀有的极品19星奇异兽..." | 极品19星奇异兽 |
| 6 | "你把这无比优秀的19星奇异兽带上吧..." | 极品19星奇异兽 |

**限制**：每天只能聊天一次（`_root.gzchat`控制）

---

### 2. 送礼系统

**功能**：周日送花给公主，大幅提升友好度

**开放时间**：周日（`_root.mc_day.nowday % 7 == 0`）

**可送礼物**：
| 礼物 | 基础经验 | 额外经验 |
|------|---------|---------|
| 99朵白玫瑰 | 5点 | 每多1朵+1点 |
| 999朵白玫瑰 | 25点 | 每多1朵+5点 |

**送花流程**：
1. 与公主对话选择"送礼"
2. 打开背包选择鲜花
3. 公主收下礼物并计算经验
4. 播放送花音效

**限制**：每天只能送礼一次（`_root.gzgive`控制）

---

### 3. 周日礼物

**功能**：周日公主会送玩家一份礼物

**开放时间**：周日（`_root.mc_day.nowday % 7 == 0`）

**礼物内容**（根据关系等级）：

| 关系等级 | 礼物 | 公主对话 |
|---------|------|---------|
| 0-2 | 高级经验石 | "这是我收藏了许久的优质宝石，高级经验石..." |
| 3-4 | 高级战斗力石 | "这是我收藏了许久的优质宝石，高级战斗力石..." |
| 5 | 灵魂王 | "这是我收藏了许久的优质宝石，灵魂王..." |
| 6（未开战魂） | 电浆药水 | "我找到了一瓶电浆药水，它可以把人物的幸运提高到100哦。" |
| 6（已开战魂） | 战魂之心 | "我找到了一个战魂之心，它是极其稀有的宝石..." |

**限制**：每周只能领取一次（`_root.gzgift`控制）

---

### 4. 知己的礼物

**功能**：关系达到知己后，公主赠送超级幻兽

**条件**：关系等级≥4（知己）

**奖励**：年猪（超级幻兽）

**触发**：首次达到知己等级时自动解锁选项

**限制**：只能领取一次（`_root.gzgx4`控制）

## 特殊技能：爱的力量

**解锁条件**：
- 关系等级5（恋人）：学会"爱的力量"等级1
- 关系等级6（亲密恋人）：学会"爱的力量"等级2

**技能效果**：战斗中提供额外加成（具体效果见技能系统文档）

**学习代码**：
```actionscript
// 关系等级5
_root.jineng.studyjn(5, 1);

// 关系等级6
_root.jineng.studyjn(5, 2);
```

## 核心代码分析

### upgzgx函数（关系升级）

```actionscript
function upgzgx(exps)
{
   // 增加经验值
   gzgxexp += exps;
   
   // 判断等级
   if(gzgxexp >= 200)      // 亲密恋人
   {
      if(gzgx < 6)
      {
         _root.alertbox("恭喜，你与公主感情关系到了最高级了...");
         gxname = "亲密恋人";
         _root.jineng.studyjn(5, 2);  // 学习技能
         if(gzgx < 4) _root.gzgx4 = true;
      }
      gzgx = 6;
   }
   else if(gzgxexp >= 100) // 恋人
   {
      if(gzgx < 5)
      {
         _root.alertbox("恭喜，你与公主感情关系提高到了恋人了...");
         gxname = "恋人";
         _root.jineng.studyjn(5, 1);
         if(gzgx < 4) _root.gzgx4 = true;
      }
      gzgx = 5;
   }
   // ... 其他等级类似
}
```

### chat函数（聊天奖励）

```actionscript
function chat()
{
   _root.gzchat = false;  // 标记今天已聊天
   
   switch(_root.xinxi.gzgx)
   {
      case 2:  // 普通朋友
         _root.moshishang.gfx.newbb(100);  // 极品1星攻防型
         break;
      case 3:  // 好朋友
         _root.moshishang.xo.newbb();  // 奇异兽
         break;
      case 4:  // 知己
         _root.moshishang.xo12.newbb();  // 极品12星奇异兽
         break;
      case 5:  // 恋人
      case 6:  // 亲密恋人
         _root.moshishang.xo19.newbb();  // 极品19星奇异兽
         break;
   }
   
   _root.xinxi.upgzgx(1);  // 增加友好度
}
```

## 每日重置

在`frame_6/DoAction.as`的`nextday()`函数中，以下变量会被重置：

```actionscript
gzchat = true;   // 可以聊天
gzgive = true;   // 可以送礼
gzgift = true;   // 可以领取周日礼物
```

## 快速提升关系攻略

### 最优路径

1. **第1天**：聊天(+1) → 认识
2. **第2-10天**：每天聊天(+9) → 普通朋友（累计10点）
3. **第11-30天**：每天聊天(+20) → 好朋友（累计30点）
4. **第31-50天**：每天聊天(+20) → 知己（累计50点）
   - 获得年猪礼物
5. **第51-100天**：每天聊天(+50) → 恋人（累计100点）
   - 学会"爱的力量"等级1
6. **第101-200天**：每天聊天(+100) → 亲密恋人（累计200点）
   - 学会"爱的力量"等级2

### 送花加速

使用999朵白玫瑰可以大幅加速：
- 送1次999朵白玫瑰 = +25点经验
- 送10次999朵白玫瑰 = +250点经验（直接达到恋人）
