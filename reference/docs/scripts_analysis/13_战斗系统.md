# 战斗系统分析

## 概述

游戏采用回合制战斗系统，玩家与怪物/BOSS进行战斗。战斗中可以使用普通攻击、技能攻击，幻兽可以出征协助战斗。战斗消耗时间单位（每场战斗3单位）和体力值（使用技能时）。

## 战斗流程

### 1. 战斗触发

```
地图场景 -> 点击怪物 -> frame_36 -> zhanchang.gotoAndPlay("开始")
```

### 2. 战斗初始化 (frame_10)

```actionscript
// 创建怪物实例
if(isBoss)
{
   attachMovie("BOSS", "gw0", depth);  // BOSS单独处理
}
else
{
   // 创建普通怪物（最多6只）
   for(i = 0; i < gwnum; i++)
   {
      attachMovie("怪物对象", "gw" + i, depth);
   }
}

// 战魂套装效果
if(zhuangbei.zhth() == 1)  // 天魂套装
{
   敌人战斗力下降 2 * zhjj() %;

else if(zhuangbei.zhdh() == 1)  // 地魂套装

   敌人生命值减少 5 * zhjj() %;

```

### 3. 战斗结束 (frame_18)

```actionscript

{
   removeMovieClip(array[i]);
}

// 消耗时间
_root.mc_day.times_go(3);  // 每场战斗消耗3个时间单位

// 返回地图

```

## 伤害计算系统

### 基础伤害公式

```actionscript
// 攻击者计算伤害
hit = xgj + random(dgj - xgj + 1);  // 最小攻击~最大攻击之间随机

// 战斗力修正
if(it_zdl > gwzdl)  // 攻击者战斗力高
{
   add = min(it_zdl - gwzdl, 20);
   hit += add * 0.05 * hit;  // 最多+100%伤害
}
else if(it_zdl < gwzdl)  // 防御者战斗力高
{
   sub = min(gwzdl - it_zdl, 50);
   hit -= sub * 0.01 * hit;  // 最多-50%伤害
}

// 防御减免
hit -= fy;
if(hit < 1) hit = 1;  // 最小伤害为1
```

## 怪物战斗系统

### 怪物属性结构

```actionscript
gwzdl   // 怪物战斗力
dj      // 怪物等级
mhp     // 最大生命 = base_hp + cz_hp * dj
hp      // 当前生命
xgj     // 最小攻击 = base_xgj + cz_xgj * dj
dgj     // 最大攻击 = base_dgj + cz_dgj * dj
fy      // 防御 = base_fy + cz_fy * dj
```

### 怪物攻击流程

```actionscript
// frame_11: 怪物攻击
hitsb(_root.xinxi);          // 攻击玩家
_parent.next_gw_hit(xi + 1); // 下一个怪物攻击

```

## 幻兽战斗系统

### 出征机制

```actionscript
function chuzheng(dsc)
{
   _visible = true;
   point = dsc;  // 幻兽数据引用
   updata();     // 更新显示
   gotoAndStop(dsc.hs_name);  // 显示对应幻兽形象
}
```

### 合体系统

```actionscript
function setInOne(b)
{
   _parent.InOne = b;
   if(b)
   {
      // 合体：攻击力、防御力合并
      _root.msgbox("幻兽合体成功，攻击力、防御力得到提升");
   }
   else
   {
      // 解体：幻兽独立战斗
   }
   _root.zhuangbei.flashme();
}
```

### 合体效果

- **合体状态**：幻兽属性加到角色身上，角色受到伤害时由幻兽承受
- **非合体状态**：幻兽独立攻击，不承受伤害，仅提供战斗力加成

### 幻兽受伤处理

```actionscript
function byhit(hit)
{
   hp -= hit;
   if(hp <= 0)
   {
      _root.alertbox("幻兽已经死亡，幸运值降低10点");
      _root.xinxi.xy -= 10;
      hp = 0;
      
      if(_root.xinxi.xy < 0)
      {
         _root.xinxi.xy = 0;
         _root.zhanchang.gotoAndPlay("结束");  // 幸运值为0，自动退出战斗
      }
   }
}
```

## 战斗回合流程

```
1. 玩家行动
   ├── 普通攻击 -> hitgw(0)
   ├── 技能攻击 -> hitgw(2-7)
   └── 使用物品

2. 怪物反击
   ├── 遍历存活怪物
   ├── 每个怪物执行 hitsb(玩家)
   └── 所有怪物攻击完毕后 -> wanjia.turnme()

3. 循环直到战斗结束
   ├── 所有怪物死亡 -> 战斗胜利
   └── 玩家/幻兽死亡 -> 战斗失败
```

## 战斗力系统

### 战斗力计算

```actionscript
zdl = jbzdl + jxzdl + jwzdl + hs1zdl + hs2zdl + zbpzzdl + mhdjzdl + dongzdl + bszdl + fixzdl + bestbszdl + jnzdl + zhzdl;
```

| 组成部分 | 说明 |
|---------|------|
| jbzdl | 基础战斗力 = 等级 |
| jxzdl | 军衔战斗力 (1-60) |
| jwzdl | 爵位战斗力 (2-50) |
| hs1zdl, hs2zdl | 幻兽战斗力 |
| zbpzzdl | 装备品质战斗力 |
| mhdjzdl | 追加等级战斗力 |
| dongzdl | 镶嵌孔战斗力 |
| bszdl | 宝石战斗力 |
| jnzdl | 技能加成战斗力 |
| zhzdl | 战魂加成战斗力 |

### 战斗力差距修正

| 差距 | 伤害修正 |
|-----|---------|
| 攻击者战斗力高 | 每点差距+5%伤害，最多+100% |
| 防御者战斗力高 | 每点差距-1%伤害，最多-50% |

## 战斗失败惩罚

- 幸运值-10
- 经验值-5%
- 如果幸运值降为0，自动退出战斗

## 设计模式

战斗系统采用了以下设计模式：

1. **状态模式**：战斗状态（开始、进行中、结束）切换
2. **策略模式**：不同攻击类型使用不同的伤害计算
3. **观察者模式**：伤害变化时更新UI显示
4. **组合模式**：幻兽合体时属性合并
