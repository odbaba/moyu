# 技能书类分析

## 概述

技能书是游戏中用于学习新技能的特殊物品。使用技能书后，角色可以学会对应的技能，技能书会被消耗。

## 文件列表

| 文件路径 | 物品名称 | myid | 技能ID | 技能等级 |
|---------|---------|------|-------|---------|
| DefineSprite_23_星魔剑 | 星魔剑 | "星魔剑" | 2 | 1 |
| DefineSprite_26_高级星魔剑 | 高级星魔剑 | "高级星魔剑" | 2 | 2 |
| DefineSprite_31_飞天连斩 | 飞天连斩 | "飞天连斩" | 3 | 1 |
| DefineSprite_28_高级飞天连斩 | 高级飞天连斩 | "高级飞天连斩" | 3 | 2 |

## 技能参数映射

技能书通过 `_root.jineng.studyjn(skillId, level)` 方法学习技能：

| 技能书 | skillId | level | 技能效果 |
|-------|---------|-------|---------|
| 星魔剑 | 2 | 1 | 群体攻击，攻击力120% |
| 高级星魔剑 | 2 | 2 | 群体攻击，攻击力150% |
| 飞天连斩 | 3 | 1 | 单体四连击 |
| 高级飞天连斩 | 3 | 2 | 单体四连击，其中2击破防 |

## 核心函数分析

### useitem() - 学习技能

```actionscript
function useitem()
{
   _root.jineng.studyjn(skillId, level);  // 调用技能系统学习技能
   _root.msgbox("学会了" + names);         // 显示学习成功消息
   _parent.freeroom(this);                 // 释放背包格子
   this.removeMovieClip();                 // 删除技能书
}
```

不同技能书的参数：
- 星魔剑：`_root.jineng.studyjn(2, 1);`
- 高级星魔剑：`_root.jineng.studyjn(2, 2);`
- 飞天连斩：`_root.jineng.studyjn(3, 1);`
- 高级飞天连斩：`_root.jineng.studyjn(3, 2);`

### doAfterDrag() - 拖拽后处理

技能书支持以下拖拽目标：

```actionscript
function doAfterDrag()
{
   // 1. 返回原容器
   if(this.hitTest(_parent.baokou)) { _parent.getroom(this); }
   
   // 2. 背包
   else if(this.hitTest(_root.beibao.baokou)) { _root.beibao.movethings(this); }
   
   // 3. 仓库
   else if(this.hitTest(_root.cangku.baokou)) { _root.cangku.movethings(this); }
   
   // 4. 家货商
   else if(this.hitTest(_root.jiahuoshang.baokou)) { ... }
   
   // 5. 收藏架
   else if(this.hitTest(_root.shoucangjia.baokou)) { ... }
   
   // 6. 寄易
   else if(this.hitTest(_root.geiyi.baokou)) { ... }
   
   // 7. 垃圾箱
   else if(this.hitTest(_root.lajixiang))
   {
      this.removeMovieClip();
   }
}
```

## 物品属性结构

```actionscript
myid      // 物品标识符

yj        // 格子Y坐标 (-1表示未放置)

```

## 事件处理

### onPress - 按下事件

```actionscript
onPress = function()
{
   _root.wpxs.tohide();           // 隐藏物品提示
   _parent.swapDepths(104000);    // 提升父容器层级
   this.swapDepths(104005);       // 提升当前物品层级
   _parent.freeroom(this);        // 释放原位置
   startDrag(this, 0);            // 开始拖拽
};
```

### onRelease - 释放事件

```actionscript
onRelease = function()
{
   _parent.swapDepths(_parent.mydepth);  // 恢复父容器层级
   this.swapDepths(mydepth);             // 恢复当前物品层级
   stopDrag();                           // 停止拖拽
   doAfterDrag();                        // 处理放置逻辑
};
```

### onRollOver - 鼠标悬停

```actionscript
onRollOver = function()
{
   texts = useit + "\n" + names + "\n" + 
           "使用后学会" + names + "技能" + "\n" + 
           "技能效果：...";
   _root.wpxs.toshow(this);
};
```

### onRollOut - 鼠标离开

```actionscript
onRollOut = function()
{
   _root.wpxs.tohide();
};
```

## 与其他系统的交互

- **技能系统**：通过 `_root.jineng.studyjn(skillId, level)` 学习技能
- **消息系统**：通过 `_root.msgbox()` 显示学习成功消息
- **物品提示系统**：通过 `_root.wpxs.toshow()/tohide()` 显示提示
- **背包系统**：通过 `_parent.freeroom()` 释放格子

## 技能体系结构

### 技能ID分类

根据代码分析，技能ID可能有以下含义：

| 技能ID | 技能类型 |
|-------|---------|
| 1 | 基础攻击（推测） |
| 2 | 星魔剑系列 |
| 3 | 飞天连斩系列 |

### 技能等级

每个技能有两个等级：

| 等级 | 说明 |
|-----|------|
| 1 | 普通版本 |
| 2 | 高级版本（效果更强） |

## 设计模式

技能书类采用了以下设计模式：

1. **策略模式**：不同技能书有不同的 studyjn() 参数
2. **模板方法模式**：共享 useitem() 结构，仅参数不同
3. **命令模式**：useitem() 封装了学习技能的操作

## 注意事项

1. 技能书使用后会被消耗（删除）
2. 高级技能书价值更高，效果更强
3. 技能书不可堆叠（没有 finding() 函数）
4. 使用技能书需要通过物品提示界面的"使用"按钮触发
