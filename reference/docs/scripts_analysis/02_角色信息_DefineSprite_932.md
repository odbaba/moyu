# 角色信息管理分析 (DefineSprite_932)

## 概述

DefineSprite_932 是角色系统的核心，管理角色的所有属性、战斗、升级等功能。

## 核心函数分析

### flashdata() - 刷新角色属性

重新计算角色的所有属性：

```actionscript
function flashdata()
{
   miss = _root.zhuangbei.zhmiss();  // 闪避率来自装备战魂
   mhp = base_hp + cz_hp * dj;       // 最大HP
   mtl = base_tl + cz_tl * dj;       // 最大体力
   xgj = base_xgj + cz_xgj * dj + _root.zhuangbei.getxgj();  // 最小攻击
   dgj = base_dgj + cz_dgj * dj + _root.zhuangbei.getdgj();  // 最大攻击
   fy = base_fy + cz_fy * dj + _root.zhuangbei.getfy();      // 防御
   
   // 幻兽出征加成
   if(_root.czmb0.InOne && _root.czmb0._visible)
   {
      xgj += _root.czmb0.point.xgj;
      dgj += _root.czmb0.point.dgj;
      fy += _root.czmb0.point.fy;
   }
   
   // 天魂战魂攻击加成
   xgj = Math.round(xgj * (1 + _root.zhuangbei.zhgj()));
   dgj = Math.round(dgj * (1 + _root.zhuangbei.zhgj()));
   
   flashzdl();  // 刷新战斗力
   upxx();      // 更新界面
}
```

### hitsb(hittype, dsc) - 攻击目标

攻击类型伤害倍率：

| hittype | 倍率 | 说明 |
|---------|------|------|
| 0/4 | 1.0 | 普通攻击 |
| 1/5 | 1.5 | 暴击 |
| 2 | 0.6 | 弱攻击 |
| 3 | 0.75 | 中等攻击 |
| 6 | 1.0 | 反弹伤害 |

### byhit(hit, it_zdl) - 受到伤害

伤害计算流程：

1. **闪避判定**：`random(100) < miss`
2. **战斗力差距修正**：
   - 敌人战斗力高：伤害增加（最多+100%）
   - 敌人战斗力低：伤害减少（最多-50%）
3. **防御减免**：`hit -= fy`
4. **幻兽分担伤害**

### have_exp_only(exps) - 角色升级

升级逻辑：

```actionscript
while(jy >= mjy)
{
   jy -= mjy;
   dj++;
   
   if(++xy > 100) xy = 100;  // 幸运值增加
   
   // 升级所需经验计算
   if(dj < 20)
      mjy = Math.round(mjy * 1.2);
   else if(dj <= 50)
      mjy = Math.round(mjy * 1.1);
   else
      mjy += hun;
   
   flashdata();
   hp = mhp;
   tl = mtl;
}
```

## 死亡处理

角色死亡时：
1. 幸运值-10
2. 经验值-5%
3. 如果幸运值降为0，自动退出战斗

## 设计模式

角色系统采用了以下设计模式：

1. **组合模式**：角色属性由基础+成长+装备+幻兽组合而成
2. **观察者模式**：属性变化时自动更新界面
3. **策略模式**：不同攻击类型使用不同伤害计算策略
