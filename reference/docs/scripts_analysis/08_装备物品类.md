# 装备物品类分析

## 概述

装备物品类是游戏中所有可装备物品的基类实现，包括武器、头盔、手镯、项链、衣服、战鞋六种类型。每种装备都有独立的脚本文件，但共享相同的代码结构和功能逻辑。

## 装备属性结构

### 基础属性

```actionscript
dj      // 使用等级要求 (1-74)
pz      // 品质 (0=普通, 1=良品, 2=上品, 3=精品, 4=极品)
mhdj    // 追加等级 (强化等级)
dong    // 镶嵌孔数 (0-2)
dong1   // 第一个孔镶嵌的宝石
dong2   // 第二个孔镶嵌的宝石
```

### 战魂属性

```actionscript
zhtype  // 战魂类型 (1=天魂, 2=地魂)
zhdj    // 战魂等级 (1-5)
```

### 计算属性

不同装备类型的属性计算公式：

| 装备类型 | 属性 | setmydim公式 | flashcount公式 |
|---------|------|-------------|---------------|
| 武器 | 攻击力 | dgj=15*dj, xgj=10*dj | dgj=30*dj, xgj=20*dj |
| 头盔 | 防御力 | fy=6*dj | fy=12*dj |
| 手镯 | 攻击力 | dgj=10*dj, xgj=5*dj | dgj=15*dj, xgj=10*dj |
| 项链 | 攻击力 | dgj=10*dj, xgj=8*dj | dgj=20*dj, xgj=15*dj |
| 衣服 | 防御力 | fy=8*dj | fy=18*dj |
| 战鞋 | 防御力 | fy=4*dj | fy=8*dj |

追加属性计算：
```actionscript
fdgj = Math.floor(dgj / 10) * mhdj;  // 追加最大攻击
fxgj = Math.floor(xgj / 10) * mhdj;  // 追加最小攻击
ffy = Math.floor(fy / 10) * mhdj;    // 追加防御
```

## 核心函数分析

```actionscript
function setmydim()
{
   ddim = _parent.src;
   if(ddim.zhtype != undefined)

   mhdj = ddim.mhdj;
   dong = ddim.dong;
   dong1 = ddim.dong1;
   dong2 = ddim.dong2;

}
```

### doAfterDrag() - 拖拽后处理

处理装备拖拽后的放置逻辑，支持多种目标容器：

```actionscript
function doAfterDrag()
{
   // 1. 返回原容器
   if(this.hitTest(_parent.baokou)) { _parent.getroom(this); }
   
   // 2. 背包
   else if(this.hitTest(_root.beibao.baokou)) { _root.beibao.movethings(this); }
   
   // 3. 仓库
   else if(this.hitTest(_root.cangku.baokou)) { _root.cangku.movethings(this); }
   
   // 4. 家货商
   else if(this.hitTest(_root.jiahuoshang.baokou)) { ... }
   
   // 5. 收藏架
   else if(this.hitTest(_root.shoucangjia.baokou)) { ... }
   
   // 6. 寄易
   else if(this.hitTest(_root.geiyi.baokou)) { ... }
   
   // 7. 装备精炼
   else if(this.hitTest(_root.zbjingliank.baokou)) { ... }
   
   // 8. 装备幻境
   else if(this.hitTest(_root.zhuangbeihuanjy.baokou)) { ... }
   
   // 9. 装备栏 - 核心逻辑
   else if(this.hitTest(_root.zhuangbei.baokou))
   {
      if(_root.xinxi.dj >= dj)  // 检查等级
      {
         if(!_root.zhuangbei.xxx.item)  // 槽位为空
         {
            _root.zhuangbei.setzhuangbei(this);
         }
         else  // 槽位有装备，交换
         {
            swapitem();
            _parent.getroom(this);
         }
      }
      else
      {
         _root.msgbox("你的等级不够还不能使用这件装备");
      }
   }
   
   // 10. 垃圾箱 - 删除物品
   else if(this.hitTest(_root.lajixiang))
   {
      this.removeMovieClip();
   }
}
```

### swapitem() - 装备交换

交换当前装备与目标槽位装备的所有属性：

```actionscript
function swapitem()
{
   ditem = _root.zhuangbei.xxx.item;  // 目标槽位装备
   // 交换所有属性
   temp = zhtype; zhtype = ditem.zhtype; ditem.zhtype = temp;
   temp = zhdj; zhdj = ditem.zhdj; ditem.zhdj = temp;
   temp = dj; dj = ditem.dj; ditem.dj = temp;
   temp = pz; pz = ditem.pz; ditem.pz = temp;
   temp = mhdj; mhdj = ditem.mhdj; ditem.mhdj = temp;
   temp = dong; dong = ditem.dong; ditem.dong = temp;
   temp = dong1; dong1 = ditem.dong1; ditem.dong1 = temp;
   temp = dong2; dong2 = ditem.dong2; ditem.dong2 = temp;
   // 刷新显示
   flashcount();
   nowplayto();
}
```

### nowplayto() - 帧控制

控制装备图标显示：

```actionscript
function nowplayto(n)
{
   if(n)
   {
      gotoAndStop(n);  // 指定帧
   }
   else if(_parent._name == "zhuangbei" || _parent._name == "zbjingliank")
   {
      gotoAndStop(dj + 1 + "s");  // 装备栏显示
   }
   else
   {
      gotoAndStop(dj + "s");  // 背包显示
   }
}
```

### checkbs() - 宝石检查

检查镶嵌宝石的属性加成：

```actionscript
function checkbs(bs)
{
   switch(bs)
   {
      case "中级战斗力石":
         zdl = 3;
         return "战斗力+3";
      case "高级战斗力石":
         zdl = 5;
         return "战斗力+5";
      case "中级经验石":
         jy = 0.25;
         return "经验值+25%";
      case "高级经验石":
         jy = 0.5;
         return "经验值+50%";
      default:
         return "";
   }
}
```

### getjbvalue() - 金币价值

计算装备的金币价值：

```actionscript
function getjbvalue()
{
   return 100 * dj * (pz + 1) + 100 * mhdj + 10000 * dong * dong * dong;
}
```

### getmsvalue() - 魔石价值

计算极品装备的魔石价值：

```actionscript
function getmsvalue()
{
   if(pz == 4)  // 仅极品装备
   {
      return 28 * (dj * 2.5 + 50) + mhdj * 128 + 1500 * dong * dong * dong;
   }
   return 0;
}
```

## 事件处理

### onPress - 按下事件

```actionscript
onPress = function()
{
   _root.wpxs.tohide();           // 隐藏物品提示
   _parent.swapDepths(1040000);   // 提升父容器层级
   this.swapDepths(1040005);      // 提升当前物品层级
   _parent.freeroom(this);        // 释放原位置
   nowplayto(dj + 1 + "s");       // 显示装备状态图标
   startDrag(this, 0);            // 开始拖拽
};
```

### onRelease - 释放事件

```actionscript
onRelease = function()
{
   _parent.swapDepths(_parent.mydepth);  // 恢复父容器层级
   nowplayto();                          // 恢复正常显示
   this.swapDepths(mydepth);             // 恢复当前物品层级
   stopDrag();                           // 停止拖拽
   doAfterDrag();                        // 处理放置逻辑
};
```

### onRollOver - 鼠标悬停

显示装备详细信息提示：

```actionscript
onRollOver = function()
{
   flashcount();
   nowplayto();
   
   // 品质颜色
   switch(pz)
   {
      case 0: pzcolor = "<font color=\"#ffffff\">"; break;  // 普通-白色
      case 1: pzcolor = "<font color=\"#00ff00\">"; break;  // 良品-绿色
      case 2: pzcolor = "<font color=\"#0000ff\">"; break;  // 上品-蓝色
      case 3: pzcolor = "<font color=\"#ff0000\">"; break;  // 精品-红色
      case 4: pzcolor = "<font color=\"#cc00ff\">"; break;  // 极品-紫色
   }
   
   // 构建提示文本
   texts2 = pzcolor + 品质前缀 + 名称;
   texts2 += 使用等级;
   texts2 += 主属性;
   texts2 += 追加属性;
   texts2 += 战魂信息;
   texts2 += 镶嵌信息;
   
   _root.wpxs.toshow(this);
};
```

### onRollOut - 鼠标离开

```actionscript
onRollOut = function()
{
   _root.wpxs.tohide();
};
```

## 战魂系统

### 天魂 (zhtype=1)
- 效果：攻击加成
- 公式：攻击+ zhdj * 5%
- 最大等级：5级 (MAX)

### 地魂 (zhtype=2)
- 效果：闪避加成
- 公式：闪避+ zhdj * 2%
- 最大等级：5级 (MAX)

## 镶嵌系统

装备最多可镶嵌2颗宝石：

| 宝石名称 | 效果 |
|---------|------|
| 中级战斗力石 | 战斗力+3 |
| 高级战斗力石 | 战斗力+5 |
| 中级经验石 | 经验值+25% |
| 高级经验石 | 经验值+50% |

## 帧标签与图片映射

装备使用帧标签控制显示：

- **背包显示**：`gotoAndStop(dj + "s")` - 如 "1s", "10s", "74s"
- **装备栏显示**：`gotoAndStop(dj + 1 + "s")` - 如 "2s", "11s", "75s"

每个帧标签对应不同的图片资源，实现不同等级装备的外观差异。

## 设计模式

装备类采用了以下设计模式：

1. **模板方法模式**：所有装备共享相同的函数结构，仅属性计算公式不同
2. **策略模式**：通过myid区分不同装备类型，运行时动态绑定到对应槽位
3. **观察者模式**：通过事件处理响应用户交互

## 与其他系统的交互

- **背包系统**：通过movethings()方法交互
- **装备栏系统**：通过setzhuangbei()方法装备
- **物品提示系统**：通过wpxs.toshow()/tohide()显示提示
- **消息系统**：通过msgbox()/alertbox()显示提示信息
