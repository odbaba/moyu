# 收藏家交互逻辑文档

## 一、概述

收藏家是游戏中的一个特殊NPC，位于卡萨诺城，专门收购珍稀物品和极品装备，以魔石作为交易货币。玩家可以通过与收藏家交易获得魔石，这是游戏中获取魔石的主要途径之一。

## 三、交互流程

### 3.1 完整交互流程

```
1. 玩家点击收藏家NPC
   ↓
2. 触发talk()函数，显示对话
   ↓
3. 玩家选择"我有些好东西要卖"
   ↓
4. 执行answer(1)：
   - CloseAll() 关闭所有界面
   - shoucangjia.openme() 打开收藏架
   - beibao.openme() 打开背包
   - talk.closeme() 关闭对话
   ↓
5. 玩家将物品从背包拖拽到收藏架
   ↓
6. 触发物品的doAfterDrag()函数
   ↓
7. 调用shoucangjia.movethings(this)
   ↓
8. 收藏架调用getroom()放置物品
   ↓
9. 调用countvalue()计算魔石价值
   ↓
10. 玩家点击出售按钮
   ↓
11. 执行sell()函数，玩家获得魔石
```

### 3.2 物品拖拽逻辑

所有可交易物品都实现了`doAfterDrag()`函数，支持拖拽到以下容器：

```actionscript
function doAfterDrag()
{
   // 1. 返回原容器
   if(this.hitTest(_parent.baokou)) { _parent.getroom(this); }

   // 4. 家货商
   else if(this.hitTest(_root.jiahuoshang.baokou)) { ... }
   
   // 5. 收藏架 ★
   else if(this.hitTest(_root.shoucangjia.baokou)) 
   { 
      if(!_root.shoucangjia.movethings(this))
      {
         _parent.getroom(this);  // 如果收藏架满了，返回原容器
      }
   }
   
   // 6. 其他容器...
}
```

## 四、价值计算系统

### 4.1 魔石价值计算公式

收藏架使用以下公式计算物品的魔石价值：

```actionscript
function countvalue(wp, flag)
{
   myms += flag * wp.getmsvalue() * 0.8;
   ms.text = showjb(myms);
}
```

**说明**：
- `wp.getmsvalue()`：物品的基础魔石价值
- `* 0.8`：收藏家以80%的价格收购
- `flag`：1表示添加物品，-1表示移除物品

#### 极品装备类

装备的魔石价值计算较为复杂，只有**极品装备（pz=4）**才能出售给收藏家：

```actionscript
function getmsvalue()
{
   if(pz == 4)  // 只有极品装备才有魔石价值
   {
      return 28 * (dj * 2.5 + 50) + mhdj * 128 + 1500 * dong * dong * dong;
   }
   return 0;
}
```

**计算公式**：
```
魔石价值 = 28 × (装备等级 × 2.5 + 50) + 魔魂等级 × 128 + 1500 × 宝石洞数量³
```

**示例计算**：
- 50级极品武器，魔魂+9，2个洞：
  ```
  = 28 × (50 × 2.5 + 50) + 9 × 128 + 1500 × 2³
  = 28 × 175 + 1152 + 12000
  = 4900 + 1152 + 12000
  = 18052 魔石
  ```

- 100级极品衣服，魔魂+12，1个洞：
  ```
  = 28 × (100 × 2.5 + 50) + 12 × 128 + 1500 × 1³
  = 28 × 300 + 1536 + 1500
  = 8400 + 1536 + 1500
  = 11436 魔石
  ```

## 五、核心函数详解

### 5.1 收藏架核心函数

#### movethings(dsc) - 接收物品

```actionscript
function movethings(dsc)
{
   isok = false;
   i = 0;
   while(i < yn)
   {
      j = 0;
      while(j < xn)
      {
         if(!array[i][j])  // 查找空位
         {
            isok = true;
            i = yn;
            j = xn;
         }
         j++;
      }
      i++;
   }
   var _loc2_;
   if(isok)  // 如果有空位
   {
      src = dsc;
      _loc2_ = this.getNextHighestDepth();
      this.attachMovie(dsc.myid,"wp" + _loc2_,_loc2_);  // 创建物品实例
   }
   return isok;
}
```

#### getroom(dsc) - 放置物品到格子

```actionscript
function getroom(dsc)
{
   var _loc0_;
   var _loc2_ = yj = -1;
   i = 0;
   while(i < yn)
   {
      j = 0;
      while(j < xn)
      {
         if(!array[i][j])
         {
            array[i][j] = dsc;          // 将物品放入数组
            countvalue(dsc,1);           // 计算价值
            _loc2_ = i;
            yj = j;
            i = yn;
            j = xn;
         }
         j++;
      }
      i++;
   }
   if(_loc2_ != -1 && yj != -1)
   {
      dsc.xi = _loc2_;
      dsc.yj = yj;
      dsc._x = xbase + base * yj + offset;  // 设置物品位置
      dsc._y = ybase + base * _loc2_ + offset;
   }
   else
   {
      removeMovieClip(dsc);  // 没有空位，删除物品
   }
}
```

#### sell() - 出售所有物品

```actionscript
function sell()
{
   i = 0;
   while(i < yn)
   {
      j = 0;
      while(j < xn)
      {
         if(array[i][j] != false)
         {
            removeMovieClip(array[i][j]);  // 删除物品
            array[i][j] = false;
         }
         j++;
      }
      i++;
   }
   _root.beibao.subms(-myms);  // 增加玩家魔石
   myms = 0;                   // 重置价值
   ms.text = showjb(myms);
}
```

## 七、交易限制与规则

### 7.1 物品限制

1. **装备限制**：只有极品装备（品质pz=4）才能出售给收藏家
2. **容量限制**：收藏架最多容纳12个物品
3. **价值限制**：物品必须有魔石价值（getmsvalue() > 0）

### 7.2 价格机制

1. **收购价格**：物品魔石价值 × 80%
2. **显示格式**：魔石数量以千分位格式显示（如：1,234,567）

### 7.3 交易流程

1. 玩家将物品拖入收藏架
2. 系统自动计算并显示总价值
3. 玩家点击"出售"按钮
4. 物品被删除，玩家获得魔石
5. 交易不可撤销

## 十、总结

收藏家系统是游戏中重要的魔石获取途径，通过以下特点体现了游戏的经济系统设计：

1. **差异化定价**：不同物品有不同的魔石价值，极品装备价值最高
2. **折扣机制**：收藏家以80%的价格收购，体现了NPC的利润空间
3. **交互友好**：拖拽式操作，自动计算价值，简化交易流程
4. **限制机制**：只有特定物品和极品装备才能交易，保证了游戏平衡

该系统通过清晰的交互逻辑和合理的价值计算，为玩家提供了一个稳定可靠的魔石来源，同时也促进了玩家对极品装备的追求。
