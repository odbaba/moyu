## 一、核心功能

宝石合成师提供宝石合成服务，允许玩家将低级宝石合成为高级宝石。

### 主要功能
- 宝石合成（5种配方）
- 材料检查
- 背包物品管理

---

## 二、合成配方

### 1. 魔魂之心
- **所需材料**: 5个魔魂晶石
- **合成结果**: 1个魔魂之心
- **用途**: 提升装备魔魂等级（成功率100%，最高可提升至9级）

### 2. 幻魔之心
- **所需材料**: 5个幻魔晶石
- **合成结果**: 1个幻魔之心
- **用途**: 提升装备使用等级（成功率100%）

### 3. 灵魂王
- **所需材料**: 20个灵魂晶石
- **合成结果**: 1个灵魂王
- **用途**: 提升装备品质（成功率100%，最高可提升至极品）

### 4. 高级经验石
- **所需材料**: 10个中级经验石
- **合成结果**: 1个高级经验石
- **用途**: 镶嵌到装备上增加经验获取

### 5. 高级战斗力石
- **所需材料**: 10个中级战斗力石
- **合成结果**: 1个高级战斗力石
- **用途**: 镶嵌到装备上增加战斗力

### 4.2 材料检查与消耗

**检查并消耗材料**: `_root.beibao.usethings(itemName, count)`

**功能**: 
- 检查背包中是否有指定数量的物品
- 如果有，则消耗该数量的物品
- 返回 `true` 表示成功，`false` 表示失败

**实现逻辑** (来自 [DefineSprite_572](../scripts/DefineSprite_572/frame_1/DoAction.as)):
```actionscript
function usethings(it_name, it_num)
{
   // 遍历背包查找物品
   i = 0;
   while(i < yn)
   {
      j = 0;
      while(j < xn)
      {
         if(array[i][j] && array[i][j].myid == it_name)
         {
            if(array[i][j].number >= it_num)
            {
               array[i][j].number -= it_num;
               if(array[i][j].number <= 0)
               {
                  removeMovieClip(array[i][j]);
                  array[i][j] = false;
               }
               return true;
            }
            return false;
         }
         j++;
      }
      i++;
   }
   return false;
}
```

### 4.3 物品生成

**添加物品到背包**: `_root.beibao.more(this)`

**功能**:
- 检查背包是否有空位
- 如果有，则创建新物品并添加到背包
- 返回 `true` 表示成功，`false` 表示背包已满

**实现逻辑**:
```actionscript
function more(dsc)
{
   isok = false;
   // 检查背包是否有空位
   i = 0;
   while(i < yn)
   {
      j = 0;
      while(j < xn)
      {
         if(!array[i][j])
         {
            isok = true;
            i = yn;
            j = xn;
         }
         j++;
      }
      i++;
   }
   
   if(!isok)
   {
      _root.alertbox("你的背包已经满了");
      return isok;
   }
   
   src = dsc;
   var _loc3_ = this.getNextHighestDepth();
   this.attachMovie(dsc.id, "wp" + _loc3_, _loc3_);
   return isok;
}
```

## 五、合成逻辑详解

### 5.1 魔魂之心合成


5. 如果失败，显示材料不足提示

## 十、注意事项

### 10.1 合成限制
- 合成成功率均为100%（不同于直接使用基础宝石）
- 需要背包有空位才能合成
- 材料数量必须足够

### 10.2 物品价值对比

| 物品 | 单价 | 合成成本 | 合成结果价值 |
|------|------|---------|------------|
| 魔魂之心 | - | 250,000金币 | 高于基础宝石 |
| 幻魔之心 | - | 2,500,000金币 | 高于基础宝石 |
| 灵魂王 | - | 20,000,000金币 | 高于基础宝石 |

### 10.3 使用建议
- 高级宝石（心、王）的成功率100%，适合重要装备升级
- 基础宝石有失败风险，但成本较低，适合尝试性升级
- 建议在装备等级较高时使用高级宝石

## 十二、代码参考

### 完整代码结构

```actionscript
// 对话函数
function talk()
{
   _root.talk.openme(this);
   words = "我可以帮你合成　魔魂之心、幻魔之心、灵魂王、高级经验石、高级战斗力石。\r";
   words += "\r魔魂之心：需要5个魔魂晶石。";
   words += "\r幻魔之心：需要5个幻魔晶石。";
   words += "\r灵魂王：需要20个灵魂晶石。";
   words += "\r高级经验石：需要10个中级经验石。";
   _root.talk.words(words, "宝石合成师");
   var _loc3_ = 1;
   _root.talk.answer(_loc3_++, "我要合成　魔魂之心");
   _root.talk.answer(_loc3_++, "我要合成　幻魔之心");
   _root.talk.answer(_loc3_++, "我要合成　灵魂王");
   _root.talk.answer(_loc3_++, "我要合成　高级经验石");
}

// 响应函数
function answer(num)
{
   switch(num)
   {
      case 1: // 魔魂之心
      case 2: // 幻魔之心
      case 3: // 灵魂王
      case 4: // 高级经验石
      case 5: // 高级战斗力石
      case 6: // 关闭对话
         _root.talk.closeme();
   }
}

// 事件处理
this.onRelease = function() { talk(); };
this.onRollOver = function() { gotoAndStop(2); };
this.onRollOut = function() { gotoAndStop(1); };
this.onPress = function() { gotoAndStop(3); };
```
