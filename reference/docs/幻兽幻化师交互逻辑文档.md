# 幻兽幻化师交互逻辑文档

## 概述

幻兽幻化师是游戏中用于提升幻兽属性的核心NPC。通过幻化系统，玩家可以将副幻兽的属性转移给主幻兽，大幅提升主幻兽的成长率和属性值。幻化是幻兽养成的核心玩法之一。

**相关代码文件**：
- [frame_6/DoAction.as](scripts/frame_6/DoAction.as) - 幻化核心逻辑函数
- [DefineSprite_822/frame_1/DoAction.as](scripts/DefineSprite_822/frame_1/DoAction.as) - 幻化界面逻辑
- [DefineSprite_680/frame_1/DoAction.as](scripts/DefineSprite_680/frame_1/DoAction.as) - 幻化结果显示
- [DefineSprite_1065/frame_1/DoAction.as](scripts/DefineSprite_1065/frame_1/DoAction.as) - 幻兽拖拽功能

## 幻化条件

### 基本条件

| 条件 | 要求 | 说明 |
|------|------|------|
| 主幻兽等级 | ≥ 50级 | 幻兽必须达到50级才能进行幻化 |
| 副幻兽类型 | 与主幻兽相同 或 奇异兽 | 奇异兽可作为任何类型幻兽的副幻兽 |
| 副幻兽评分 | ≥ 评分要求 | 主幻兽星级越高，对副幻兽评分要求越高 |

### 评分要求计算

当主幻兽评分较高时，会对副幻兽有评分要求：

```actionscript
// 文件: scripts/DefineSprite_822/frame_1/DoAction.as
// 行: 153-160
function yaoqiu(fen)
{
   if(fen < 1500)
   {
      return 0;  // 评分低于1500时无要求
   }
   return Math.floor((fen - 500) / 2);  // 评分要求 = (主幻兽评分 - 500) / 2
}
```

**评分要求对照表**：

| 主幻兽评分 | 副幻兽评分要求 |
|-----------|---------------|
| < 1500 | 无要求 |
| 1500 | 500 |
| 2000 | 750 |
| 2500 | 1000 |
| 3000 | 1250 |

## 幻化效果

幻化会同时进行三种属性转移：
1. **主属性幻化** - 成长率加成（无上限）
2. **副属性幻化** - 生命和防御成长率转移
3. **初始属性幻化** - 初始属性转移

### 主属性幻化

根据幻兽类型不同，主属性（攻击成长）会获得不同的加成系数。

#### 加成系数计算

```actionscript
// 文件: scripts/frame_6/DoAction.as
// 行: 936-1191
// 加成系数 = min(副幻兽评分 / max(主幻兽评分, 20), 2)
// 系数范围: 0 ~ 2
var mainPz = Math.max(bbz.pz, 20);      // 主幻兽评分下限20
var subPz = Math.max(bbf.pz, 40);        // 副幻兽评分下限40
var ratio = Math.min(subPz / mainPz, 2); // 系数上限2
```

#### 各类型幻兽主属性加成

| 幻兽类型 | 最小攻击成长 | 最大攻击成长 | 防御成长 | 生命成长 | 特点 |
|---------|-------------|-------------|---------|---------|------|
| 攻防型 | 1.0 | 1.2 | 0.8 | - | 均衡发展 |
| 调皮鬼 | 0.8 | 1.4 | 0.7 | - | 最大攻击加成最高 |
| 吉鲁猪 | 1.2 | 1.6 | - | - | 攻击加成最高，无防御加成 |
| 奇异兽 | 1.3 | 1.3 | - | - | 攻击均衡，无防御加成 |
| 圣天使 | 0.5 | 0.8 | - | 1.8 | 生命加成最高 |
| 守护 | 1.4 | 1.6 | - | - | 攻击加成高，无防御加成 |
| 年猪 | 1.1 | 1.2 | 1.0 | 1.5 | 全属性加成 |

### 副属性幻化

副属性（生命成长率、防御成长率）的转移规则：

```actionscript
// 文件: scripts/frame_6/DoAction.as
// 行: 1192-1196
function fuhuanhua(zf, ff)
{
   var diff = ff - zf;
   return Math.round((diff <= 0 ? 0 : diff * 0.9) * 10) / 10;
}
```

**转移规则**：
- 只转移副幻兽比主幻兽高的部分
- 转移比例为 90%
- 适用于：生命成长率(cz_hp)、防御成长率(cz_fy)

### 初始属性幻化

初始属性的转移规则：

```actionscript
// 文件: scripts/frame_6/DoAction.as
// 行: 1197-1219
function cuhuanhua(bbz, bbf)
{
   // 初始最小攻击转移
   bbz.cxgj += Math.round((bbf.cxgj - bbz.cxgj <= 0 ? 0 : (bbf.cxgj - bbz.cxgj) * 0.85));
   
   // 初始最大攻击转移
   bbz.cdgj += Math.round((bbf.cdgj - bbz.cdgj <= 0 ? 0 : (bbf.cdgj - bbz.cdgj) * 0.85));
   
   // 初始防御转移
   bbz.cfy += Math.round((bbf.cfy - bbz.cfy <= 0 ? 0 : (bbf.cfy - bbz.cfy) * 0.85));
   
   // 初始生命转移
   bbz.chp += Math.round((bbf.chp - bbz.chp <= 0 ? 0 : (bbf.chp - bbz.chp) * 0.85));
}
```

**转移规则**：
- 只转移副幻兽比主幻兽高的部分
- 转移比例为 85%
- 适用于：初始最小攻击(cxgj)、初始最大攻击(cdgj)、初始防御(cfy)、初始生命(chp)

**注意**：年猪不进行初始属性幻化

## 幻化后效果

### 属性变化

幻化完成后主幻兽会发生以下变化：

| 变化项 | 效果 |
|-------|------|
| 等级 | 重置为1级 |
| 当前经验 | 重置为0 |
| 升级所需经验 | 重置为10 |
| 转世次数 | +1 |
| 评分 | 增加幻化获得的分数 |
| 成长率 | 根据幻化结果提升 |
| 初始属性 | 根据幻化结果提升 |

### 幻化前等级保存

```actionscript
// 文件: scripts/frame_6/DoAction.as
// 行: 1178-1183
bbz.predj = bbz.dj;    // 保存幻化前等级
bbz.prejy = bbz.jy;    // 保存幻化前经验
bbz.premjy = bbz.mjy;  // 保存幻化前升级需求
bbz.jy = 0;            // 重置经验
bbz.mjy = 10;          // 重置升级需求
bbz.dj = 1;            // 重置等级
```

### 顿悟机制

幻化后幻兽升级到50级时有概率触发顿悟：

```actionscript
// 文件: scripts/DefineSprite_139_空幻兽对象/frame_1/DoAction.as
// 行: 250-259
if(dj == 50)
{
   hun = Math.round(mjy * 0.2);
   if(predj > dj)  // predj是幻化前等级
   {
      dj = predj;      // 恢复到幻化前等级
      mjy = premjy;    // 恢复升级所需经验
      jy = prejy;      // 恢复当前经验
      _root.msgbox("幻兽在升级中顿悟了，等级立即升到幻化转世之前的等级" + dj + "级");
   }
}
```

**顿悟条件**：
- 幻兽升级到50级时触发检查
- 幻化前等级(predj) > 当前等级(dj)

**顿悟效果**：
- 等级立即恢复到幻化前等级
- 经验和升级需求同步恢复

```actionscript
function pfxgj(dsc)
```

```actionscript
function setzbb(zb)
```

#### autosetfbb() - 自动设置副幻兽

```actionscript
// 文件: scripts/DefineSprite_822/frame_1/DoAction.as
// 行: 54-68
function autosetfbb()
{
   // 从背包末尾开始查找最低分的奇异兽
   i = _root.huanshoumb.bblen() - 1;
   while(i > 0)
   {
      if(_root.huanshoumb.array[i] && 
         _root.huanshoumb.array[i].hs_name == "奇异兽" && 
         _root.huanshoumb.array[i].pz >= this.yq)
      {
         this.setfbb(_root.huanshoumb.array[i]);
         return true;
      }
      i--;
   }
   _root.alertbox("你的幻兽背包里没有合适的奇异兽了。");
   return false;
}
```

```actionscript
   return false;
```

## 自动幻化功能

### 设置选项

| 选项 | 功能 | 条件 |
|------|------|------|
| 自动放入副幻兽 | 自动选择符合要求的奇异兽作为副幻兽 | 无 |
| 自动使用经验球 | 主幻兽等级不足时自动使用满经验球升级 | 无 |
| 自动幻化 | 满足条件时自动执行幻化 | 角色等级 ≥ 40级 |

### 自动幻化流程

```
1. 放入主幻兽
   ↓
2. 检查是否启用自动放入副幻兽
   ├── 是 → 自动查找符合条件的奇异兽
   └── 否 → 等待手动放入
   ↓
3. 检查是否启用自动幻化
   ├── 是 → 检查等级条件
   │   ├── 等级 ≥ 50 → 执行幻化
   │   └── 等级 < 50 且启用自动使用经验球 → 使用经验球后执行幻化
   └── 否 → 等待手动点击幻化按钮
```

## 幻兽拖拽系统

幻化界面支持拖拽幻兽到指定槽位：

```actionscript
// 文件: scripts/DefineSprite_1065/frame_1/DoAction.as
function doStartDrag(bb)
{
   if(bb == undefined) return false;
   movebb = bb;
   _visible = true;
   startDrag(this, 1);
}

function doAfterDrag()
{
   stopDrag();
   if(movebb == null) return false;
   
   // 检测拖拽目标
   if(this.hitTest(_root.huanhuak.fbaokou))
   {
      _root.huanhuak.setfbb(movebb);  // 放入副幻兽槽
   }
   else if(this.hitTest(_root.huanhuak.zbaokou))
   {
      _root.huanhuak.setzbb(movebb);  // 放入主幻兽槽
   }
   
   _visible = false;
   movebb = null;
}
```

```actionscript

if(bbz.cz_xgj > bbz.cz_dgj)
{
   bbz.cz_dgj = bbz.cz_xgj;  // 最大攻击成长 = 最小攻击成长
```

### 年猪特殊处理

年猪幻化有以下特殊规则：
1. 不进行初始属性幻化

## 设计模式

幻化系统采用了以下设计模式：

1. **策略模式** - 不同幻兽类型有不同的加成策略
2. **模板方法模式** - 幻化流程固定，具体加成由子类实现
3. **观察者模式** - 幻化完成后更新相关界面
4. **建造者模式** - 幻化结果信息的构建

---

## 注意事项

1. **副幻兽会被消耗** - 幻化后副幻兽会消失，请谨慎选择
2. **等级重置** - 幻化后主幻兽等级重置为1级
3. **顿悟概率** - 幻化后升级到50级有概率触发顿悟恢复等级
4. **评分要求** - 高星级幻兽幻化时对副幻兽有评分要求
5. **奇异兽特殊** - 奇异兽可作为任何类型幻兽的副幻兽
