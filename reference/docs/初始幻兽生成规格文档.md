# 初始幻兽生成规格文档

## 一、概述

新游戏开始时，系统会自动为玩家生成两只攻防型幻兽，并设置为出征和合体状态，帮助新手玩家快速上手游戏。

---

| 文件路径 | 功能说明 |
|---------|---------|
| [scripts/DefineSprite_443/frame_2/DoAction.as](../scripts/DefineSprite_443/frame_2/DoAction.as) | 生成第一只攻防型幻兽 |
| [scripts/DefineSprite_443/frame_3/DoAction.as](../scripts/DefineSprite_443/frame_3/DoAction.as) | 设置第一只出征，生成第二只 |
| [scripts/DefineSprite_443/frame_4/DoAction.as](../scripts/DefineSprite_443/frame_4/DoAction.as) | 设置第二只出征，初始化物品 |
| [scripts/DefineSprite_613/frame_1/DoAction.as](../scripts/DefineSprite_613/frame_1/DoAction.as) | 攻防型幻兽属性生成逻辑 |

## 三、触发条件

| 条件 | 说明 |
|------|------|
| `_root.newgame == true` | 新游戏标记，在 frame_4 中设置，在 frame_5 中结束 |
| 触发位置 | DefineSprite_443 的 frame_2、frame_3、frame_4 |

### 新游戏标记流程

```
frame_4: _root.newgame = true   (玩家输入名称后)
    ↓
frame_5: _root.newgame = false  (开始游戏判断)
    ↓
DefineSprite_443/frame_2~4: 检查 _root.newgame 并执行初始化
```

## 五、攻防型幻兽属性生成

### 5.1 newbb 函数

```actionscript
function newbb(newpz)
{
   flashme(newpz);                  // 生成幻兽属性
   _root.huanshoumb.givebb(this);   // 添加到幻兽背包
}
```

### 5.2 flashme 函数 - 属性生成

```actionscript
function flashme(newpz)
{
   // ========== 基础信息 ==========
   zs = 0;                              // 转世次数
   hs_name = othername = "攻防型";       // 幻兽名称
   dj = 1;                              // 等级为1
   
   // ========== 随机生成初始属性 ==========
   cxgj = random(5) + 10;               // 初始最小攻击: 10-14
   cdgj = random(30 - cxgj) + cxgj;     // 初始最大攻击: cxgj ~ 29
   cfy = random(5) + 5;                 // 初始防御: 5-9
   chp = random(15) + 20;               // 初始生命: 20-34
   
   // ========== 随机生成成长属性 ==========
   cz_xgj = 8 + random(4);              // 最小攻击成长: 8-11
   cz_dgj = random(17 - cz_xgj) + cz_xgj; // 最大攻击成长
   cz_fy = 1 + random(6);               // 防御成长: 1-6
   cz_hp = 30 + random(12);             // 生命成长: 30-41
   
   // ========== 随机加成 (12.5%概率触发其中一种) ==========
   switch(random(8))
   {
      case 0: cxgj = random(100); break;           // 初始最小攻击大加成
      case 1: cdgj = random(100 - cxgj) + cxgj; break; // 初始最大攻击大加成
      case 2: cfy = random(100); break;            // 初始防御大加成
      case 3: chp = random(291); break;            // 初始生命大加成 (0-290)
      case 4: 
         cz_xgj = random(21);                      // 最小攻击成长大加成 (0-20)
         if(cz_dgj < cz_xgj) cz_dgj = cz_xgj;      // 确保最大攻击成长 >= 最小攻击成长
         break;
      case 5: cz_dgj = random(26 - cz_xgj) + cz_xgj; break; // 最大攻击成长大加成
      case 6: cz_fy = random(16); break;           // 防御成长大加成 (0-15)
      case 7: cz_hp = random(41); break;           // 生命成长大加成 (0-40)
   }
   
   // ========== 计算当前属性值 ==========
   hp = mhp = cz_hp * (dj - 1) + chp;
   dgj = cz_dgj * (dj - 1) + cdgj;
   xgj = cz_xgj * (dj - 1) + cxgj;
   fy = cz_fy * (dj - 1) + cfy;
   mjy = 10;                             // 升级所需经验
   jy = 0;                               // 当前经验
   
   // ========== 计算评分 ==========
   pzbase = 0;                           // 攻防型基础评分为0
   pz_chp = pz_cxgj = pz_cdgj = pz_cfy = 0;
   _root.pfc(this);                      // 计算初始属性评分
   pz_cz_hp = pz_cz_xgj = pz_cz_dgj = pz_cz_fy = 0;
   _root.pfhp(this);                     // 计算生命成长评分
   _root.pfxgj(this);                    // 计算最小攻击成长评分
   _root.pfdgj(this);                    // 计算最大攻击成长评分
   _root.pffy(this);                     // 计算防御成长评分
   
   // 计算总评分
   pz = pzbase + pz_chp + pz_cxgj + pz_cdgj + pz_cfy + 
        pz_cz_hp + pz_cz_xgj + pz_cz_dgj + pz_cz_fy;
   
   // 额外评分加成（用于特殊幻兽）
   if(newpz)
   {
      pz += newpz;
   }
}
```

## 十、设计意图

### 10.1 为什么是两只幻兽

1. **新手友好**: 玩家开局就拥有两只出征且合体的幻兽，可以立即体验完整的战斗系统
2. **属性加成**: 两只幻兽的属性都会加成到角色，提升新手期的战斗力
3. **伤害分担**: 合体状态下幻兽会替角色承受伤害，降低新手死亡风险

### 10.2 为什么是攻防型

1. **均衡发展**: 攻防型幻兽攻击和防御都是主属性，适合新手培养
2. **基础评分低**: pzbase = 0，让玩家有明确的幻兽提升目标
3. **价格最低**: 魔石商人售价仅1魔石，是最便宜的幻兽
