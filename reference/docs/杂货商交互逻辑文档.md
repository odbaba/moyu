# 杂货商交互逻辑文档

## 一、概述

杂货商（代码中称为"加货商"，jiahuoshang）是游戏中的重要NPC，位于卡萨诺城。玩家可以与杂货商进行物品交易，包括购买消耗品和出售物品。

**核心文件位置**：
- 商店界面：[scripts/DefineSprite_609/frame_1/DoAction.as](../../scripts/DefineSprite_609/frame_1/DoAction.as)
- NPC按钮：[scripts/frame_12/PlaceObject2_1159_39/CLIPACTIONRECORD on(release).as](../../scripts/frame_12/PlaceObject2_1159_39/CLIPACTIONRECORD on(release).as)
- 地图场景：[scripts/frame_11/DoAction.as](../../scripts/frame_11/DoAction.as)

## 二、杂货商位置

### 地图信息
- **所在地图**：卡萨诺城（frame_11）
- **地图类型**：安全区域（无怪物）
- **访问方式**：通过frame_12的NPC按钮交互

玩家点击杂货商NPC时，触发以下逻辑：


## 四、出售系统

### 4.1 出售流程

玩家可以将物品拖拽到杂货商界面进行出售：

1. **拖拽物品**：玩家从背包拖拽物品
2. **检测目标**：物品的`doAfterDrag()`函数检测是否拖到杂货商界面
3. **添加到商店**：调用`_root.jiahuoshang.movethings(this)`
4. **计算价值**：自动计算物品的出售价格
5. **获得金币**：点击出售按钮后获得金币

### 4.2 拖拽检测逻辑

所有物品类都有`doAfterDrag()`函数，检测拖拽目标：

```actionscript
function doAfterDrag()
{
   // ... 其他检测 ...
   
   // 检测是否拖到杂货商界面
   else if(this.hitTest(_root.jiahuoshang.baokou))
   {
      if(!_root.jiahuoshang.movethings(this))
      {
         _parent.getroom(this);  // 如果失败，返回原位置
      }
   }
   
   // ... 其他检测 ...
}
```

### 4.3 物品价值计算

#### 出售价格公式

```actionscript
function countvalue(wp, flag)
{
   // 出售价格为物品价值的75%
   myjb += flag * wp.getjbvalue() * 0.75;
   jb.text = showjb(myjb);  // 更新显示
}
```

#### 物品价值获取

每个物品都有`getjbvalue()`函数返回其金币价值：

```actionscript
function getjbvalue()
{
   return price_jb;  // 返回物品的基础价格
}
```

#### 示例：银矿的价值

```actionscript
// 银矿的价值计算
myid = "银矿";
if(pz == 10)
{
   price_jb = 500000;  // 品质10的银矿价值50万
}
else
{
   price_jb = pz * 10000;  // 其他品质：品质 × 1万
}
```

### 4.4 出售操作

玩家点击出售按钮时：

```actionscript
function sell()
{
   // 清空商店界面中的所有物品
   i = 0;
   while(i < yn)
   {
      j = 0;
      while(j < xn)
      {
         if(array[i][j] != false)
         {
            removeMovieClip(array[i][j]);  // 移除物品
            array[i][j] = false;
         }
         j++;
      }
      i++;
   }
   
   // 增加玩家金币
   _root.beibao.subjb(myjb);
   myjb = 0;  // 重置价值
   jb.text = showjb(myjb);  // 更新显示
}
```

## 六、数据结构

### 6.1 商店格子数组

```actionscript
// 商店界面是一个4×3的格子
xn = 4;  // 横向4格
yn = 3;  // 纵向3格
array = new Array(yn);

// 初始化数组
i = 0;
while(i < yn)
{
   array[i] = new Array(xn);
   j = 0;
   while(j < xn)
   {
      array[i][j] = false;  // false表示空格
      j++;
   }
   i++;
}
```

### 6.2 物品位置计算

```actionscript
function getroom(dsc)
{
   // 寻找空格
   var _loc2_ = yj = -1;
   i = 0;
   while(i < yn)
   {
      j = 0;
      while(j < xn)
      {
         if(!array[i][j])  // 找到空格
         {
            array[i][j] = dsc;
            countvalue(dsc, 1);  // 计算价值
            _loc2_ = i;
            yj = j;
            i = yn;
            j = xn;
         }
         j++;
      }
      i++;
   }
   
   // 设置物品位置
   if(_loc2_ != -1 && yj != -1)
   {
      dsc.xi = _loc2_;
      dsc.yj = yj;
      dsc._x = xbase + base * yj + offset;  // 166 + 40 * j + 4
      dsc._y = ybase + base * _loc2_ + offset;  // 81 + 40 * i + 4
   }
}
```

## 七、交互流程图

```
玩家点击杂货商NPC
    ↓
关闭所有界面（CloseAll）
    ↓
打开杂货商界面（jiahuoshang.openme）
    ↓
打开背包界面（beibao.openme）
    ↓
玩家选择操作：
    ├─→ 购买物品
    │       ↓
    │   选择物品（设置thing和price_jb）
    │       ↓
    │   点击购买按钮
    │       ↓
    │   检查金币是否足够
    │       ↓
    │   扣除金币，添加物品到背包
    │
    └─→ 出售物品
            ↓
        从背包拖拽物品
            ↓
        拖到杂货商界面
            ↓
        物品添加到商店格子
            ↓

            ↓
        点击出售按钮
```

### 9.1 物品描述提示


### 9.2 出售价格比例

杂货商的收购价格为物品价值的**75%**，这意味着玩家会损失25%的价值。这是游戏经济系统的设计，鼓励玩家通过其他方式（如收藏家）出售高价值物品。

- 显示位置：(285, 90)
- 隐藏位置：(800, 600) - 屏幕外

## 十一、总结

杂货商是游戏中重要的经济系统组成部分，提供了基础的物品交易功能：

1. **购买功能**：玩家可以购买各种消耗品、宝石和技能书
2. **出售功能**：玩家可以出售不需要的物品获得金币（75%价值）
3. **界面交互**：通过拖拽方式进行物品交易
4. **经济平衡**：通过75%的收购价格，控制游戏经济平衡

杂货商系统与背包系统、金币系统紧密配合，构成了游戏的基础经济循环。
