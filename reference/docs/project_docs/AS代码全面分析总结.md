## 2. 游戏系统实现分析

### 2.1 玩家角色系统 (`DefineSprite_932/frame_1/DoAction.as`)

#### 核心属性
```actionscript
// 基本属性
dj      // 等级 (1-132)
hp/mhp  // 当前生命值/最大生命值
tl/mtl  // 当前体力/最大体力
xgj/dgj // 最小攻击力/最大攻击力
fy      // 防御力
zdl     // 战斗力

// 称号系统
jxdj    // 军衔等级 (0-11)
jwdj    // 爵位等级 (0-6)
gzgx    // 公主关系 (0-6)
xy      // 幸运值 (0-100)
```

#### 核心方法
- `hitsb()` - 攻击怪物
- `byhit()` - 受到伤害
- `flashdata()` - 更新角色数据
- `have_exp()` - 获得经验值
- `have_exp_only()` - 仅获得经验（不升级）

#### 经验系统
- 最大等级: 132
- 经验计算公式: 基于当前等级和获得经验值
- 等级提升: 触发属性增长和技能解锁

### 2.2 怪物系统 (`DefineSprite_124_怪物对象/frame_1/DoAction.as`)

#### 怪物属性
- 名称、等级、生命值、攻击力、防御力、战斗力
- 掉落物品类型和概率
- 经验值奖励（等于怪物最大生命值）

#### 战斗逻辑
- `hitsb()` - 怪物攻击玩家
- `byhit()` - 受到玩家攻击
- 死亡处理: 触发`_root.creatething.drop1()`生成掉落物品
- 经验奖励: `_root.xinxi.have_exp(mhp)`

### 2.3 装备系统 (`DefineSprite_164_武器/frame_1/DoAction.as`)

#### 装备属性
```actionscript
dj      // 装备等级
pz      // 品质 (0-4)

```

#### 装备操作
- 拖放: 可拖放到背包、仓库、NPC
- 装备: 等级要求检查，装备位置验证
- 强化: 品质提升、魔魂升级、打孔、镶嵌

### 2.4 战斗系统

#### 伤害计算流程
1. **基础伤害**: `xgj + random(dgj - xgj + 1)`
2. **技能倍率**: 技能特定的伤害倍数 (0.5x - 1.5x)
3. **战斗力修正**: 基于玩家和怪物的战斗力差值
4. **防御减免**: 减去目标的防御力
5. **暴击判定**: 基于幸运值和暴击率

#### 命中类型系统
代码中定义了8种命中类型 (0-7):
- 0: 普通命中 (1.0x)
- 1: 暴击 (1.5x)
- 2: 闪避 (0x)
- 3-7: 特殊命中类型 (0.6x - 1.2x)

### 2.5 技能系统

#### 技能类型
1. **单体攻击技能**: 高级风斩、飞天连斩
2. **群体攻击技能**: 高级地裂爆斩、星魔剑
3. **增益技能**: 斗志抑扬（提升战斗力）
4. **特殊技能**: 爱的力量（回复生命）

#### 技能触发

## 4. 核心算法和计算公式

### 4.1 战斗力计算算法

```
总战斗力 = 基础战斗力(等级)
         + 军衔战斗力
         + 爵位战斗力
         + 幻兽战斗力(宠物1 + 宠物2)
         + 装备品质战斗力
         + 魔魂等级战斗力
         + 宝石孔战斗力
         + 宝石属性战斗力
         + 技能加成战斗力
         + 战魂加成战斗力
```

### 4.2 装备属性成长公式

```
武器攻击力 = (10×等级 ～ 30×等级) + 追加攻击
头盔防御力 = 6×等级 + 追加防御
衣服防御力 = 8×等级 + 追加防御
战鞋防御力 = 4×等级 + 追加防御

追加属性 = floor(基础属性/10) × 魔魂等级
```

### 4.3 怪物属性生成公式

```
生命值 = 基础生命 + 生命成长 × 等级
攻击力 = 基础攻击 + 攻击成长 × 等级
防御力 = 基础防御 + 防御成长 × 等级
经验值 = 怪物最大生命值
```

### 4.4 伤害计算算法

```
1. 计算基础伤害范围: [最小攻击力, 最大攻击力]
2. 随机基础伤害: 基础攻击力 + rand(最大-最小+1)
3. 应用技能倍率: 基础伤害 × 技能倍率
4. 战斗力修正: 根据玩家-怪物战斗力差值调整
5. 防御减免: 伤害 - 目标防御力
6. 暴击判定: 基于幸运值，暴击时×1.5
7. 命中类型: 8种命中类型(0-7)对应不同倍率
```

## 5. 系统交互和流程

### 5.1 战斗流程

```
1. 玩家进入地图 (frame_X)
2. 怪物生成系统激活 (DefineSprite_118_选择怪物)
3. 战斗开始 (zhanchang系统)
   ├─ 玩家回合
   │   ├─ 选择目标
   │   ├─ 执行攻击 (hitsb)
   │   │   ├─ 技能检查 (jineng)
   │   │   ├─ 伤害计算
   │   │   └─ 幻兽协同攻击 (czmb0/czmb1)
   │   └─ 更新战斗状态
   └─ 怪物回合
       ├─ AI选择目标
       ├─ 执行攻击 (byhit)
       └─ 更新战斗状态
4. 战斗结束条件
   ├─ 怪物死亡
   │   ├─ 掉落物品生成 (creatething.drop1/drop2)
   │   └─ 经验奖励 (xinxi.have_exp)
   └─ 玩家死亡
       ├─ 幸运值减少10点
       └─ 经验损失5%
```

### 5.2 装备强化流程

```
装备强化入口
├─ 品质提升 (使用灵魂晶石/灵魂王)
│   └─ 品质等级: 0(白)→1(绿)→2(蓝)→3(紫)→4(橙)
├─ 魔魂提升 (使用魔魂晶石/魔魂之心)
│   └─ 魔魂等级: 0→1→2→...→12
├─ 等级提升 (使用幻魔晶石/幻魔之心)
│   └─ 装备等级: +10级
├─ 打孔 (使用月光宝盒/月光宝盒增强版)
│   └─ 宝石孔: 0→1→2
├─ 宝石镶嵌 (使用战斗力石/经验石)
│   └─ 孔位填充: dong1, dong2
└─ 战魂激活 (使用战魂晶石/战魂之心)
    └─ 战魂类型: 0→1/2, 战魂等级: 1→5
```
