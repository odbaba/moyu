# 幻兽系统技术文档

## 概述

幻兽系统是游戏的核心战斗辅助系统，玩家可以携带最多两只幻兽参与战斗。幻兽具有独立的属性、成长系统和幻化进化机制。通过幻化可以大幅提升幻兽的属性成长率。

## 幻化系统

### 幻化规则

幻化是将副幻兽的属性转移给主幻兽的过程，可以大幅提升主幻兽的成长率。

### 幻化条件
- 主幻兽等级 ≥ 50级
- 需要一只副幻兽作为材料

### 幻化效果

```actionscript
// 文件: scripts/frame_6/DoAction.as
// 行: 936-1191
function huanhua(bbz, bbf)
{
   // bbz: 主幻兽, bbf: 副幻兽
   
   // 计算成长率加成系数
   // 主幻兽评分下限为20，副幻兽评分下限为40，系数上限为2
   var mainPz = Math.max(bbz.pz, 20);
   var subPz = Math.max(bbf.pz, 40);
   var ratio = Math.min(subPz / mainPz, 2);
   
   // 根据幻兽类型分配成长加成
   switch(bbz.hs_name)
   {
      case "攻防型":
         bbz.cz_xgj += ratio * 1.0;
         bbz.cz_dgj += ratio * 1.2;
         bbz.cz_fy += ratio * 0.8;
         break;
      case "调皮鬼":
         bbz.cz_xgj += ratio * 0.8;
         bbz.cz_dgj += ratio * 1.4;  // 最大攻击加成最高
         bbz.cz_fy += ratio * 0.7;
         break;
      case "吉鲁猪":
         bbz.cz_xgj += ratio * 1.2;
         bbz.cz_dgj += ratio * 1.6;  // 攻击加成最高
         break;
      case "奇异兽":
         bbz.cz_xgj += ratio * 1.3;
         bbz.cz_dgj += ratio * 1.3;
         break;
      case "圣天使":
         bbz.cz_xgj += ratio * 0.5;
         bbz.cz_dgj += ratio * 0.8;
         bbz.cz_hp += ratio * 1.8;  // 生命加成最高
         break;
      case "守护":
         bbz.cz_xgj += ratio * 1.4;
         bbz.cz_dgj += ratio * 1.6;
         break;
      case "年猪":
         bbz.cz_xgj += ratio * 1.1;
         bbz.cz_dgj += ratio * 1.2;
         bbz.cz_fy += ratio * 1.0;
         bbz.cz_hp += ratio * 1.5;
         break;
   }
   
   // 副属性转移（副幻兽比主幻兽高的部分×90%）
   bbz.cz_hp += fuhuanhua(bbz.cz_hp, bbf.cz_hp);
   bbz.cz_fy += fuhuanhua(bbz.cz_fy, bbf.cz_fy);
   
   // 初始属性转移（副幻兽比主幻兽高的部分×85%）
   bbz.cxgj += Math.max(bbf.cxgj - bbz.cxgj, 0) * 0.85;
   bbz.cdgj += Math.max(bbf.cdgj - bbz.cdgj, 0) * 0.85;
   bbz.cfy += Math.max(bbf.cfy - bbz.cfy, 0) * 0.85;
   bbz.chp += Math.max(bbf.chp - bbz.chp, 0) * 0.85;
   
   // 更新评分和转世次数
   bbz.pz += 总加分;
   bbz.zs++;
   
   // 重置等级
   bbz.predj = bbz.dj;
   bbz.dj = 1;
   bbz.jy = 0;
   bbz.mjy = 10;
}
```

## 经验与升级系统

### 等级限制

| 限制类型 | 条件 | 说明 |
|----------|------|------|
| 最高等级 | dj >= 130 | 幻兽等级已满，无法再获得经验 |
| 角色关联 | dj >= 角色等级+10 | 幻兽等级已高于人物10级，无法再获得经验 |

### 经验获取

```actionscript
// 文件: scripts/DefineSprite_139_空幻兽对象/frame_1/DoAction.as
// 行: 106-176
function have_exp(exps)
{
   // 等级上限检查
   if(dj >= 130)
   {
      _root.msgbox("幻兽等级已满，无法再获得经验值了。");
      jy = 0;
      return false;
   }
   
   // 不能超过人物等级+10
   if(dj >= _root.xinxi.dj + 10)
   {
      _root.msgbox("幻兽等级已高于人物的10级，无法再获得经验值了。");
      return false;
   }
   
   // 幻兽获得双倍经验
   exps *= 2;
   jy += exps;
   
   // 升级处理
   while(jy >= mjy)
   {
      jy -= mjy;
      dj++;
      
      // 经验需求递增
      if(dj < 20) mjy = Math.round(mjy * 1.2);
      else if(dj <= 50) mjy = Math.round(mjy * 1.1);
      else mjy += hun;
      
      // 50级提示可幻化
      if(dj == 50)
      {
         _root.alertbox("你的幻兽达到50级了，可以到幻化大师那里进行幻化。");
      }
   }
}
```

## 幻兽评分排序规则

幻兽背包中的幻兽会按照特定规则自动排序。

### 排序公式

```
排序值 = 评分 + 出征状态 × 1000000
```

### 排序规则

1. **出征幻兽优先**: 出征中的幻兽始终排在背包最前面
2. **评分从高到低**: 同为出征或非出征状态时，评分高的排在前面

### 代码实现

```actionscript
// 文件: scripts/DefineSprite_787/frame_1/DoAction.as
// 行: 164-210
function reversebb()
{
   // ... 排序逻辑
   if(array[_loc2_].pz + array[_loc2_].chuzheng * 1000000 < 
      array[_loc1_].pz + array[_loc1_].chuzheng * 1000000)
   {
      // 交换位置
      _loc3_ = array[_loc2_];
      array[_loc2_] = array[_loc1_];
      array[_loc1_] = _loc3_;
      array[_loc2_].number = _loc2_;
      array[_loc1_].number = _loc1_;
   }
}
```

```actionscript
{
```

```actionscript
   {
      return (point.pz - point.pz % 100) / 100;
   }
   return 0;
}
```

**注意**: 幻兽战斗力只与评分相关，与等级、转世次数无关。
