# 幻兽系统技术文档

## 概述

幻兽系统是游戏的核心战斗辅助系统，玩家可以携带最多两只幻兽参与战斗。幻兽具有独立的属性、成长系统和幻化进化机制。通过幻化可以大幅提升幻兽的属性成长率。

## 幻兽评分系统

### 评分计算公式

```
总评分 = 基础评分 + 初始属性评分 + 成长属性评分
```

### 初始属性评分计算

```actionscript
// 文件: scripts/frame_6/DoAction.as
// 行: 919-935
function pfc(dsc)
{
   // 初始属性评分（基于标准值差值×2）
   dsc.pz_cxgj = (dsc.cxgj - 15) <= 0 ? 0 : (dsc.cxgj - 15) * 2;
   dsc.pz_cdgj = (dsc.cdgj - 25) <= 0 ? 0 : (dsc.cdgj - 25) * 2;
   dsc.pz_cfy = (dsc.cfy - 10) <= 0 ? 0 : (dsc.cfy - 10) * 2;
   dsc.pz_chp = (dsc.chp - 100) <= 0 ? 0 : (dsc.chp - 100) * 2;
}
```

## 幻化系统

### 幻化规则

幻化是将副幻兽的属性转移给主幻兽的过程，可以大幅提升主幻兽的成长率。

### 幻化条件
- 主幻兽等级 ≥ 50级
- 需要一只副幻兽作为材料

### 幻化效果

```actionscript
// 文件: scripts/frame_6/DoAction.as
// 行: 936-1191
function huanhua(bbz, bbf)
{
   // bbz: 主幻兽, bbf: 副幻兽
   
   // 计算成长率加成系数
   // 主幻兽评分下限为20，副幻兽评分下限为40，系数上限为2
   var mainPz = Math.max(bbz.pz, 20);
   var subPz = Math.max(bbf.pz, 40);
   var ratio = Math.min(subPz / mainPz, 2);
   
   // 根据幻兽类型分配成长加成
   switch(bbz.hs_name)
   {
      case "攻防型":
         bbz.cz_xgj += ratio * 1.0;
         bbz.cz_dgj += ratio * 1.2;
         bbz.cz_fy += ratio * 0.8;
         break;
      case "调皮鬼":
         bbz.cz_xgj += ratio * 0.8;
         bbz.cz_dgj += ratio * 1.4;  // 最大攻击加成最高
         bbz.cz_fy += ratio * 0.7;
         break;
      case "吉鲁猪":
         bbz.cz_xgj += ratio * 1.2;
         bbz.cz_dgj += ratio * 1.6;  // 攻击加成最高
         break;
      case "奇异兽":
         bbz.cz_xgj += ratio * 1.3;
         bbz.cz_dgj += ratio * 1.3;
         break;
      case "圣天使":
         bbz.cz_xgj += ratio * 0.5;
         bbz.cz_dgj += ratio * 0.8;
         bbz.cz_hp += ratio * 1.8;  // 生命加成最高
         break;
      case "守护":
         bbz.cz_xgj += ratio * 1.4;
         bbz.cz_dgj += ratio * 1.6;
         break;
      case "年猪":
         bbz.cz_xgj += ratio * 1.1;
         bbz.cz_dgj += ratio * 1.2;
         bbz.cz_fy += ratio * 1.0;
         bbz.cz_hp += ratio * 1.5;
         break;
   }
   
   // 副属性转移（副幻兽比主幻兽高的部分×90%）
   bbz.cz_hp += fuhuanhua(bbz.cz_hp, bbf.cz_hp);
   bbz.cz_fy += fuhuanhua(bbz.cz_fy, bbf.cz_fy);
   
   // 初始属性转移（副幻兽比主幻兽高的部分×85%）
   bbz.cxgj += Math.max(bbf.cxgj - bbz.cxgj, 0) * 0.85;
   bbz.cdgj += Math.max(bbf.cdgj - bbz.cdgj, 0) * 0.85;
   bbz.cfy += Math.max(bbf.cfy - bbz.cfy, 0) * 0.85;
   bbz.chp += Math.max(bbf.chp - bbz.chp, 0) * 0.85;
   
   // 更新评分和转世次数
   bbz.pz += 总加分;
   bbz.zs++;
   
   // 重置等级
   bbz.predj = bbz.dj;
   bbz.dj = 1;
   bbz.jy = 0;
   bbz.mjy = 10;
}
```

### 幻化后等级恢复

幻化后幻兽等级重置为1级，但在升级过程中有概率"顿悟"，直接恢复到幻化前等级：

```actionscript
// 文件: scripts/DefineSprite_139_空幻兽对象/frame_1/DoAction.as
// 行: 151-170
if(dj == 50)
{
   hun = Math.round(mjy * 0.2);
   if(predj > dj)  // predj是幻化前的等级
   {
      dj = predj;      // 恢复到幻化前等级
      mjy = premjy;    // 恢复升级所需经验
      jy = prejy;      // 恢复当前经验

   }
}
```

{
   // 等级上限检查
   if(dj >= 130)
   {
      _root.msgbox("幻兽等级已满，无法再获得经验值了。");
      jy = 0;

      return false;

   // 幻兽获得双倍经验
   exps *= 2;
   jy += exps;

   while(jy >= mjy)
   {
      jy -= mjy;
      dj++;
      
      // 经验需求递增
      if(dj < 20) mjy = Math.round(mjy * 1.2);
      else if(dj <= 50) mjy = Math.round(mjy * 1.1);

      }
   }

## 幻兽战斗力系统

### 战斗力计算公式

幻兽战斗力直接由评分决定：

```
幻兽战斗力 = Math.floor(评分 / 100)
```

例如：
- 评分 0-99 → 战斗力 0
- 评分 100-199 → 战斗力 1
- 评分 1000-1099 → 战斗力 10

### 角色总战斗力计算

幻兽战斗力是角色总战斗力的重要组成部分：

```actionscript
// 文件: scripts/DefineSprite_932/frame_1/DoAction.as
// 行: 241-356
function flashzdl()
{
   // 初始化所有战斗力组成部分
   zdl = jbzdl = jxzdl = jwzdl = hs1zdl = hs2zdl = zbpzzdl = mhdjzdl = dongzdl = bszdl = fixzdl = bestbszdl = zhzdl = 0;
   
   // 基础战斗力 = 等级
   jbzdl = dj;
   
   // 军衔战斗力
   // 少尉=1, 中尉=2, 上尉=3, 少校=5, 中校=10, 上校=15, 少将=20, 中将=30, 上将=40, 大将=50, 元帅=60
   
   // 爵位战斗力
   // 勋爵=2, 子爵=6, 伯爵=12, 公爵=20, 侯爵=30, 王=50
   
   // 获取两只出征幻兽的战斗力
   hs1zdl = _root.czmb0.getzdl();
   hs2zdl = _root.czmb1.getzdl();
   
   // 记录历史最高幻兽战斗力
   var _loc2_ = hs1zdl <= hs2zdl ? hs2zdl : hs1zdl;  // 较高的战斗力
   var _loc3_ = hs1zdl >= hs2zdl ? hs2zdl : hs1zdl;  // 较低的战斗力
   if(_loc2_ >= hs1_maxzdl)
   {
      hs1_maxzdl = _loc2_;
      if(_loc3_ >= hs2_maxzdl)
      {
         hs2_maxzdl = _loc3_;
      }
   }
   
   // 装备相关战斗力
   zbpzzdl = _root.zhuangbei.getpz();      // 装备品质战斗力
   mhdjzdl = _root.zhuangbei.getmhdj();    // 追加等级战斗力
   dongzdl = _root.zhuangbei.getdong();    // 镶嵌孔战斗力
   bszdl = _root.zhuangbei.getbs();        // 宝石战斗力
   fixzdl = _root.zhuangbei.getfix();      // 修复战斗力
   bestbszdl = _root.zhuangbei.bestbszdl;  // 最佳宝石战斗力
   
   // 计算基础总战斗力
   zdl = jbzdl + jxzdl + jwzdl + hs1zdl + hs2zdl + zbpzzdl + mhdjzdl + dongzdl + bszdl + fixzdl + bestbszdl;
   
   // 技能战斗力加成
   jnjc = _root.jineng.getjnjc();
   jnzdl = Math.round(jnjc * zdl);
   
   // 综合战斗力加成
   zhzdl = Math.round(_root.zhuangbei.zhzdlrace() * zdl);
   
   // 最终战斗力
   zdl += jnzdl + zhzdl;
   
   return zdl;
}
```

### 战斗力对战斗的影响

#### 战斗力差值影响伤害

```actionscript
// 文件: scripts/DefineSprite_932/frame_1/DoAction.as
// 行: 141-165
function byhit(hit, it_zdl)
{
   // 闪避判定
   if(random(100) < miss)
   {
      hithp = 0;
      mubiao.setshanghai();
      return false;
   }
   
   var _loc4_;
   // 敌人战斗力 > 我方战斗力：受到的伤害增加
   if(it_zdl > zdl)
   {
      _loc4_ = it_zdl - zdl <= 20 ? it_zdl - zdl : 20;  // 最多计算20点差距
      hit += _loc4_ * 0.05 * hit;  // 每点差距增加5%伤害
   }
   // 我方战斗力 > 敌人战斗力：受到的伤害减少
   else if(it_zdl < zdl)
   {
      _loc4_ = zdl - it_zdl <= 50 ? zdl - it_zdl : 50;  // 最多计算50点差距
      hit -= _loc4_ * 0.01 * hit;  // 每点差距减少1%伤害
   }
   
   // 减去防御
   hit -= fy;
   hit = Math.round(hit);
   if(hit < 0) hit = 1;
   
   // ... 后续处理
}
```

#### 战斗力影响规则

| 场景 | 计算方式 | 上限 |
|------|----------|------|
| 敌人战力高于我方 | 每高1点，受到伤害+5% | 最多+100%（20点差距） |
| 我方战力高于敌人 | 每高1点，受到伤害-1% | 最多-50%（50点差距） |

#### 战斗力对经验的影响

```
战斗经验加成 = (战斗力 - 等级) × 5%
```

战斗力比等级每高1点，战斗获得的经验增加5%。

| 途径 | 说明 |
|------|------|
| 提升评分 | 战斗力 = 评分/100，提升评分直接提升战斗力 |
| 幻化 | 通过幻化提升成长率，间接提升评分 |
