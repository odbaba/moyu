# 物品系统技术文档 - 装备类

## 概述

装备系统是游戏的核心成长系统之一，玩家通过穿戴装备提升角色的攻击力、防御力等属性。装备具有品质、魔魂等级、宝石镶嵌和战魂等多重强化维度。

### 武器 (myid: "武器")

**基本信息**

- 类型: 主手武器
- 主要属性: 攻击力
- 装备位置: 武器栏

**属性计算公式**

| 属性        | 基础公式    | 追加公式                        |
| --------- | ------- | --------------------------- |
| 最小攻击(xgj) | 10 × dj | Math.floor(xgj / 10) × mhdj |
| 最大攻击(dgj) | 30 × dj | Math.floor(dgj / 10) × mhdj |

**代码引用**

```actionscript
// 文件: scripts/DefineSprite_164_武器/frame_1/DoAction.as
```

## 品质系统

### 品质等级

| 品质值 | 品质名称 | 颜色代码         | 说明    |
| --- | ---- | ------------ | ----- |
| 0   | 普通品  | #ffffff (白色) | 最基础品质 |
| 1   | 良品   | #00ff00 (绿色) | 略有提升  |
| 2   | 上品   | #0000ff (蓝色) | 中等品质  |
| 3   | 精品   | #ff0000 (红色) | 高品质   |
| 4   | 极品   | #cc00ff (紫色) | 最高品质  |

### 品质对战斗力的影响

品质值直接加到战斗力计算中：

```
战斗力 += pz (所有装备pz之和)
```

**代码引用**

```actionscript
// 文件: scripts/DefineSprite_561/frame_1/DoAction.as
// 行: 165-193
function getpz()
{
   var _loc1_ = 0;
   if(wuqi.item) _loc1_ += wuqi.item.pz;
   if(toukui.item) _loc1_ += toukui.item.pz;
   if(shouzhuo.item) _loc1_ += shouzhuo.item.pz;
   if(xianglian.item) _loc1_ += xianglian.item.pz;
   if(yifu.item) _loc1_ += yifu.item.pz;
   if(zhanxie.item) _loc1_ += zhanxie.item.pz;
   return _loc1_;
}
```

## 魔魂系统

### 魔魂等级

魔魂等级范围: 0-12级

### 魔魂效果

魔魂等级提供追加属性：

**攻击型装备:**

```
追加最小攻击 = Math.floor(基础最小攻击 / 10) × mhdj
追加最大攻击 = Math.floor(基础最大攻击 / 10) × mhdj
```

**防御型装备:**

```
追加防御 = Math.floor(基础防御 / 10) × mhdj
```

### 魔魂对战斗力的影响

战斗力取所有装备中最低的魔魂等级：

```
战斗力 += min(所有装备mhdj)
```

**代码引用**: [DefineSprite\_561/frame\_1/DoAction.as](scripts/DefineSprite_561/frame_1/DoAction.as#L194-L264)

| ------ | ------- | ----- |

| 高级经验石  | 经验值+50% | 0     |

### 宝石对战斗力的影响

```
战斗力 += 宝石战斗力之和
```

**代码引用**


## 价值计算

### 金币价值

```actionscript
function getjbvalue()
{
   return 100 * dj * (pz + 1) + 100 * mhdj + 10000 * dong * dong * dong;
}
```

**公式解析:**

- 等级价值: 100 × dj × (pz + 1)
- 魔魂价值: 100 × mhdj
- 宝石洞价值: 10000 × dong³

### 魔石价值（仅极品）

```actionscript
function getmsvalue()
{
   if(pz == 4)
   {
      return 28 * (dj * 2.5 + 50) + mhdj * 128 + 1500 * dong * dong * dong;
   }
   return 0;
}
```

**公式解析（仅pz=4时）:**

- 等级价值: 28 × (dj × 2.5 + 50)
- 魔魂价值: mhdj × 128
- 宝石洞价值: 1500 × dong³

## 装备掉落规则

### 普通怪物掉落

```actionscript
// 文件: scripts/DefineSprite_443/frame_1/DoAction.as
// 行: 161-227
if(random(100) < 25)  // 25%概率掉落装备
{
   // 等级处理
   if(dj < 10) dj = 1;
   else if(dj > 100) dj = 125;
   else if(dj % 10) dj -= dj % 10;  // 取整十级
   
   // 品质随机
   pz = 0;
   if(random(100) < 30) pz = 1;  // 30%良品
   if(random(100) < 30) pz = 2;  // 30%上品
   if(random(200) < 5 * baoli) pz = 3;  // 2.5%精品
   if(random(200) < 5 * baoli) pz = 4;  // 2.5%极品
   
   // 魔魂等级随机
   if(random(100) < 90) mhdj = random(10);  // 0-9
   else mhdj = 9 + random(4);  // 9-12
   
   // 宝石洞随机
   dong = 0;
   if(random(100) < 5) dong = random(2);  // 5%有洞
   
   // 装备类型随机
   switch(random(6))
   {
      case 0: id = "武器"; break;
      case 1: id = "头盔"; break;
      case 2: id = "项链"; break;
      case 3: id = "衣服"; break;
      case 4: id = "手镯"; break;
      case 5: id = "战鞋"; break;
   }
}
```

### BOSS掉落

```actionscript
// 文件: scripts/DefineSprite_443/frame_1/DoAction.as
// 行: 364-410
```

## 核心函数

### setmydim() - 初始化装备属性

**功能**: 从数据源加载装备属性

**代码引用**: 各装备文件 L1-L26

### doAfterDrag() - 拖拽后处理

**功能**: 处理装备拖拽后的放置逻辑

**支持的目标位置:**

- 装备栏（需等级满足）
- 背包
- 仓库
- 垃圾箱（删除）

### swapitem() - 装备交换

**功能**: 当目标位置已有装备时，交换两件装备的属性

### flashcount() - 刷新属性计算

**功能**: 重新计算装备的基础属性和追加属性

### nowplayto() - 更新显示

**功能**: 根据装备等级和位置更新装备外观
