# 抽奖系统文档

## 一、系统概述

抽奖系统是游戏中的一个特色功能，玩家可以花费魔石在抽奖房进行抽奖，有机会获得各种稀有物品和幻兽。

## 三、抽奖流程

### 1. 进入抽奖房

玩家通过与"抽奖官"NPC对话，选择"好吧，让我来试试我的运气"进入抽奖房。

```
抽奖官对话内容：
"国家为了鼓励勇士们英勇奋战，特别开设一抽奖房。抽奖房里的宝箱有各种各样的好东西，甚至是稀世极品，只要你花上28魔石就能打开一个宝箱，每个宝箱都有可能得到极品的哦。"
```

### 2. 抽奖费用

- 每次抽奖需要 **28魔石**
- 通过 `_root.beibao.subms(-28)` 扣除魔石
- 如果魔石不足，提示："你不够28点魔石了，不能抽奖费啦。"

### 3. 抽奖概率机制

抽奖使用 `random(1000)` 生成 0-999 的随机数，根据随机值范围确定奖品等级：

| 奖品等级 | 随机值范围 | 概率 | 说明 |
|---------|-----------|------|------|
| **极品奖励** | 0-19 | 2% | 幸运女神青睐，播放升级音效 |
| **高级奖励** | 20-69 | 5% | 稀有物品 |
| **中级奖励** | 70-449 | 38% | 较好物品 |
| **普通奖励** | 450-999 | 55% | 基础物品 |

- 头盔
- 项链
- 衣服
- 手镯
- 战鞋

## 六、核心代码逻辑

```actionscript
function openbox()
{
   // 1. 检查魔石是否足够
   if(!_root.beibao.subms(-28))
   {
      _root.alertbox("\r\r你不够28点魔石了，不能抽奖费啦。");
      return false;
   }
   
   // 2. 消耗时间（2点）
   _root.mc_day.times_go(2);
   
   // 3. 生成随机数（0-999）
   var _loc3_ = random(1000);
   
   // 4. 根据随机值范围确定奖品
   if(_loc3_ < 20)        // 极品奖励 2%
   else if(_loc3_ < 70)   // 高级奖励 5%
   else if(_loc3_ < 450)  // 中级奖励 38%
   else                   // 普通奖励 55%
   
   // 5. 显示结果消息
   _root.msgbox(_root.xinxi.myname + "意气风发，获得了" + id);
}
```

## 七、相关系统调用

### 背包系统 (`_root.beibao`)

- `subms(-28)` - 扣除28魔石
- `more(this)` - 添加物品到背包

### 幻兽系统 (`_root.moshishang`)

- `nz.newbb()` - 生成噜噜幻兽
- `ts.newbb()` - 生成圣天使幻兽
- `xo8.newbb()` - 生成8星奇异兽
- `xo12.newbb()` - 生成12星奇异兽

### 时间系统 (`_root.mc_day`)

- `times_go(2)` - 消耗2点时间

## 八、交互流程图

```
玩家点击抽奖官 NPC
       ↓

       ↓

       ↓

       ↓

       ↓

       ↓

```

## 九、注意事项

1. **时间消耗**：每次抽奖消耗2点时间
2. **魔石消耗**：每次抽奖消耗28魔石，不可撤销
3. **概率说明**：所有概率为独立事件，每次抽奖概率相同
4. **装备绑定**：抽奖获得的装备等级与玩家等级相关
