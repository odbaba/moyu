# 角色系统技术文档

## 概述

角色系统是游戏的核心系统之一，定义了玩家角色的所有属性、成长规则和战斗机制。玩家通过战斗获取经验升级，提升军衔和爵位，并与公主建立关系。

## 战斗力计算公式

### 总战斗力公式

```
总战斗力 = 基础战斗力 + 军衔战斗力 + 爵位战斗力 
         + 幻兽1战斗力 + 幻兽2战斗力 
         + 装备品质战斗力 + 魔魂等级战斗力 
         + 宝石洞战斗力 + 宝石战斗力 
         + 装备修正战斗力 + 技能加成战斗力 + 战魂加成战斗力
```

### 战斗力组成

| 组成部分 | 计算方式 | 说明 |
|----------|----------|------|
| jbzdl | dj | 基础战斗力 = 等级 |
| jxzdl | 军衔对应值 | 军衔战斗力 |
| jwzdl | 爵位对应值 | 爵位战斗力 |
| hs1zdl | 幻兽1战斗力 | 取两只幻兽中较高者 |
| hs2zdl | 幻兽2战斗力 | 取两只幻兽中较低者 |
| zbpzzdl | 装备品质总和 | 所有装备pz之和 |
| mhdjzdl | 最低魔魂等级 | 取所有装备中最低mhdj |
| dongzdl | 宝石洞总数 | 所有装备dong之和 |
| bszdl | 宝石战斗力 | 战斗力石加成 |
| fixzdl | 装备等级修正 | 装备等级是否匹配 |
| jnzdl | Math.round(jnjc × zdl) | 技能加成 |
| zhzdl | Math.round(zhzdlrace × zdl) | 战魂加成 |

**代码引用**
```actionscript
// 文件: scripts/DefineSprite_932/frame_1/DoAction.as
// 行: 186-300
function flashzdl()
{
   jbzdl = dj;
   // ... 计算各部分战斗力
   zdl = jbzdl + jxzdl + jwzdl + hs1zdl + hs2zdl 
       + zbpzzdl + mhdjzdl + dongzdl + bszdl + fixzdl + bestbszdl;
   jnzdl = Math.round(jnjc * zdl);
   zhzdl = Math.round(_root.zhuangbei.zhzdlrace() * zdl);
   zdl += jnzdl + zhzdl;
}
```

## 闪避系统

### 闪避率计算

闪避率来自装备的战魂系统，只有地魂战魂才能提供闪避加成。

**闪避率公式**
```
miss = Σ(装备.zhdj × 2%)  // 仅计算地魂战魂(zhtype=2)的装备
```

**战魂类型与效果**

| 战魂类型 | zhtype | 效果 |
|----------|--------|------|
| 天魂 | 1 | 攻击力+zhdj×5% |
| 地魂 | 2 | 闪避率+zhdj×2% |

**代码引用**
```actionscript
// 文件: scripts/DefineSprite_561/frame_1/DoAction.as
// 行: 476-509
function zhmiss()
{
   if(_root.openzh != true)
   {
      return 0;
   }
   var _loc2_ = 0;
   var _loc3_ = 2;  // 每级战魂提供2%闪避
   if(wuqi.item.zhtype == 2)
   {
      _loc2_ += wuqi.item.zhdj * _loc3_;
   }
   // ... 其他装备同理
   return _loc2_;
}
```

### 闪避判定

在受击时进行闪避判定：
```actionscript
if(random(100) < miss)
{
   return false;  // 闪避成功，不受到伤害
}
```

## 经验加成系统

### 经验加成计算

玩家获得的经验会受到多种加成影响：

**经验加成公式**
```
more_exp = (zdl - dj) × 0.05 + bs_exp
实际经验 = 怪物hp × (1 + more_exp) / 100
```

**加成来源**

| 加成来源 | 计算方式 | 说明 |
|----------|----------|------|
| 战斗力加成 | (zdl - dj) × 0.05 | 战斗力超过等级的部分，每点加成5% |
| 宝石加成 | bs_exp | 装备上镶嵌的经验石 |

**宝石经验加成**

| 宝石类型 | 经验加成 |
|----------|----------|
| 中级经验石 | +25% |
| 高级经验石 | +50% |

**代码引用**
```actionscript
// 文件: scripts/DefineSprite_932/frame_1/DoAction.as
// 行: 23-26
bs_exp = _root.zhuangbei.getbsexp();

// 行: 302-309
```

## 战斗系统

### 攻击计算

```actionscript
// 文件: scripts/DefineSprite_932/frame_1/DoAction.as
// 行: 53-85
function hitsb(hittype, dsc)
{
   hit = xgj + random(dgj - xgj + 1);  // 基础伤害
   switch(hittype)
   {
      case 0: hit *= 1; break;      // 普通攻击
      case 1: hit *= 1.5; break;    // 暴击
      case 2: hit *= 0.6; break;    // 减速攻击
      case 3: hit *= 0.75; break;   // 减防攻击
      case 5: hit *= 1.5; break;    // 技能攻击
      case 6: hit *= 1; dsc.byhit(hit, zdl, true); break; // 破防攻击
   }
   dsc.byhit(hit, zdl);
}
```

### 受击计算

```actionscript
// 文件: scripts/DefineSprite_932/frame_1/DoAction.as
// 行: 86-140
function byhit(hit, it_zdl)
{
   // 闪避判定
   if(random(100) < miss) return false;
   
   // 战斗力差距修正
   if(it_zdl > zdl) {
      hit += (it_zdl - zdl) * 0.05 * hit;  // 敌人更强，伤害增加
   } else if(it_zdl < zdl) {
      hit -= (zdl - it_zdl) * 0.01 * hit;  // 敌人更弱，伤害减少
   }
   
   // 防御减伤
   hit -= fy;
   if(hit < 0) hit = 1;
   
   hp -= hit;
   if(hp <= 0) {
      // 死亡处理
      xy -= 10;           // 幸运值-10
      jy -= Math.round(jy * 0.05);  // 经验-5%
   }
}
```

## 核心函数

### flashdata() - 刷新数据

**功能**: 重新计算所有属性值

**代码引用**: [DefineSprite_932/frame_1/DoAction.as](scripts/DefineSprite_932/frame_1/DoAction.as#L1-L27)

```actionscript
function flashdata()
{
   miss = _root.zhuangbei.zhmiss();
   mhp = base_hp + cz_hp * dj;
   mtl = base_tl + cz_tl * dj;
   xgj = base_xgj + cz_xgj * dj + _root.zhuangbei.getxgj();
   dgj = base_dgj + cz_dgj * dj + _root.zhuangbei.getdgj();
   fy = base_fy + cz_fy * dj + _root.zhuangbei.getfy();
   // 幻兽加成
   if(_root.czmb0.InOne && _root.czmb0._visible) {
      xgj += _root.czmb0.point.xgj;
      dgj += _root.czmb0.point.dgj;
      fy += _root.czmb0.point.fy;
   }
   // 战魂加成
   xgj = Math.round(xgj * (1 + _root.zhuangbei.zhgj()));
   dgj = Math.round(dgj * (1 + _root.zhuangbei.zhgj()));
}
```
