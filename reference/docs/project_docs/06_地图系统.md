# 地图系统技术文档

## 概述

地图系统定义了游戏中的所有场景区域，包括怪物分布、NPC位置、传送点和特殊事件。玩家在不同地图中战斗、探索和完成任务。

### BOSS刷新概率

```actionscript
// 文件: scripts/frame_6/DoAction.as
// 行: 95-134
function flashboss()
{
   boss10 = boss20 = boss30 = boss50 = boss70 = boss90 = boss100 = bossZZ = bossDZZ = false;
   
   if(random(100) < 55) boss10 = true;   // 55%概率刷新
   if(random(100) > 55) boss20 = true;   // 45%概率刷新
   if(random(100) < 33) boss30 = true;   // 33%概率刷新
   if(random(100) > 77) boss50 = true;   // 23%概率刷新
   if(random(100) < 33) boss70 = true;   // 33%概率刷新
   if(random(100) > 77) boss90 = true;   // 23%概率刷新
   if(random(100) < 33) boss100 = true;  // 33%概率刷新
   if(random(100) > 77) bossZZ = true;   // 23%概率刷新
   if(random(100) < 33) bossDZZ = true;  // 33%概率刷新
}
```

## 特殊地图事件

### 魔族军队复活

```actionscript
// 文件: scripts/frame_6/DoAction.as
// 行: 145-155
function flashmj()
{
   if(_root.mj_gj == false || _root.mj_fy == false || _root.mj_tt == false || 
      _root.mj_sm == false || _root.mj_zs == false || _root.mj_nl == false)
   {
      if(_root.king == true)
      {
         _root.alertbox("\r黑夜到来时，魔的能量将\r所有死亡的魔族军队复活了");
      }
   }
   _root.mj_gj = _root.mj_fy = _root.mj_tt = _root.mj_sm = _root.mj_zs = _root.mj_nl = true;
}
```
