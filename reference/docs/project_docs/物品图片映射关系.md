# 物品与PNG图片映射关系

本文档说明游戏中物品与PNG图片文件之间的映射关系，帮助理解如何通过物品ID找到对应的图片资源。

---

## 1. 核心机制

### attachMovie 链接机制

游戏使用 Flash/ActionScript 的 `attachMovie()` 函数从库中创建物品实例：

```actionscript
// 文件: scripts/DefineSprite_561/frame_1/DoAction.as
// 行: 58
this.attachMovie(dsc.myid, "wp" + _loc2_, _loc2_);
```

**参数说明**：
- 第一个参数：库链接标识符（linkage identifier），对应物品的 `myid`
- 第二个参数：实例名称
- 第三个参数：深度层级

### 物品标识符 (myid)

每个物品都有唯一的 `myid` 属性，用于标识物品类型：

```actionscript
myid = "武器";    // 武器
myid = "头盔";    // 头盔
myid = "体力药";  // 体力药
myid = "星魔剑";  // 技能书
```

---

## 2. 目录结构映射

### 资源目录 (scripts/)

物品脚本和PNG图片都存放在 `scripts/DefineSprite_编号_名称/` 目录中：

```
scripts/
└── DefineSprite_164_武器/
    ├── frame_1/
    │   └── DoAction.as      # 武器逻辑代码
    ├── 1.png                # 第1帧图片
    ├── 2.png                # 第2帧图片
    └── ...                  # 更多帧和代码
```

**重要说明**：PNG图片直接存放在 `DefineSprite_编号_名称/` 目录根目录下，而不是单独的 `sprites/` 目录。

## 3. 具体示例

### 示例1：武器（多帧装备）

**物品信息**：
- myid: "武器"
- DefineSprite编号: 164

**文件路径**：
```
scripts/
└── DefineSprite_164_武器/
    ├── frame_1/
    │   └── DoAction.as      # 武器逻辑代码
    ├── 1.png                # 第1帧图片
    ├── 2.png                # 第2帧图片
    ├── 3.png                # 第3帧图片
    └── ...                  # 更多帧（共77个PNG）
```

**代码逻辑**：
```actionscript
// scripts/DefineSprite_164_武器/frame_1/DoAction.as
// 行: 211
myid = "武器";

// 行: 164-178 - 根据使用等级要求显示不同帧
function nowplayto(n)
{
   if(n)
   {
      gotoAndStop(n);
   }
   else if(_parent._name == "zhuangbei" || _parent._name == "zbjingliank")
   {
      gotoAndStop(dj + 1 + "s");  // 装备状态：跳转到帧标签 "(dj+1)s"
   }
   else
   {
      gotoAndStop(dj + "s");      // 背包状态：跳转到帧标签 "djs"
   }
}
```

**重要说明**：

1. **`dj` 是"使用等级要求"**，不是"装备等级"
   - 表示玩家需要达到多少级才能使用该装备
   - 代码证据：`texts2 += "\r使用等级 " + dj;`（第298行）

2. **帧标签与PNG文件编号是不同的概念**：
   - `gotoAndStop(dj + "s")` 跳转到**帧标签**为 `"djs"` 的帧
   - PNG文件编号（如1.png, 2.png）对应的是**帧编号**，不是帧标签
   - 帧标签和帧编号之间的映射关系需要通过Flash源文件或实际测试确定

**实际观察到的映射**（用户测试结果）：

| 使用等级要求(dj) | 背包显示PNG | 装备显示PNG |
|------------------|-------------|-------------|
| 1级 | 2.png, 3.png, 4.png | 5.png, 6.png, 7.png |
| 10级 | 8.png, 9.png, 10.png | 11.png, 12.png, 13.png |

**注意**：帧标签（如"1s", "2s"）与PNG文件编号的精确映射关系需要进一步分析Flash源文件确定。

## 5. 映射关系总结图

```
┌─────────────────────────────────────────────────────────────┐
│                    物品创建流程                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  代码: attachMovie("武器", "wp1", 1)                        │
│              ↓                                              │
│  myid = "武器"  ←→  Flash库链接标识符                        │
│              ↓                                              │
│  DefineSprite_164_武器 (库元件)                             │
│              ↓                                              │
│  ┌─────────────────────────────────────┐                   │
│  │ scripts/DefineSprite_164_武器/      │                   │
│  │   ├── frame_1/DoAction.as           │                   │
│  │   ├── 1.png  (第1帧)                │                   │
│  │   ├── 2.png  (第2帧)                │                   │
│  │   └── ...                           │                   │
│  └─────────────────────────────────────┘                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 快速查找公式

```
物品myid → DefineSprite编号 → scripts/DefineSprite_编号_名称/N.png
```

**示例**：
- 查找"体力药"图片：`myid="体力药"` → 编号=37 → `scripts/DefineSprite_37_体力药/1.png`
- 查找"武器"使用等级要求5的图片：`myid="武器"` → 编号=164 → `scripts/DefineSprite_164_武器/` 目录下对应帧的PNG
