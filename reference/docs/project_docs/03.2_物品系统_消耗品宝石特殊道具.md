## 七、物品通用函数

### finding() - 物品堆叠检测

**功能**: 检查背包中是否有相同物品，有则堆叠

```actionscript
function finding()
{
   var _loc3_ = false;
   i = 0;
   while(i < _parent.yn)
   {
      j = 0;
      while(j < _parent.xn)
      {
         if(_parent.array[i][j].myid == myid)
         {
            _parent.array[i][j].number += number;
            _loc3_ = true;
            break;
         }
         j++;
      }
      i++;
   }
   if(_loc3_) removeMovieClip(this);
   else _parent.getroom(this);
}
```
