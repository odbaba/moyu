## 七、装备名称显示逻辑

### 名称获取函数

```actionscript
// 文件: scripts/DefineSprite_164_武器/frame_X/DoAction.as
// 每个帧对应一个装备名称
names = "装备名称";
```

### 外观显示函数

```actionscript
// 文件: scripts/DefineSprite_164_武器/frame_1/DoAction.as
// 行: 164-178
function nowplayto(n)
{
   if(n)
   {
      gotoAndStop(n);
   }
   else if(_parent._name == "zhuangbei" || _parent._name == "zbjingliank")
   {
      gotoAndStop(dj + 1 + "s");  // 装备栏显示
   }
   else
   {
      gotoAndStop(dj + "s");  // 背包显示
   }
}
```

## 八、装备属性计算

### 武器攻击力

```
基础最小攻击 = 10 × dj
基础最大攻击 = 30 × dj
追加最小攻击 = floor(基础最小攻击 / 10) × mhdj
追加最大攻击 = floor(基础最大攻击 / 10) × mhdj
```

### 头盔防御力

```
基础防御 = 6 × dj
追加防御 = floor(基础防御 / 10) × mhdj
```

### 衣服防御力

```
基础防御 = 8 × dj
追加防御 = floor(基础防御 / 10) × mhdj
```

### 战鞋防御力

```
基础防御 = 4 × dj
追加防御 = floor(基础防御 / 10) × mhdj
```

### 手镯攻击力

```
基础最小攻击 = 5 × dj
基础最大攻击 = 15 × dj
追加最小攻击 = floor(基础最小攻击 / 10) × mhdj
追加最大攻击 = floor(基础最大攻击 / 10) × mhdj
```

### 项链攻击力

```
基础最小攻击 = 8 × dj
基础最大攻击 = 20 × dj
追加最小攻击 = floor(基础最小攻击 / 10) × mhdj
追加最大攻击 = floor(基础最大攻击 / 10) × mhdj
```
