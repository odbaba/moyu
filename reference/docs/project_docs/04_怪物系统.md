# 怪物系统技术文档

## 概述

怪物系统是游戏战斗的核心组成部分，定义了所有敌对生物的属性、行为和掉落规则。怪物分为普通怪物、BOSS怪物、魔族军队和特殊怪物四大类，分布在不同的地图中。

## 怪物属性系统

### 通用属性参数

| 属性名   | 类型     | 说明    |
| ----- | ------ | ----- |
| names | String | 怪物名称  |
| gwzdl | Number | 战斗力   |
| dj    | Number | 等级    |
| hp    | Number | 当前生命值 |
| mhp   | Number | 最大生命值 |
| xgj   | Number | 最小攻击力 |
| dgj   | Number | 最大攻击力 |
| fy    | Number | 防御力   |

### 属性计算公式

```
最大生命值(mhp) = 基础生命 + 生命成长 × 等级
最小攻击力(xgj) = 基础最小攻击 + 最小攻击成长 × 等级
最大攻击力(dgj) = 基础最大攻击 + 最大攻击成长 × 等级
防御力(fy) = 基础防御 + 防御成长 × 等级
经验值 = 怪物最大生命值
```

### setprop函数定义

```actionscript
// 文件: scripts/DefineSprite_124_怪物对象/frame_1/DoAction.as
// 行: 10-28
function setprop(zdl, gwdj, base_hp, base_xgj, base_dgj, base_fy, cz_hp, cz_xgj, cz_dgj, cz_fy)
{
   gwzdl = zdl;          // 战斗力
   dj = gwdj;            // 等级
   mhp = base_hp + cz_hp * dj;      // 最大生命值
   hp = base_hp + cz_hp * dj;       // 当前生命值
   xgj = base_xgj + cz_xgj * dj;    // 最小攻击力
   dgj = base_dgj + cz_dgj * dj;    // 最大攻击力
   fy = base_fy + cz_fy * dj;       // 防御力
   
   // 战魂套装效果
   if(_root.zhuangbei.zhth() == 1)  // 天魂套装
   {
      gwzdl = Math.round(gwzdl * (1 - _root.zhuangbei.zhjj() * 0.02));
   }
   else if(_root.zhuangbei.zhdh() == 1)  // 地魂套装
   {
      hp = Math.round(mhp * (1 - _root.zhuangbei.zhjj() * 0.05));
   }
   upxx();
}
```

## 七、战斗系统

### 伤害计算

```actionscript
// 文件: scripts/DefineSprite_124_怪物对象/frame_1/DoAction.as
// 行: 34-80
function byhit(hit, it_zdl, heavy)
{
   // 战斗力差距修正
   if(it_zdl > gwzdl)
   {
      var _loc6_ = it_zdl - gwzdl <= 50 ? it_zdl - gwzdl : 50;
      hit += _loc6_ * 0.05 * hit;  // 敌人更强，伤害增加
   }
   else if(it_zdl < gwzdl)
   {
      var _loc6_ = gwzdl - it_zdl <= 50 ? gwzdl - it_zdl : 50;
      hit -= _loc6_ * 0.01 * hit;  // 敌人更弱，伤害减少
   }
   
   // 防御减伤（破防攻击除外）
   if(heavy != true)
   {
      hit -= fy;
   }
   
   hit = Math.round(hit);
   if(hit < 0) hit = 1;
   
   hp -= hit;
   if(hp <= 0)
   {
      // 死亡处理，触发掉落
      _root.creatething.gwname = names;
      _root.creatething.drop1();  // 普通怪物掉落
      _root.xinxi.have_exp(mhp);  // 给予经验
      _parent.freeroom(this);
   }
}
```

### 普通怪物掉落 (drop1)

```actionscript
// 文件: scripts/DefineSprite_443/frame_1/DoAction.as
// 行: 1-286
function drop1()
{
   _root.hidegw();
   baoli = 1 + (_root.xinxi.xy + 1) / 100;  // 暴率 = 1 + (幸运值+1)/100
   
   // 金币掉落
   _root.beibao.subjb(6 * (20 + dj) * 10 * baoli);
   
   // 灵魂晶石 (2.5%概率)
   if(random(200) < 5 * baoli)
   {
      id = "灵魂晶石";
      _root.beibao.more(this);
   }
   
   // 装备掉落 (25%概率)
   if(random(100) < 25)
   {
      // 等级处理
      if(dj < 10) dj = 1;
      else if(dj > 100) dj = 125;
      else if(dj % 10) dj -= dj % 10;
      
      // 品质随机
      pz = 0;
      if(random(100) < 30) pz = 1;  // 良品
      if(random(100) < 30) pz = 2;  // 上品
      if(random(200) < 5 * baoli) pz = 3;  // 精品
      if(random(200) < 5 * baoli) pz = 4;  // 极品
      
      // 魔魂等级随机
      if(random(100) < 90) mhdj = random(10);
      else mhdj = 9 + random(4);
      
      // 宝石洞随机
      dong = 0;
      if(random(100) < 5) dong = random(2);
      
      // 装备类型随机
      switch(random(6))
      {
         case 0: id = "武器"; break;
         case 1: id = "头盔"; break;
         case 2: id = "项链"; break;
         case 3: id = "衣服"; break;
         case 4: id = "手镯"; break;
         case 5: id = "战鞋"; break;
      }
      _root.beibao.more(this);
   }
}
```
