## 核心公式汇总

### 战斗力计算

```
总战斗力 = 基础战斗力(dj) 
         + 军衔战斗力(jxzdl) 
         + 爵位战斗力(jwzdl) 
         + 幻兽战斗力(hs1zdl + hs2zdl) 
         + 装备品质战斗力(zbpzzdl) 
         + 魔魂等级战斗力(mhdjzdl) 
         + 宝石洞战斗力(dongzdl) 
         + 宝石战斗力(bszdl) 
         + 技能加成战斗力(jnzdl) 
         + 战魂加成战斗力(zhzdl)
```

### 伤害计算

```
基础伤害 = xgj + random(dgj - xgj + 1)
实际伤害 = 基础伤害 × 技能倍率 × 战斗力修正 - 防御力
```

### 装备属性计算

```
武器攻击力 = 10×dj ~ 30×dj + 追加攻击
头盔防御力 = 6×dj + 追加防御
衣服防御力 = 8×dj + 追加防御
战鞋防御力 = 4×dj + 追加防御
追加攻击/防御 = floor(基础属性/10) × mhdj
```

### 怪物属性计算

```
生命值 = 基础生命 + 生命成长 × 等级
攻击力 = 基础攻击 + 攻击成长 × 等级
防御力 = 基础防御 + 防御成长 × 等级
经验值 = 怪物最大生命值
```

### 战斗流程

```
1. 进入地图 (frame_X)
      │
      ▼
2. 怪物生成 (DefineSprite_118_选择怪物)
      │
      ▼
3. 战斗开始 (zhanchang)
      │
      ├─► 玩家攻击 (hitsb)
      │       │
      │       ├─► 技能触发 (jineng)
      │       │
      │       └─► 幻兽攻击 (czmb0/czmb1)
      │
      └─► 怪物攻击 (byhit)
              │
              └─► 伤害计算 (战斗力修正 - 防御)
      │
      ▼
4. 战斗结束
      │
      ├─► 怪物死亡
      │       │
      │       └─► 掉落物品 (creatething.drop1/drop2)
      │
      └─► 玩家死亡
              │
              └─► 幸运值-10, 经验-5%
```
