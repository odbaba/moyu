# 技能系统技术文档

## 概述

技能系统定义了玩家可学习和使用的战斗技能。技能通过使用技能书学习，部分技能可以升级。技能在战斗中自动触发，提供额外的伤害输出或增益效果。

**重要说明**：技能消耗的是**体力值(TL)**，而非MP。风斩（等级1）不消耗体力。

### studyjn(n, m) - 学习技能

**功能**: 学习或升级技能

**参数**:
- n: 技能索引 (0-5)
- m: 技能等级

**代码引用**
```actionscript
// 文件: scripts/DefineSprite_731/frame_1/DoAction.as
// 行: 45-77
function studyjn(n, m)
{
   var _loc3_;
   var _loc2_;
   var _loc5_;
   if(!jineng[n])  // 新技能
   {
      _loc3_ = 0;
      _loc2_ = 0;
      while(_loc2_ < jns)
      {
         _loc3_ += jineng[_loc2_] <= 0 ? 0 : 1;
         _loc2_ = _loc2_ + 1;
      }
      jineng[n] = m;
      this["jn" + n]._visible = true;
      this["jn" + n]._y = ybase + _loc3_ * base;
      this["jn" + n]._x = xbase;
      openme();
      _loc5_ = new Sound();
      _loc5_.attachSound("学习技能.wav");
      _loc5_.start();
   }
   else if(jineng[n] < m)  // 升级
   {
      jineng[n] = m;
      openme();
      _loc5_ = new Sound();
      _loc5_.attachSound("学习技能.wav");
      _loc5_.start();
   }
   updata();
}
```

### 技能伤害计算

```actionscript
// 文件: scripts/DefineSprite_932/frame_1/DoAction.as
// 行: 108-140
function hitsb(hittype, dsc)
{
   hit = xgj + random(dgj - xgj + 1);
   switch(hittype)
   {
      case 0: hit *= 1; break;      // 普通攻击（风斩）
      case 1: hit *= 1.5; break;    // 高级风斩
      case 2: hit *= 0.6; break;    // 裂地爆斩（群体）
      case 3: hit *= 0.75; break;   // 高级裂地爆斩（群体）
      case 4: hit *= 1; break;      // 星魔剑（群体）
      case 5: hit *= 1.5; break;    // 高级星魔剑（群体）
      case 6: hit *= 1; dsc.byhit(hit, zdl, true); break; // 高级飞天连斩（破防）
      case 7: hit *= 1; break;      // 飞天连斩
   }
   dsc.byhit(hit, zdl);
}
```
