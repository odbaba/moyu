## 二、对话交互流程

### 2.1 初始对话

当玩家点击装备打造师时，触发 `talk()` 函数：

```actionscript
function talk()
{
   _root.talk.openme(this);
   words = "　　精练能使你的装备属性更好，战斗力更高。";
   words = "\r　　装备精练说明：装备精练分五种，提升装备品质、提升装备魔魂等级、提升装备使用等级、装备开洞和镶嵌宝石。";
   words += "\r\r你需要些什么服务？";
   _root.talk.words(words,"元帅");
   
   var _loc3_ = 1;
   _root.talk.answer(_loc3_++,"我要精练我的装备");
   _root.talk.answer(_loc3_++,"关于提升魔魂等级");
   _root.talk.answer(_loc3_++,"关于提升品质");
   _root.talk.answer(_loc3_++,"关于装备开洞");
   _root.talk.answer(_loc3_++,"关于镶嵌宝石");
   if(_root.openzh == true)
   {
      _root.talk.answer(_loc3_++,"关于战魂");
   }
}
```

### 2.2 对话选项

| 选项 | 功能 | 说明 |
|------|------|------|
| 1. 我要精练我的装备 | 打开精练界面 | 同时打开背包和装备栏 |
| 2. 关于提升魔魂等级 | 显示帮助信息 | 解释魔魂系统 |
| 3. 关于提升品质 | 显示帮助信息 | 解释品质系统 |
| 4. 关于装备开洞 | 显示帮助信息 | 解释开洞系统 |
| 5. 关于镶嵌宝石 | 显示帮助信息 | 解释镶嵌系统 |
| 6. 关于战魂 | 显示帮助信息 | 仅当战魂系统开启时显示 |

### 2.3 帮助信息内容

#### 关于提升魔魂等级
```
提升魔魂等级：魔魂等级最高可以+12，魔魂等级可以追加装备的攻击或防御属性，每一级追加装备基本属性的10%。
如果全套装备都有魔魂等级还可以加战斗力，比如全套装备都是魔魂等级+9的就加9战斗力。
魔魂等级可以用[魔魂晶石]或[魔魂之心]来提升，[魔魂之心]在+9之前可以使用，成功率为100%，+9之后只能用[魔魂晶石]追加。
魔魂等级在升级时如果成功则升一级，如果失败就会降一级，+9之后不会再降低于+9了。
```

#### 关于提升品质
```
提升品质：装备品质有白品、良品、上品、精品、极品五个等级，
白品加1战斗力、良品加2战斗力、上品加3战斗力、精品加4战斗力、极品加5战斗力。
装备的品质可以用[灵魂晶石]或[灵魂王]来精练提升等级。
```

#### 关于装备开洞
```
装备开洞：可以用[月光宝盒]或[月光宝盒加强版]给装备开洞，
开第一个洞时要使用[月光宝盒]，开第二个洞时要使用[月光宝盒加强版]。
先把装备放上，把月光宝盒放到"宝石"的位置，再点开始。
```

#### 关于镶嵌宝石
```
镶嵌宝石：可以给有[洞]的装备镶嵌宝石，可以镶嵌中级经验石、中级战斗力石、高级经验石和高级战斗力石。
一个洞只能镶嵌一个宝石。
```

#### 关于战魂
```
谢谢你，年轻的勇士。我已经看懂了你带给我有关战魂的秘密。
装备在升极品时或都开洞时都可能会使装备激发出战魂，但是机率非常之小。
在BOSS手中有一种叫做[战魂晶石]的宝石用来激发装备战魂机率较高。
还有一种叫做[战魂之心]的稀有宝石，可惜不知来源...
只有在精练装备的时候战魂等级才可能得到提升，所以对于战魂装备来说，越差的装备升级潜力越大。
```

## 四、精练功能详解

### 4.1 提升品质

| 宝石 | 成功率 | 说明 |
|------|--------|------|
| 灵魂晶石 | 25%-50% | 白品→良品100%，良品→上品50%，上品→精品25% |
| 灵魂王 | 100% | 必定成功，最高到极品 |

**代码逻辑：**
```actionscript
case "灵魂晶石":
   if(weapon.pz < 2)           // 白品→良品：100%成功
      _loc2_ = weaponUp("品质");
   else if(weapon.pz == 2)     // 上品→精品：50%成功
      if(random(100) % 2) _loc2_ = weaponUp("品质");
   else if(weapon.pz == 3)     // 精品→极品：25%成功
      if(random(100) % 4 == 1) _loc2_ = weaponUp("品质");
```

**品质等级对照表：**

| 品质等级(pz) | 名称 | 战斗力加成 |
|--------------|------|------------|
| 0 | 白品 | +1 |
| 1 | 良品 | +2 |
| 2 | 上品 | +3 |
| 3 | 精品 | +4 |
| 4 | 极品 | +5 |

### 4.2 提升魔魂等级

| 宝石 | 成功率 | 失败惩罚 | 说明 |
|------|--------|----------|------|
| 魔魂晶石 | 35%-90% | 降1级 | +9后失败不降级 |
| 魔魂之心 | 100% | 无 | 仅+9前可用 |

**成功率规则：**
- +0~+5：90%成功率
- +6~+8：50%成功率
- +9~+11：35%成功率，失败后+9以上不降级

**代码逻辑：**
```actionscript
case "魔魂晶石":
   if(weapon.mhdj < 6)         // +0~+5：90%成功
      if(random(100) < 90) _loc2_ = weaponUp("魔魂");
   else if(weapon.mhdj < 9)    // +6~+8：50%成功
      if(random(100) < 50) _loc2_ = weaponUp("魔魂");
   else if(weapon.mhdj < 12)   // +9~+11：35%成功
      if(random(100) < 35) _loc2_ = weaponUp("魔魂");
```

**魔魂等级效果：**
- 每级追加装备基本属性的10%
- 全套装备魔魂等级相同时，额外增加战斗力（如全套+9加9战斗力）

### 4.3 提升使用等级

| 宝石 | 成功率 | 说明 |
|------|--------|------|
| 幻魔晶石 | 20%-50% | 等级越高成功率越低 |
| 幻魔之心 | 100% | 必定成功 |

**成功率规则：**
- 1级→10级：50%成功率
- 10级~80级：30%成功率
- 80级~125级：20%成功率

**等级提升规则：**
- 1级 → 10级（+9）
- 10级~90级 → +10级
- 100级 → 125级（+25）

**升级限制：**
```actionscript
function canuse()
{
   // 装备已经是最高等级
   if(weapon.dj == 125) return false;
   
   // 计算升级后的等级
   var _loc2_ = 125;
   if(weapon.dj == 1) _loc2_ = 10;
   else if(weapon.dj < 100) _loc2_ = weapon.dj + 10;
   else if(weapon.dj < 125) _loc2_ = 125;
   
   // 升级后等级不能超过玩家等级
   if(_loc2_ <= _root.xinxi.dj) return true;
   return false;
}
```

### 4.4 装备开洞

| 道具 | 功能 | 战魂触发概率 |
|------|------|--------------|
| 月光宝盒 | 给无洞装备开第一个洞 | 3%概率激活战魂 |
| 月光宝盒增强版 | 给一洞装备开第二个洞 | 10%概率激活战魂 |

**代码逻辑：**
```actionscript
case "月光宝盒":
   if(weapon.dong == 0)
   {
      weapon.dong = 1;
      if(random(1000) < 30) openzh();  // 3%概率激活战魂
   }

case "月光宝盒增强版":
   if(weapon.dong == 1)
   {
      weapon.dong = 2;
      if(random(1000) < 100) openzh(); // 10%概率激活战魂
   }
```

### 4.5 镶嵌宝石

| 宝石 | 效果 | 战魂提升 |
|------|------|----------|
| 中级战斗力石 | 战斗力+3 | 无 |
| 高级战斗力石 | 战斗力+5 | 战魂等级+1（最高5级） |
| 中级经验石 | 经验+25% | 无 |
| 高级经验石 | 经验+50% | 战魂等级+1（最高5级） |

**代码逻辑：**
```actionscript
case "高级战斗力石":
   _loc2_ = stoneIn("高级战斗力石");
   if(_loc2_ && weapon.zhtype > 0 && weapon.zhdj < 5)
   {
      weapon.zhdj += 1;  // 战魂等级+1
      _root.alertbox("高级宝石的镶入使得装备能量提升，战魂等级提高一级。");
   }
```

**镶嵌规则：**
- 只有带洞装备才能镶嵌
- 一个洞只能镶嵌一个宝石
- 先镶嵌第一个洞，再镶嵌第二个洞

### 4.6 激活战魂

| 宝石 | 成功率 | 说明 |
|------|--------|------|
| 战魂晶石 | 20% | 激活或改变战魂类型 |
| 战魂之心 | 100% | 激活或改变战魂类型 |

**战魂类型：**
- 天魂（zhtype=1）：攻击力+zhdj×5%
- 地魂（zhtype=2）：闪避率+zhdj×2%

**代码逻辑：**
```actionscript
function openzh()
{
   if(_root.openzh == false) return false;
   if(weapon.zhtype <= 0)
   {
      _root.alertbox("装备在精练中爆发出强大的能量激活了装备战魂");
   }
   weapon.zhtype = random(2) + 1;  // 随机天魂或地魂
   weapon.zhdj = 1;                 // 初始等级为1
   return true;
}
```

**注意事项：**
- 如果装备已有战魂，使用战魂晶石/战魂之心会改变战魂类型，但等级重置为1
- 战魂系统需要通过剧情解锁（`_root.openzh == true`）

## 五、战魂等级提升途径

| 途径 | 提升条件 | 说明 |
|------|----------|------|
| 升到极品 | 战魂等级+1 | 品质提升到极品时触发 |

| 魔魂升到+12 | 战魂等级+1 | 魔魂等级达到12级时触发 |

## 九、界面操作流程

### 9.1 打开精练界面

1. 与装备打造师对话
2. 选择"我要精练我的装备"
3. 系统同时打开：精练界面、背包、装备栏

### 9.2 精练操作

1. 将装备拖拽到左侧装备槽
2. 将宝石拖拽到右侧宝石槽
3. 点击"开始"按钮执行精练
4. 系统判断成功或失败，播放对应音效

### 9.3 关闭界面

关闭精练界面时：
- 装备自动返回背包
- 宝石自动返回背包或仓库
