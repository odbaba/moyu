# 魔石商人交互逻辑文档

## 一、概述

魔石商人（代码中称为"moshishang"）是游戏中的重要NPC，玩家可以使用魔石购买各种珍贵物品和幻兽。魔石商人出售的物品包括幻兽、宝石、消耗品、技能书和特殊道具。

**核心文件位置**：
- 商店界面：[scripts/DefineSprite_645/frame_1/DoAction.as](../../scripts/DefineSprite_645/frame_1/DoAction.as)
- NPC按钮：[scripts/frame_12/PlaceObject2_1137_16/CLIPACTIONRECORD on(release).as](../../scripts/frame_12/PlaceObject2_1137_16/CLIPACTIONRECORD on(release).as)
- 全局关闭：[scripts/frame_6/DoAction.as](../../scripts/frame_6/DoAction.as)

## 二、魔石商人位置与访问

### 2.1 进入方式

玩家点击魔石商人NPC时，触发以下逻辑：

```actionscript
on(release){
   _root.CloseAll();              // 关闭所有界面
   _root.moshishang.openme();     // 打开魔石商人界面
   _root.beibao.openme();         // 打开背包界面
   _root.huanshoumb.opens();      // 打开幻兽背包
   var over_sound = new Sound();
   over_sound.attachSound("选择NPC.wav");
   over_sound.start();            // 播放音效
}
```

### 2.2 界面管理

**打开界面**：

```actionscript
function openme()
{
   _X = show_x;  // 285
   _Y = show_y;  // 90
   _visible = true;
}
```

**关闭界面**：

```actionscript
function closeme()
{
   _X = hide_x;  // 800（屏幕外）
   _Y = hide_y;  // 600（屏幕外）
   _visible = false;
   _root.huanshoumb.closeme();  // 同时关闭幻兽背包
}
```

**全局关闭**：

在切换地图或进入战斗时，会调用`CloseAll()`关闭所有界面：

```actionscript
function CloseAll(baobao)
{
   // ... 关闭其他界面 ...
   _root.moshishang.closeme();  // 关闭魔石商人
   // ... 关闭其他界面 ...
}
```

## 三、购买系统

### 3.1 购买流程

玩家在魔石商人界面选择物品后，点击购买按钮触发购买逻辑：

```actionscript
function buy()
{
   // 检查魔石是否足够
   if(_root.beibao.subms(- price_ms))
   {
      id = thing;  // 设置物品ID
      
      // 如果是幻兽
      if(id == "幻兽")
      {
         huanshou.flashme();  // 初始化幻兽属性
         if(!_root.huanshoumb.givebb(huanshou))  // 添加到幻兽背包
         {
            _root.alertbox("\r\r你的幻兽背包已经满了，放不下更多幻兽了");
            _root.beibao.subms(price_ms);  // 退还魔石
            return false;
         }
      }
      // 如果是普通物品
      else if(!_root.beibao.more(this))  // 添加到背包
      {
         noroom._visible = true;  // 显示背包已满提示
         _root.beibao.subms(price_ms);  // 退还魔石
      }
   }
   else
   {
      nomoney._visible = true;  // 显示魔石不足提示
   }
}
```

### 3.2 选择物品

玩家点击物品时，会设置物品信息和价格：

```actionscript
on(release){
   _parent.price_jb = 28000000;    // 金币价格（用于显示）
   _parent.price_ms = 2800;        // 魔石价格（实际扣款）
   _parent.thing = "斗志抑扬";      // 物品名称
   _parent.select._x = _X - 1.5;   // 显示选中框
   _parent.select._y = _Y - 1.5;
}
```

对于幻兽类物品，还会设置幻兽引用：

```actionscript
on(release){
   _parent.price_jb = 10000;
   _parent.price_ms = 1;
   _parent.thing = "幻兽";
   _parent.huanshou = this;  // 设置幻兽引用
}
```

## 五、幻兽生成系统

### 5.1 幻兽属性生成

每种幻兽都有独立的生成逻辑，以攻防型为例：

```actionscript
function newbb(newpz)
{
   flashme(newpz);  // 生成幻兽属性
   _root.huanshoumb.givebb(this);  // 添加到幻兽背包
}

function flashme(newpz)
{
   zs = 0;
   hs_name = othername = "攻防型";
   dj = 1;  // 等级为1
   
   // 随机生成初始属性
   cxgj = random(5) + 10;  // 初始攻击
   cdgj = random(30 - cxgj) + cxgj;  // 初始大攻击
   cfy = random(5) + 5;  // 初始防御
   chp = random(15) + 20;  // 初始生命
   
   // 随机生成成长属性
   cz_xgj = 8 + random(4);  // 攻击成长
   cz_dgj = random(17 - cz_xgj) + cz_xgj;  // 大攻击成长
   cz_fy = 1 + random(6);  // 防御成长
   cz_hp = 30 + random(12);  // 生命成长
   
   // 随机提升某一项属性
   switch(random(8))
   {
      case 0: cxgj = random(100); break;
      case 1: cdgj = random(100 - cxgj) + cxgj; break;
      case 2: cfy = random(100); break;
      case 3: chp = random(291); break;
      case 4: cz_xgj = random(21); break;
      case 5: cz_dgj = random(26 - cz_xgj) + cz_xgj; break;
      case 6: cz_fy = random(16); break;
      case 7: cz_hp = random(41);
   }
   
   // 计算最终属性
   hp = cz_hp * (dj - 1) + chp;
   dgj = cz_dgj * (dj - 1) + cdgj;
   xgj = cz_xgj * (dj - 1) + cxgj;
   fy = cz_fy * (dj - 1) + cfy;
   
   // 计算品质
   pzbase = 0;
   _root.pfc(this);  // 计算品质基础分
   _root.pfhp(this);  // 计算生命品质分
   _root.pfxgj(this);  // 计算攻击品质分
   _root.pfdgj(this);  // 计算大攻击品质分
   _root.pffy(this);  // 计算防御品质分
   
   pz = pzbase + pz_chp + pz_cxgj + pz_cdgj + pz_cfy + 
        pz_cz_hp + pz_cz_xgj + pz_cz_dgj + pz_cz_fy;
   
   if(newpz)
   {
      pz += newpz;  // 额外品质加成
   }
}
```

### 5.2 不同幻兽的差异

不同幻兽的主要差异在于：
- **名称**：hs_name 和 othername
- **基础品质分**：pzbase
  - 攻防型：0
  - 调皮猫：280
  - 吉鲁猪：380
  - 奇异兽、守护等：各有不同

## 六、交互流程图

```
玩家点击魔石商人NPC
    ↓
关闭所有界面（CloseAll）
    ↓
打开魔石商人界面（moshishang.openme）
    ↓
打开背包界面（beibao.openme）
    ↓
打开幻兽背包（huanshoumb.opens）
    ↓
玩家选择物品：
    ├─→ 鼠标悬停
    │       ↓
    │   显示物品描述和价格
    │
    └─→ 点击物品
            ↓
        设置物品信息和价格
            ↓
        显示选中框
            ↓
        点击购买按钮
            ↓
        检查魔石是否足够
            ↓
        ├─→ 魔石不足：显示提示
        │
        └─→ 魔石足够：
                ↓
            扣除魔石
                ↓
            ├─→ 幻兽类：
            │       ↓
            │   生成幻兽属性
            │       ↓
            │   添加到幻兽背包
            │       ↓
            │   ├─→ 成功：完成购买
            │   └─→ 失败：退还魔石，显示提示
            │
            └─→ 物品类：
                    ↓
                添加到背包
                    ↓
                ├─→ 成功：完成购买
                └─→ 失败：退还魔石，显示提示
```

## 十、总结

魔石商人是游戏中重要的经济系统组成部分，提供了使用魔石购买珍贵物品和幻兽的功能：

1. **购买功能**：玩家可以使用魔石购买幻兽、宝石、消耗品、技能书和特殊道具
2. **幻兽系统**：每种幻兽都有独特的属性生成逻辑，确保幻兽的多样性
3. **界面交互**：通过点击选择物品，显示物品描述和价格
4. **背包管理**：自动区分幻兽和普通物品，分别添加到对应的背包

魔石商人系统与背包系统、幻兽背包系统、魔石货币系统紧密配合，构成了游戏的高级经济循环。
